あとから円柱の面数（頂点数）を変更したい（F9の使いどころ）

円柱を置いたあとで「頂点数をもっと増やしたい」と思っても、パネルが出てこない。原因はキーの取り違えと、F9 が効く期間がとても短いこと。

まず F12 はレンダリングで、面数とは無関係。使うのは F9（最後の操作を調整）。そして——移動したあとでは、もう変更できない。

移動を取り消せる段階なら Ctrl+Z で F9 が復活する。それより先に進んでしまったら作り直す。あとから何度も変えたいものは、最初からジオメトリノードの円柱ノードで作る。

Keysまず2つ訂正

キー 実際の機能
F12 レンダリング（画像をレンダー）。面数とは無関係
F9 最後の操作を調整（Adjust Last Operation）。こちらが目的のもの ビューポート左下のヘッドアップディスプレイのパネルと同じ中身

Whyなぜ、あとからだと出てこないのか

公式マニュアルの説明はこうなっている。

「オペレーターを実行した後に、そのパラメーターを調整できる」

「対応しているエディターでは、左下にヘッドアップディスプレイのパネルがある」

「F9（編集 > 最後の操作を調整）のポップアップも同じことをする」

「このパネルは最後に実行された操作に基づく」

効いてくるのは最後の一行。「最後に実行された操作」に基づくので、円柱を追加したあとに別の操作をした瞬間、パネルの中身が入れ替わる。

もっと根本的な理由

Blender のプリミティブはパラメトリックではない。「頂点32個の円柱オブジェクト」が存在しているのではなく、作られた瞬間にただの頂点と面の集合になっている。F9 は「もう一度作り直す」機能であって、既存のメッシュの設定を書き換えているわけではない。だから編集したあとに戻れるはずがない。

Fix対処法（上から順に試す）

1. 追加した直後に F9（本来の使い方）

Shift+A > メッシュ > 円柱
→ 何もせずに F9（または左下のパネルを開く）
→ 頂点 / 半径 / 深度 / ふたの塗りつぶし を調整

追加した直後に必ず数値を決めるのを習慣にするのが、結局いちばん早い。

2. Ctrl+Z で追加直後まで戻ってから F9

移動しただけなら、Ctrl+Z を1回押して移動を取り消せば、最後の操作が「追加」に戻るので F9 が使える。

3. 消して作り直す（結局これが一番速いことが多い）

移動した位置を保ちたいなら、3Dカーソルを使う。

  1. 3Dカーソルをそのオブジェクトにスナップ 
    Shift+S > カーソル → 選択物
  2. 古い円柱を削除（X）
  3. Shift+A > メッシュ > 円柱

    3Dカーソルの位置に作られる。

  4. F9 で頂点数を指定

4. あとから何度でも変えたいなら：ジオメトリノード

これが本当の解決策。ジオメトリノードの円柱ノードはパラメトリックなので、いつでも頂点数を変えられる。

  1. オブジェクトを選択
  2. ジオメトリノードプロパティ > 新規
  3. Shift+A > メッシュ > プリミティブ > 円柱
  4. グループ出力に繋ぐ
  5. モディファイアパネルに「頂点」などが出てくるので、いつでも変更できる

あとから何度も調整する可能性があるものは、最初からジオメトリノードで作るのが正解。各入力の意味は下の表にまとめた。

5. Python コンソールから作る

import bpy
bpy.ops.mesh.primitive_cylinder_add(vertices=64, radius=0.5, depth=2, location=(0,0,0))

数値を書き換えて実行し直せば何度でも作れる。

Nodeジオメトリノードの円柱ノード：入力の意味

入力 マニュアルの定義
頂点（Vertices） 上面と下面の円上の頂点数 3未満ではジオメトリが生成されない
サイドセグメント 側面に沿って垂直に走る辺の数 1未満では生成されない
フィルセグメント 上面・下面の丸い面を埋めるのに使う同心円状のリングの数
半径 Z軸からの頂点の距離 0だと出力は1本の線になる
深度 円柱の高さ
フィルタイプ（プロパティ） 半径が0より大きいとき、上下の円をどう面で埋めるか なし / Nゴン / 三角形

Edit mode編集モードで分割を増やしたい場合

既存の円柱の円周方向の分割数を直接変えることはできないが、近いことはできる。

やりたいこと 方法
高さ方向の分割を増やす Ctrl+R（ループカット）／側面を選択して細分化
円周方向の分割を倍にする 側面の垂直な辺をすべて選択 > 右クリック > 細分化

ただし細分化しただけでは新しい頂点は円弧上ではなく多角形の辺の上に乗るので、断面が真円から外れる。円形に整えるには LoopTools アドオンの「円」を使うか、素直に作り直す。

結論：円周の分割数を変えたいなら作り直したほうが速くてきれい。

Recapまとめ

  • F12 はレンダリング。

    面数とは別の機能。

  • F9 は最後の操作を調整。追加した「直後」だけ有効。

    移動・選択など別の操作をした時点で、もう変えられない。

  • 変えられなくなったら Ctrl+Z で戻るか、作り直す。
  • あとから変えたいものは、ジオメトリノードの円柱ノードで作る。
