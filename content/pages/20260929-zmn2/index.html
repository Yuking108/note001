左のツールバーを消す（T キー）

編集モードで3Dビューポートの左端に縦に並ぶアイコンの列（選択・移動・押し出し・ベベルなど）。画面が狭いときに、これを畳んで作業面積を取り戻す。

3Dビューポート上にマウスを置いて T。もう一度 T で戻る。

消えるのは ツールバー（Toolbar）。メニューからなら ビュー > サイドバー/ツールバー。表示の設定なので、モデルやシーンには一切影響しない。

Whatツールバーとは何か

コンテキストに応じたツールアイコンが並ぶ領域。今のモードで使える操作が出るので、編集モードでは押し出しやベベルが並ぶ。

Where

ツールバーは3Dビューポート専用ではない。シェーダーエディター、UVエディター、シーケンサー、ドープシート、ファイルブラウザなど多くのエディターに共通で存在する。

そしてどこでも T で開閉できる。効かないときは、キーを押す前にマウスがそのエディターの上にあるかを確認する。Blender のショートカットはマウス位置のエディターに効く。

Nearbyついでに覚えておく周辺のトグル

キー / 場所 消えるもの
T 左のツールバー
N 右のサイドバー（アイテム / ツール / ビュー のパネル）
ビュー > ギズモ チェックを外すと、右上のナビゲーションギズモ、右端のズーム・手のひら・カメラ・鍵アイコン
オーバーレイを表示 ヘッダー右のボタン。グリッド、選択のハイライト、原点、法線表示など
Ctrl + Space マウス位置のエディターを一時的に全画面化（レイアウトは保持）

N のサイドバーも T と同じく、グラフエディターやUVエディターなど多くのエディターで共通。

Cleanスクリーンショットを撮るとき

次の順に切っていくと、ほぼ絵だけのクリーンな画面になる。

  1. T — 左のツールバー
  2. N — 右のサイドバー
  3. ビュー > ギズモ のチェックを外す
  4. ヘッダー右のオーバーレイを表示を OFF

作業に戻るときはそれぞれ元に戻すだけ。表示の設定なので、モデルやシーンには一切影響しない。
