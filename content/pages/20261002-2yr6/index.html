ベベルが意図しない方向（下）にかかる

ベベルは選択した辺を挟む2つの面の間に、指定した幅ぶんの面を作る操作。「どちらへ広がるか」は、辺の位置・隣接ジオメトリ・スケール・オプションで決まる。穴（スリット）の縁をベベルして、上面に丸みが乗らず内壁を下へ削る結果になったときの切り分け。

まず Ctrl+A > スケール を適用し、次に Clamp Overlap をオンにする。

この2つで直ることが多い。残るときは Loop Slide・選択ループ・Width Type を順に見る。

Order確認の順番

  1. Ctrl+A > スケール を適用したか
  2. Clamp Overlap をオンにする
  3. Loop Slide をオフにしてみる
  4. 選択しているループが上の縁か
  5. Width Type がチュートリアルと同じか

Cause 1スケールが適用されていない（最有力）

ベベルの幅はローカル空間で計算される。オブジェクトモードで拡大縮小した（スケールが 1.0 でない）状態だと、方向によって実際の幅が変わり、チュートリアルと同じ数値を入れても全く別の結果になる。

  • Nパネルでスケールが 1.0, 1.0, 1.0 になっているか確認
  • なっていなければ Ctrl+A > スケール（または全トランスフォーム）
  • ベベルをかける前に必ずやる。 これを忘れているのが一番多い

チュートリアルの 0.911336 m のような数値をそのまま入れても、スケールが違えば意味が変わる。

Cause 2クランプオーバーラップ（Clamp Overlap）がオフ

オペレーターパネルの Clamp Overlap にチェックを入れる。

オフだと、ベベル幅が隣の面のサイズを超えても止まらない。スリットの壁の高さより幅が大きいと、丸みが内壁を突き抜けて下まで届いてしまう。

オンにすると隣接ジオメトリを超えない範囲に自動で制限される。「幅を上げても途中から広がらなくなる」なら、そこが限界という意味。

Cause 3ループスライド（Loop Slide）がオン

オペレーターパネルの Loop Slide をオフにしてみる。

オンだと、新しく作られる頂点が隣接する辺ループに沿ってスライドする。隣のループ配置が上下非対称だと、ベベルが片側に引っ張られる。

  • 隣接ループが均等 → オンのままでよい（既存の形状を保てる）
  • 片側だけ近い場所にループがある → オフにすると辺に対して垂直な、対称なベベルになる

スリットの縁は「上面（広い）」と「内壁（狭い）」で条件が非対称なので、ここが効いている可能性が高い。

Cause 4選択している辺が違う

一番単純な見落とし。スリットには上の縁と底の縁の2本のループがある。

  • 上面に丸みを付けたい → 上の縁を選ぶ
  • 底の縁を選んでいると、当然下側にベベルがかかる

Alt+クリック でループ選択した際に、狙いと違うループを拾っていないか確認する。編集モードで一度 Alt+A で全解除してから選び直すと確実。

Width幅の指定方法（Width Type）

タイプが違うと同じ数値でも結果が変わる。チュートリアルと揃えること。

タイプ 意味
オフセット（Offset） 元の辺から新しい辺までの距離。チュートリアルで最もよく使われる
幅（Width） ベベル面そのものの幅
深度（Depth） 元の辺からベベル面までの垂直距離
パーセント（Percent） 隣接する辺の長さに対する割合

Tips試し方を速くする

ベベルは実行後も左下のオペレーターパネル（F9）で数値とオプションを変えられる。いちいちやり直さず、パネル上でチェックを切り替えながら結果を見るのが速い。

Ctrl+B 中でも、マウスホイールでセグメント数、C でクランプオーバーラップの切り替えができる。

Variant1本の辺だけベベルすると、隣の辺を巻き込んで端が斜めになる

ベベルは辺だけでなく、その辺の両端の頂点も動かす。

1本の辺をベベルすると、Blender は「この帯をどこで終わらせるか」を解決しなければならない。そのとき端点を隣接する辺に沿ってスライドさせるので、選んでいない横の辺まで形が変わったように見える。これが巻き込みの正体で、バグではなく仕様。

辺ループが一周して閉じている場合は終端が存在しないので、この問題は起きない。1本だけ／途中で途切れる選択のときに必ず出る。

対処

方法 効果
Loop Slide をオフ 端点が隣接辺に沿ってスライドしなくなり、辺に対して垂直に終端する。まずこれを試す
幅を小さくする / Clamp Overlap をオン 帯が隣の辺に届かなくなれば巻き込みも起きない
Miter Outer を変える シャープ / パッチ / アーク で終端の処理が変わる。パッチ は角に面を作って滑らかに処理する
ループ全体を選択してベベルする 閉じたループなら終端処理そのものが不要になる
事前にループカットで区切る 端点が動ける範囲を物理的に制限できる

判断の目安

  • 「端がちょっと斜めになるだけ」で見た目に影響しないなら放置でよい。サブディビジョンを掛ければ見えなくなることも多い
  • 端をきれいに垂直で止めたい → Loop Slide をオフ + 幅を控えめに
  • そもそも角をぐるっと丸めたい → 1本ではなくループ全体を選択するのが本来の使い方
