Blender Compositing 5.0 2026.09.15

コンポジターに「ノードの使用」が見つからない

チェックボックスは 5.0 で削除された。ノードツリーが独立したデータブロックになり、有効化はマテリアルと同じ「新規」ボタンに変わっている。

Question

解説に「コンポジットで『ノードの使用』にチェックを入れる」と書いてあるが、そんなボタンがない

Answer5.0 で削除された。代わりにヘッダーの「新規」を押す

5.0 でコンポジットのノードツリーが独立したデータブロックになり、マテリアルと同じ扱いに変わった。そのため有効化の操作もマテリアルと同じ形式になっている。

5.0 以降の手順

  1. コンポジットワークスペース（またはエディタタイプを「コンポジター」）を開く
  2. ヘッダーの「新規（New）」ボタンを押す → ノードツリーが作られてシーンに割り当てられる
  3. ノードを組む

これが旧バージョンの「ノードの使用にチェック」に相当する操作。

Migration5.0 でのその他の変更点

旧（4.x 以前）新（5.0 以降）
  • ヘッダーの「ノードを使用」チェック → ヘッダーの「新規」ボタン
  • コンポジットノード（最終出力） → グループ出力ノード
  • シーンに1つのノードツリー → データブロックとして複数持てる・他の blend ファイルでも再利用できる
  • scene.node_tree → scene.compositing_node_group

「コンポジットノードが見つからない」という混乱も同じ原因。最終出力はグループ出力につなぐ。

If on 4.x4.x 以前を使っているのに見つからない場合

チェックボックス自体は存在するので、以下を確認する。

  • エディタタイプが「コンポジター」になっていない（シェーダーエディタを見ている）。左上のエディタタイプで切り替える
  • ヘッダーが狭くて項目が隠れている。ヘッダー上で中ボタンドラッグ（またはホイール）すると横にスクロールして出てくる
  • バージョン確認：ヘルプ → Blender について

Follow-up「新規」を押すと自動的に反映されるのか？

反映される。 別途チェックを入れる操作は不要。押すとノードツリーが作られてそのシーンに割り当てられる。以降、F12 レンダリングと出力画像はこのノードツリーを通った結果になる。旧バージョンの「ノードを使用」にチェック＝有効化、という2段階が1つのボタンにまとまった形。

ただし「何も変わらない」ように見える

押した直後は レンダーレイヤー → グループ出力 が素通しで繋がっているだけなので、見た目は一切変わらない。間にノード（グレアやカラーバランスなど）を挟んで初めて効果が出る。

本当のオン / オフスイッチはここ

レンダープロパティ → 後処理 → コンポジティング

既定でオンなので普段は触らないが、「ノードを組んだのにレンダリングに反映されない」ときはここを確認する。逆に、ノードツリーを残したまま一時的に切りたいときもここをオフにする。

ビューポートに反映させたいとき

F12 のレンダリング結果には自動で乗るが、3D ビューポートのプレビューに出すかは別設定。3D ビューポート右上のシェーディングのポップオーバー（下向き矢印）→ コンポジター を「常時」または「カメラ内」にする。既定は「無効」。

効果を切り分けたいとき

  • 個別のノードを一時的に無効化：ノードを選んで M（ミュート）
  • ノードツリーごと外す：ヘッダーのデータブロック名の横の X でリンクを解除
