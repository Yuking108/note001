トーラスに巻きつくコイル（トロイダルコイル）を作る

ドーナツ（トーラス）の輪に沿って、チューブの周りをぐるぐる巻いたコイル——実物でいうトロイダルコイル（環状インダクタ）の形を作る。作り方は3通りあり、目的で選ぶ。

トーラスのメッシュは一切いじらない。トーラスの芯を通る円（＝中心円、半径 R）をレールとして別に作り、そこへ別に作ったバネを沿わせる。

数値で正確に作りたいなら方法C（Python スクリプト）が最も確実。アドオンが入るなら方法Bが最速。アドオンなしで後から巻き数を調整したいときだけ方法A。

Pickどの方法を使うか

方法 向いているケース 難易度
A. スクリュー + カーブ変形 アドオンなしでやりたい／後から巻き数を調整したい ★★☆
B. アドオン「Extra Curve Objects」 とにかく早く作りたい ★☆☆
C. Python スクリプト 数値で正確に作りたい／何度も作る ★☆☆

Model前提：トーラスそのものには巻きつけられない

トーラスのメッシュを加工してコイルにするのではない。トーラスは「巻きつける相手」として置いておくだけで、一切いじらない（最後は隠してもいい）。トーラスの寸法から読むのは R（主半径）と r（副半径）の2つだけ。

レールの半径 ＝ 主半径 R
チューブの外側ではなく芯。ワールド原点からチューブの芯までの距離
コイルの巻き半径 ＝ 副半径 r ＋ ワイヤーの半径
こうするとトーラスの表面にちょうど乗る（例：0.25 + 0.02 = 0.27）

やることの流れは、どの方法でも同じ。

  • トーラスの寸法から R と r を読む（加工はしない）
  • 半径 R の円カーブをレールとして置く（＝ドーナツの芯を通る輪）
  • 断面の円 ＋ スクリューでまっすぐなバネを作り、カーブモディファイアでレールに沿わせる

Step 0今あるトーラスの R と r を調べる

いちばん確実：作り直す

Shift+A > メッシュ > トーラス → F9（redoパネル）で 主半径 = 1 / 副半径 = 0.25 のように自分で数値を入れる。以降の計算で迷わない。おすすめはこれ。

既にあるトーラスから逆算する

トーラスを選択して N（サイドバー）> 寸法（Dimensions）を見る。 

X = Y = 2 × (R + r)
Z     = 2 × r

r（副半径） = Z ÷ 2
R（主半径） = X ÷ 2 − r

デフォルトのトーラスなら X = Y = 2.5 / Z = 0.5 なので、

r = 0.5 ÷ 2       = 0.25
R = 2.5 ÷ 2 − 0.25 = 1.0

オブジェクトモードでスケールをかけている場合は、先に Ctrl+A > スケール で適用してから寸法を読むこと。

Method Aスクリュー + カーブモディファイア

考え方はまっすぐなバネを作り、それを円に沿わせて曲げる。

  1. ワイヤーの断面を作る 
    Shift+A > メッシュ > 円
F9 で   頂点 = 12 / 半径 = 0.02   ← ワイヤーの太さ

    編集モードに入り（Tab）、A で全選択してから下の2操作。終わったら Tab でオブジェクトモードに戻る。 

    R X 90 Enter      ← 円を立てる（XZ平面に向ける）
G X 0.27 Enter    ← 巻き半径ぶん横にずらす（副半径0.25 + ワイヤー半径0.02）
  2. スクリューモディファイアでバネにする

    モディファイアプロパティ > 追加 > 生成 > スクリュー。

    項目 設定値 公式の説明
    軸 Z らせんを作る方向
    角度 360° 1回転の角度
    スクリュー 0.1047 らせん1回分の高さ（＝ピッチ。6.283 ÷ 60巻き）
    反復（Iterations） 60 らせんの回転数（＝巻き数）
    ステップ 16〜24 1回転の分割数（ビューポート）
    レンダーステップ 24〜32 レンダー時の分割数
  3. 沿わせる円カーブを作る 
    Shift+A > カーブ > 円
F9 で   半径 = 1     ← トーラスの主半径と同じ

    位置はトーラスと同じ（両方ワールド原点）にしておく。

  4. カーブモディファイアで曲げる

    コイルのメッシュを選択 → モディファイア > 追加 > 変形 > カーブ。カーブオブジェクトに手順3の円、変形軸は Z（コイルがZ方向に伸びているため）。

スクリュー × 反復 ＝ コイルの全長になる。ここでは 0.1047 × 60 ≒ 6.283 で、中心円の円周とぴったり一致させている。これが肝。

Method Bアドオン「Extra Curve Objects」（最速）

このアドオンのスパイラルには Archimedean / Logarithmic / Spherical / Torus の4種類があり、「Torus」がそのままトーラス状のらせんを生成してくれる。

インストール（4.2 以降は拡張機能プラットフォームに移動している）

  • Blender 4.1 まで — プリファレンス > アドオン で Add Curve: Extra Objects を有効化するだけ
  • Blender 4.2 LTS 以降（5.2 も含む） — バンドルされていないので、プリファレンス > 拡張機能（Get Extensions）で 「Extra Curve Objects」を検索してインストール

    または zip をダウンロードして「ディスクからインストール」／Blender にドラッグ＆ドロップ。

使い方

  1. らせんを出す 
    Shift+A > カーブ > Extra Objects > Spirals > Torus

    F9（redoパネル）で巻き数・半径・分割数を調整。

  2. 太さを付ける

    カーブのままでは線なので、カーブデータプロパティ > ジオメトリ > ベベルで太さを与える。 

    形状 = 丸
深度 = 0.02        ← ワイヤーの太さ
解像度 = 4

Method CPython スクリプトで数式から作る（最も正確）

トーラス上のらせんは数式で厳密に書ける。スクリプトタブに貼って実行するだけ。

パラメトリック方程式

x = (R + r·cos(Nθ)) · cos θ
y = (R + r·cos(Nθ)) · sin θ
z =  r·sin(Nθ)

θ : 0 → 2π
R : トーラスの主半径
r : 巻きの半径
N : 巻き数（整数にすると端がぴったり閉じる）

この式の点は必ずトーラス中心円から距離 r の位置に来る（＝トーラス表面にぴったり乗る）ので、浮いたり埋まったりしない。

スクリプト

import bpy, math

# ===== パラメータ =====
R         = 1.0    # トーラスの主半径
r         = 0.27   # 巻きの半径（副半径0.25 + ワイヤー半径0.02）
N         = 60     # 巻き数（整数にすること）
steps     = 24     # 1巻きあたりの分割数
thickness = 0.02   # ワイヤーの太さ
name      = "ToroidalCoil"
# =====================

total = N * steps
pts = []
for i in range(total):
    t = 2 * math.pi * i / total
    a = N * t
    x = (R + r * math.cos(a)) * math.cos(t)
    y = (R + r * math.cos(a)) * math.sin(t)
    z = r * math.sin(a)
    pts.append((x, y, z))

cu = bpy.data.curves.new(name, 'CURVE')
cu.dimensions = '3D'
cu.bevel_depth = thickness
cu.bevel_resolution = 4
cu.use_fill_caps = True

sp = cu.splines.new('POLY')
sp.points.add(len(pts) - 1)
for i, (x, y, z) in enumerate(pts):
    sp.points[i].co = (x, y, z, 1.0)
sp.use_cyclic_u = True

ob = bpy.data.objects.new(name, cu)
bpy.context.collection.objects.link(ob)
bpy.context.view_layer.objects.active = ob
ob.select_set(True)
print("done:", total, "points")

実行手順

  1. 上部の Scripting タブを開く
  2. 「新規」でテキストを作成し、上記を貼り付け
  3. パラメータ（R / r / N / thickness）を自分のトーラスに合わせる
  4. ▶ 実行（Alt+P）

メッシュにしたい場合は、生成後に オブジェクト > 変換 > メッシュ。

Gotchasつまずきやすい点

  • 全長が円周とずれていると、巻きの端どうしが繋がらない。

    方法Aなら「スクリュー」の値か「反復」を微調整して合わせる。方法Cなら N を整数にする。

  • スケールをかけたトーラスの寸法をそのまま読んでしまう。

    Ctrl+A > スケール で適用してから読む。

  • 原点の位置を気にせずカーブモディファイアを付ける。

    カーブ変形はグローバル空間で効くので、原点がずれると結果もずれる（下の引用）。

  • 内側が詰まって見えるのは正常。

    輪の内周は外周より短いので、均一に巻くと内側ほど巻きが密集する。実物のトロイダルコイルもまったく同じ見た目になるので、これは不具合ではない。

位置合わせの注意（公式マニュアルより）

カーブモディファイアはグローバル空間で動作するので、ジオメトリとカーブの位置関係が結果を決める。オブジェクトの原点をジオメトリの中心に置き（「原点をジオメトリへ」）、オブジェクトの原点をカーブオブジェクトの原点と同じ位置から始めるとよい。

カーブの端を超えた部分は、その端の方向のまま変形が続く。

後者がまさに、方法Aで全長を円周に合わせる必要がある理由。

Tuning調整のコツ

やりたいこと 操作
巻きを細かくする N（巻き数）を増やす。方法Aなら「反復」を増やし、「スクリュー」を 6.283 ÷ 反復 に合わせる
ワイヤーを太くする 断面円の半径／ベベル深度／thickness を上げる
トーラスに密着させる r ＝ 副半径 + ワイヤー半径 にする（0.25 + 0.02 = 0.27）
巻きを浮かせる r をもう少し大きく
コイルだけ見せる トーラス本体を目アイコンで隠す（カメラアイコンで隠してもレンダーに影響しない点は別ノート参照）
