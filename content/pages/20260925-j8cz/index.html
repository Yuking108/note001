カメラを動かすかオブジェクトを動かすか

好みの問題ではなく、ショットごとに答えが決まる。幾何的には同じ絵になるはずなのに結果が別物になるのは、ライティング・物理・ブラーがワールド座標基準で計算されるから。

迷ったらカメラを動かすほうが安全。

判断材料は「何が主役か」「ライティングがどう見えるか」「物理シミュがあるか」「モーションブラーをどう出したいか」の4つ。シミュレーションがあるなら、そこで決まり＝カメラ。

Rules原則：この4つで決まる

  1. シミュレーションがある → カメラ
  2. 空間や状況を見せたい → カメラ
  3. そのものの動きが主題 → オブジェクト
  4. 製品を見せる → 基本カメラ（回転台の質感を狙うならオブジェクト）

「部屋を見せたい」ならカメラ。「ドアが開くのを見せたい」ならオブジェクト。主役が空間の広がり・スケール・位置関係・周囲の状況ならカメラ、そのものの動き（歩く / 落ちる / 開く / 壊れる）ならオブジェクト、という切り分け。

Compare軸ごとの比較

最終的な絵は「カメラと被写体の相対的な動き」で決まるので幾何的には同じに見える。差が出るのは次の4軸。

Why判断の根拠：なぜ別物になるか

ライトと HDRI はワールド座標に固定されている。 被写体を回すと、被写体だけが固定された光の中を通っていく。カメラを回すと、光と被写体の関係は動かないまま視点だけが変わる。これが陰影の差になる。

ターンテーブルはどちらが正しいか

製品のターンテーブル動画は、カメラを回すほうが一般的（ライティングが一定になるため）。逆に「実写スタジオで回転台に乗せた質感」を狙うなら、オブジェクトを回すほうが正しい。

シミュレーションは「演出」ではなく「入力」になる

リジッドボディ・クロス・流体・パーティクル・ヘアがあるシーンでオブジェクトを動かすと、その動きは絵づくりの演出ではなくシミュレーションへの入力になる。慣性や風圧が発生する前提で設計するか、動かさずカメラ側に逃がすかの二択。

モーションブラーは幾何的に等価にならない代表例。同じ相対運動でも、被写体だけがブレるか画面全体が流れるかでまったく別の絵になる。「どちらでも同じはず」と思ったときは、ここを最初に思い出す。

Practice実務的なテクニック

  • カメラを直接動かさず、Empty を親にして Empty を動かす / 回す。回転中心が安定し、あとから軌道だけ差し替えられる
  • Track To コンストレイントでカメラを常に被写体（Empty）に向けておくと、軌道だけ考えればよくなる
  • カーブに沿わせたいなら Follow Path コンストレイント

Deferred保留：両方を同時に動かす

「カメラを回す」と「被写体を回す」を同時にやると、実写では撮れない絵になる。モーショングラフィックス的な表現として使われる手で、リアルな絵を狙うショットでは選ばない。
