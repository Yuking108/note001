スペキュラーとIOR（プリンシプルBSDF）

金属以外の素材の反射の強さを、どのスライダーで決めるか。4.0 で名前が変わってIOR が主役になった件と、「テカりすぎる」をスペキュラーで直そうとすると素材が壊れる理由。

結論：デフォルト（IOR 1.5 / スペキュラー 0.5）のまま触らない。反射の調整は粗さとベースカラーでやる。

デフォルトの 0.5 は正面での反射率 4%にあたり、現実の誘電体（プラスチック、木、布、肌、ガラス）はほぼすべてこの値。つまり大半の素材がデフォルトでカバーできている。

4.x でどうしても反射の強さを変えたいなら、触るのは IOR。「スペキュラー IOR レベル」は物理を無視してでも反射を弱めたい／強めたいときの逃げ道で、通常は 0.5 のまま。

Options4.0 以降の 3 項目：どれを触るか

4.0 でプリンシプルBSDFが整理され、名前と役割が変わった。

項目 内容 触るか
IOR（屈折率） デフォルト 1.5。反射の強さと、透過時の屈折の両方を決める こちらが主役。変えるならここ
スペキュラー IOR レベル 旧「スペキュラー」。デフォルト 0.5 = IOR の計算どおり。動かすと IOR と矛盾した非物理的な値になる 原則そのまま。意図的な逃げ道としてだけ
スペキュラーチント 正面の反射に色を付ける 必要なときだけ

Numbersスペキュラー値と反射率の対応

スペキュラーは「正面から見たときに、その表面がどれだけ光を跳ね返すか」の値。中身はこれだけ。

正面から見たときの反射率 = スペキュラー値 × 0.08
スペキュラー 正面の反射率 相当するIOR 実際の素材
0 0% — 反射しない（非現実的）
0.5（デフォルト） 4% 約1.5 ガラス、プラスチック、ほとんどの素材
1.0 8% 約1.8 現実にはあまりない高さ

Why判断の根拠：「鏡のような反射」は角度が作っている

ガラスも木も肌も、真正面から見たときの反射率は意外と似ていて約 4%。鏡のように強く反射して見えるのは、正面ではなく浅い角度から見たとき。

金属ではそもそも無視される

メタリックを 1.0 にすると、スペキュラーの値は（ほぼ）効かなくなる。金属の反射はベースカラーが決める。

メタリック 反射の色を決めるもの
0（非金属） 白（無彩色）の反射。強さは IOR / スペキュラー
1（金属） ベースカラーの色で反射する

金色の金属を作るならベースカラーを金色にする。金属にスペキュラーをいじっても意味がない。

Mixup「粗さ」とは別物

ハイライトまわりで混同されやすい2つ。

項目 何を変えるか
スペキュラー / IOR 反射の強さ（どれだけ跳ね返すか）
粗さ（Roughness） 反射のぼやけ具合（鏡かマットか）
  • ハイライトが白く小さく鋭い → 粗さが低い
  • ハイライトが広くぼんやり → 粗さが高い

「テカりすぎるから抑えたい」のほとんどは、スペキュラーではなく粗さを上げるのが正解。

スペキュラーを下げると、素材そのものが非現実的になる（光を跳ね返さない物体になる）。

Alternative保留した選択肢：それでも動かす場面

スペキュラー（IORレベル）をデフォルトから動かす場面は少ないが、以下は実用的。

場面 操作
布・起毛素材・つや消しの紙 わずかに下げる（0.3〜0.4）
濡れた表面・ニス塗り IOR を上げる、または少し上げる
完全にマットな板（撮影用の黒ケント紙など） 下げる＋粗さを上げる
アニメ調で反射を消したい 0 にする（非物理的だが意図的）

迷ったらデフォルトの 0.5（IOR 1.5）のままにして、粗さとベースカラーで調整する。これが最も現実に近く、破綻しない。
