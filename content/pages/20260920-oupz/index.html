カーソルに白い丸が付いてくる

ビューポートに出る円は4種類ある。追従するかどうかと、いま何モードかを見れば正体が決まる。

Question

ビューポートでマウスカーソルに白い丸い枠が付いてくる

3Dビューポートで、マウスに細い白の実線の円がずっと追従してくる状態になった。これは何？

Answer「サークル選択（Select Circle）」ツールがアクティブになっている

ツールバーの選択ツールがサークル選択に切り替わっていると、マウスに白い円が常時表示される。3Dカーソルとは別物。

Fix直し方

  • ビューポート上で W を押す（選択ツールが順送りで切り替わる）→ ツイーク または ボックス選択 に戻す
  • または T でツールバーを表示 → 一番上の選択ツール（矢印アイコン）を長押し → Tweak / Box Select を選ぶ
  • C キーで一時的に入っただけなら、右クリックか Esc で抜けられる
  • 円のサイズはこの状態でマウスホイールで変更できる

Identify紛らわしい似たもの

見た目が近いものが4つある。マウスに追従するかといまのモードで切り分ける。

  • 3Dカーソル 追従しない Shift+右クリックで配置。オブジェクト追加位置や回転・スケールの中心。オーバーレイ設定で非表示にできる。
  • 本件のケース サークル選択ツール 追従する / オブジェクト・編集モード 白い実線の円だけ。中に何も描かれない。
  • ブラシの半径 追従する / スカルプト・ペイントモード F + ドラッグでサイズ変更。オブジェクトモードに戻れば消える。
  • プロポーショナル編集の影響範囲 移動中だけ出る / 編集モード 編集モードで O で切り替え。ホイールで半径が変わる。
判別のコツ

画面左上のモード表示を見る。 オブジェクトモードなら選択ツール、スカルプト / ペイントモードならブラシの半径。
