UV Editorで合わせた画像をマテリアルとして反映させる

UV Editor で画像を開いて丁寧に展開を合わせたのに、3Dビューのオブジェクトには何も出ない。UV Editor の画像は展開の見本でしかなく、マテリアルとは別物だから。

同じ画像を、マテリアル側でもう一度読み込む。Shading ワークスペースで画像テクスチャノードを足し、その「カラー」をプリンシプルBSDFの「ベースカラー」に繋ぐ。

ベクトル入力には何も繋がなくていい。空のままなら、オブジェクトのアクティブな UV マップが自動で使われる。つまり UV Editor での作業は無駄になっていない。

Why大前提：UV Editor で画像を開いても、マテリアルにはならない

UV Editor に表示している画像は UV展開の参照用にすぎない。実際にレンダリングされるのはマテリアルのノードのほうで、この2つは別物。自動では繋がらない。

Steps手順

  1. オブジェクトを選択
  2. マテリアルプロパティ > 新規

    赤い球のアイコン。

  3. 上部タブの Shading ワークスペースへ
  4. Shift+A > テクスチャ > 画像テクスチャ
  5. ノードの「開く」ボタンで、UV Editor で使ったのと同じ画像を読み込む
  6. 画像テクスチャの「カラー」→ プリンシプルBSDFの「ベースカラー」へ接続
  7. Z > マテリアルプレビュー で確認

Vectorなぜ UV が自動で効くのか

画像テクスチャノードのベクトル入力について、公式マニュアルはこう書いている。

「何も接続されていない場合、座標はオブジェクトのアクティブなUVマップから取られる（Z = 0）」

だからベクトル入力には何も繋がなくていい。UV Editor で調整した UV が、そのまま使われる。

Recap覚え方

  • UV Editor で画像を開いただけでは表示されない。

    そこは「どこに貼るか」を決める場所。

  • Shading（マテリアル）で、同じ画像をもう一度読み込む。

    こちらが「何を貼るか」を決める場所。

  • ベクトル入力は空のままでいい。

    アクティブな UV マップが自動で使われる。

両方そろって初めて画像が表示される。
