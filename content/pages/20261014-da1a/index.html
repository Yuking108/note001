ビデオ編集（VSE）でリタイミングが見つからない

5.2 でクリップを選択しても何も出ない。サイドバー（N）を探しても無い。機能が消えたわけではなく、リタイミングキーが既定で非表示なだけ。

ストリップを選択して Ctrl + R。これでキーが現れる。メニューは「ストリップ > リタイミング」（Strip > Retiming）に全部入っている。

速度だけ手早く変えたいなら、キーを出さずに ストリップを選択 → R → 速度の数値を入力でよい。

キーは Show Retiming Keys プロパティを有効にするまで表示されない （Keys stay hidden until the Show Retiming Keys property is enabled）

「素早い速度変更には R を押して速度を入力する」

Steps最短手順

  1. ストリップ（クリップ）を選択
  2. Ctrl + R でリタイミングキーの表示をオンにする

    メニューからなら ストリップ > リタイミング > リタイミングキーを切り替え（Toggle Retiming Keys）。

  3. 出てきたキーをドラッグまたは G で移動して伸縮する

    伸ばせばスロー、縮めれば早送りになる。

キーを増やさずに速度を変えるだけなら ストリップを選択 → R → 数値入力が最短。区間ごとに速度を作り分けたいときだけ Ctrl + R からキーを触る。

Gotchasキーの選択・移動のクセ（ここでつまずく）

  • ボックス選択は、すでにキーが1つ選択されているときだけキーを拾う。

    そうでないとストリップを選択してしまう。「囲ってもキーが選べない」のはこれが原因。まず1つクリックで選ぶ。

  • Ctrl + クリックで、そのキーより右側のすべてのキーを選択できる
  • キーの移動はドラッグまたは G
  • 移動させたキー以外は動かない

    複数区間をまとめて伸縮したいなら複数選択が必要。

  • ストリップの境界外にあるキーは、最初／最後のキーと一緒に動く（隠れたリタイミング情報を保つため）

Limitsできないこと（公式明記の制限）

  • エフェクトストリップはリタイミングできない
  • 既存のアニメーション（キーフレーム）はリタイミングされない。リタイミングされるのはストリップの中身（コンテンツ）だけ
  • 音声のリタイミングは正確ではない。Audaspace 経由でフレームごとの再生速度を渡す方式のため、わずかにずれることがある
  • メタストリップは子ストリップごとリタイミングできる（メタ → 子の順に評価される）

Principle仕組み（なぜキーで速度が変わるのか）

リタイミング区間は2つのリタイミングキーで挟まれる。各キーが持つ値は2つだけ。

strip_frame_index
ストリップ先頭から数えたキーの位置（素材側の時間）
retiming_factor
0 = 素材の最初のフレーム / 1 = 最後のフレーム
  • 最後のキーの位置がストリップの長さを決める
  • 再生時は retiming_factor × 素材の長さ で表示するフレームを求める

キーの種類は3つ。

キーの種類 区間の繋ぎ方
デフォルト 2つのキー間を線形補間
フリーズフレーム 両端のキーが同じ retiming_factor を持つ
速度トランジション 隣接区間の傾きに接する円弧で繋ぐ（必ずキー2つセット）

History「昔は選択すれば出た」について

リタイミングキーは Blender 4.0 で導入された機能。古い解説には 「追加 > エフェクトストリップ > 速度コントロール」を使う手順も多いが、現在の正式な方法はリタイミングキー。

いずれにしても 5.2 では Ctrl + R でキー表示をオンにしないと何も見えないので、そこだけ押さえればよい。
