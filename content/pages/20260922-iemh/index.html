ループ選択ができない（左下にパネルが出る）

左下のパネルは「直前の操作」パネルで、エラーではない。出ている時点でループ選択コマンド自体は実行されている。直すべきは選択範囲のほうで、Mac では Option+左クリック が視点回転に奪われているのが最も多い。

Question

ループ選択しようとすると左下に画面が出てきて、選択にならない

Alt+左クリック でループ選択しようとすると、画面左下に「ループ選択」というパネルが出てきて、意図した選択にならない。

Answerパネルは正常。問題は「選択範囲が想定と違う」ほう

左下に出るのはオペレーターパネル（直前の操作 / Adjust Last Operation）。操作を邪魔しているわけではない。

Blender では何か操作を実行すると必ず左下に出て、そのままパラメータを変更できる。つまりパネルが出ている＝ループ選択コマンドは実行されている。

  • 左の > をクリックすれば折りたたまれる
  • 折りたたんだあとでも F9 を押せば同じパネルがマウス位置に出る

確認する順番

順 確認するところ 該当すると起きること
1 左下パネルの「面ループの区切り」 シームやマテリアル境界でループが途切れ、数枚しか選択されない
2 プリファレンス > 入力 の「3ボタンマウスを再現」 Option+左クリック が中ボタン（視点回転）になり、ループ選択が発動しない。Mac で最多
3 クリックしている位置 ループの方向が定まらず、1枚だけ選択される
4 トポロジー（三角面・N-gon） ループがそこで止まる

Cause 1パネルの「面ループの区切り」がオンになっている

パネルに出ている シーム / シャープ / マテリアル は、ループをどこで止めるかの指定。ここがオンだと、シームやマテリアル境界でループが途切れて数枚しか選択されない。

オフにする手順

  1. まず Alt+左クリック でループ選択を実行する（左下にパネルが出る）
  2. 左下の「ループ選択」の左にある > をクリックしてパネルを展開する
  3. 「面ループの区切り」の3つのボタン（シーム / シャープ / マテリアル）を見る
    • 青くハイライトされているものがオン
    • 全部が暗いグレーならオンになっていない → この原因ではないので原因3へ
  4. オンのボタンを Shift+左クリック して消灯させる。全部を暗い状態にするのがゴール
  5. 変更した瞬間にループ選択が再計算され、選択範囲が広がる

この3つは複数選択できるトグル（enum flag）なので、普通のクリックだと「そのボタンだけオン」に切り替わってしまう。個別にオン/オフするには Shift+クリック。パネルを閉じてしまった後でも F9 でマウス位置に同じパネルが出る。

次回もまた区切りが有効に戻る場合

ショートカットから実行したオペレーターは、キーマップに保存されたプロパティを使う。そのためパネルで変えても、次の Alt+クリック でまた元に戻ることがある。恒久的に変えるならキーマップを直接編集する。

  1. 編集 > プリファレンス > キーマップ
  2. 検索欄に loop_select と入力（検索対象を「オペレーター名」に切り替えると見つけやすい）
  3. 3Dビュー > メッシュ の中に出てくる項目の左の > を展開
  4. 区切り（Delimit）関連のチェックを外す
  5. プリファレンスは自動保存されるが、自動保存をオフにしている場合は左下メニューから「プリファレンスを保存」

面倒ならメニューから実行する

そもそもショートカットを使わずにメニューから実行すれば、キーマップのプロパティに引きずられない。

  • 選択 > ループ > 辺ループ（Alt+クリック と同じ）
  • 選択 > ループ > 辺リング

Cause 2macOS で Alt+クリックが奪われている（Mac で最多）

プリファレンス > 入力 の 「3ボタンマウスを再現（Emulate 3 Button Mouse）」がオンだと、 Option+左クリック が中ボタン（視点回転）として扱われ、ループ選択が発動しない。

トラックパッド運用でオンにしている人が多いので、Mac ではこれが一番あり得る。

  • 対処A — この設定をオフにする（マウス利用時）
  • 対処B — オンのままにしたいなら、ループ選択をメニューから実行する。選択 > ループ > 辺ループ / 辺リング
  • 対処C — キーマップで Loop Select のショートカットを別キーに割り当て直す

macOS 側のショートカット（Mission Control 等）が Option を奪っている場合も同様なので、システム設定 > キーボード > キーボードショートカット も確認する。

Cause 3クリックする位置が悪い

ループ選択はクリックした位置に近い辺の向きでループの方向が決まる。面の中心付近をクリックすると方向が定まらず、1枚だけ選択されることがある。

→ 進ませたい方向と直交する辺のすぐ近くをクリックする。

Cause 4トポロジーが四角面で繋がっていない

途中に三角面や N-gon があると、ループはそこで止まる。インセットやベベルの結果、中央が大きな N-gon になっているケースが多い。

  • Shift+Alt+クリック で継ぎ足し選択する
  • 選択 > 類似選択を使う
  • 一度トポロジーを整える

Note「直前の操作」パネルは閉じるより F9 で呼ぶ

このパネルはモデリング中に頻繁に使う。ベベルのセグメント数やループカットの本数など、実行後に数値を詰められるので、閉じる癖をつけるより F9 で呼び出す運用にすると効率がいい。
