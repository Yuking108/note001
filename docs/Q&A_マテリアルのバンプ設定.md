# Q. マテリアルのバンプは最新バージョンだと何に設定したらいい？

古いチュートリアル通りに進めると項目が見つからない。現行バージョンでのバンプの組み方を知りたい。

## A. 仕組みは変わっていない。4.0 以降で UI の場所が変わっただけ

バージョン状況（2026-09時点）

- 現行リリース: **5.2 LTS**
- **5.3 は 2026-11-10 リリース予定でまだ未リリース**（アルファ版は入手可能）
- バンプ関連のノードは 2.8 系から 5.x まで互換。作り方は同じ

## 標準的なノード構成

```
画像テクスチャ ──(カラー)──> バンプ の「高さ(Height)」
バンプ ──(ノーマル)──> プリンシプルBSDF の「ノーマル」
```

### 押さえるポイント

- 画像テクスチャの**カラースペースを「非カラー（Non-Color）」に変更する**。sRGB のままにするのが最多の失敗
- 繋ぐ先はバンプノードの「**高さ**」。「ノーマル」入力ではない
- **4.0 以降、プリンシプルBSDF の「ノーマル」は一番下の「ジオメトリ」パネルの中にある**。古い動画では一覧に並んでいるので見失いやすい

### バンプノードの値

| 項目 | 目安 |
| --- | --- |
| 強さ（Strength） | 0〜1。デフォルト 1 は強すぎることが多いので 0.1〜0.5 から |
| 距離（Distance） | 凹凸の高さ（シーン単位）。メートル単位なら 0.01〜0.05 が現実的 |
| 反転（Invert） | 凹凸が逆に見えるときにオン |

### ノーマルマップ画像の場合

`_normal` のような紫っぽい画像はバンプではなく**ノーマルマップ**ノードを使う（カラースペースは同じく非カラー）。両方使うなら、ノーマルマップノードの出力をバンプノードの「ノーマル」入力に繋いで直列にする。

## マテリアルプロパティ側の「ディスプレイスメント」

マテリアルプロパティ > 設定 > サーフェス > ディスプレイスメント は、デフォルトの**「バンプのみ」**のままで OK。

実際にメッシュを変形させたいときだけ「ディスプレイスメントとバンプ」に変更し、Cycles + アダプティブサブディビジョンが必要。**EEVEE では効かない**。

## プロシージャルなバンプ（ノイズ + カラーランプ + バンプ）

画像を使わずにノイズで凹凸を作るパターン。5.x でもそのまま作れる。

```
ノイズテクスチャ ──(カラー)──> カラーランプ の「係数」
カラーランプ ──(カラー)──> バンプ の「高さ」
バンプ ──(ノーマル)──> プリンシプルBSDF の「ノーマル」（ジオメトリパネル内）
```

### ノードの追加方法

`Shift+A` から

- テクスチャ > **ノイズテクスチャ**
- コンバーター > **カラーランプ**
- ベクトル > **バンプ**

### 参考値

- ノイズテクスチャ: 3D / スケール 105 / 細かさ 5.8 / 粗さ 0.816 / 歪み 0
- バンプ: 強さ 0.329 / 距離 1.0

### 4.1 以降でノイズテクスチャに増えた項目

古いチュートリアルのスクショと見た目が違う理由。

- **タイプ**のプルダウンが追加（fBM がデフォルト。他に Multifractal / Ridged Multifractal / Hybrid Multifractal / Hetero Terrain）
- **ラクナリティ**入力が追加（デフォルト 2.0）
- **正規化**チェックボックスが追加（デフォルト ON）

スケール / 細かさ / 粗さ / 歪み はそのまま残っているので、追加項目はデフォルトのままで上記の値を入れれば同じ結果になる。

### カラーランプの役割

ノイズの濃淡（コントラスト）を調整して凹凸の出方をコントロールする。黒と白のハンドルを内側に寄せるほど凹凸がくっきりする。バンプの強さだけで調整するより狙った質感にしやすい。

## 補足

ノイズの「カラー」出力をカラーランプの「係数」に繋ぐ形でも動く（グレースケールに変換される）。ノイズの「係数」出力を使うほうがより一般的。
