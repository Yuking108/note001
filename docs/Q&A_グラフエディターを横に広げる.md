# Q. グラフエディターを横に広くしたい

キーフレームが左端に固まっていて見づらい。横方向に広げたい。

## A. 「表示のズーム」と「エディター自体の大きさ」の2通りある

### まずこれ: `Home`（全体表示）

グラフエディターにマウスを置いて **`Home`** を押すと、**すべてのキーフレームが画面いっぱいに収まるようにフィット**する。フレーム範囲が -1728〜2688 のように無駄に広がってしまっている状態は、これ一発で直る。

- **`Home`** … 全てのキーを表示（ビュー > 全てをフレームイン）
- **テンキー `.`** … 選択したキーだけにズーム（ビュー > 選択をフレームイン）

### 横方向だけズームしたい

- **`Ctrl` + 中ボタンドラッグ** … 縦横を独立してズーム。**左右にドラッグするとX（フレーム方向）だけ伸び縮みする**
- マウスホイール … 縦横まとめてズーム
- 下端のスクロールバーの**丸い端をドラッグ**してもX方向だけズームできる
- `Ctrl` + ホイール … 横スクロール

トラックパッドなら、2本指の左右スワイプで横スクロール、ピンチでズーム。

### 表示するフレーム範囲を絞る

見たい区間だけを表示したいなら、**ビュー > フレーム範囲をプレビュー** や、タイムラインの開始/終了フレームを狭めると、その範囲がエディターの基準になる。

## エディター（領域）自体を大きくしたい場合

- **エリアの境界線をドラッグ** … 一番素直な方法
- **`Ctrl` + `Space`** … マウスが乗っているエディターを**一時的に全画面化**。もう一度押すと元のレイアウトに戻る。グラフを細かく編集するときはこれが一番速い
- 境界線を右クリック > エリアを分割 / 統合 … レイアウトそのものを組み替える
- 画面上部のワークスペースタブで **Animation** に切り替えると、アニメーション向けのレイアウトになる

## 補足

`Home` は3Dビューポートやシーケンサーなど他のエディターでも「全体を表示」として共通で使える。`Ctrl+Space` の最大化トグルも全エディター共通なので、この2つを覚えておくと作業が速い。
