# Q. ベベルをかけた後に辺を動かすと、ベベルの段数だけ動かさないといけなくて厄介。どうしている？

## A. 結論：編集中は「ベベルモディファイア」で持ち、メッシュ自体にはベベルをかけない

Ctrl+B の**ベベルツールは破壊的**で、1本の辺が実体のある2〜数本の辺に増える。以後の編集で毎回その束を扱うことになるので、当然やりにくくなる。

ハードサーフェス系のモデリングでは原則がはっきりしていて、

> **ベベルは最後の仕上げ。編集する形はローポリの「ケージ」のまま保つ。**

## 非破壊ベベルの基本セット

1. 角を落とさない、素の形（クリーンな四角面）でモデリングする
2. **ベベルモディファイア**を追加
3. **Shade Auto Smooth（Smooth by Angle）** をモディファイアの最後にかける
4. 必要なら **ウェイテッドノーマル** モディファイア、またはベベルモディファイアの **Harden Normals** で陰影を整える

これで辺を動かすときは常に1本の辺を動かすだけになり、ベベルは自動で追従する。段数や幅も後からいつでも変えられる。

### 「どの辺にベベルをかけるか」の制御

ベベルモディファイアの **制限方法（Limit Method）** で切り替える。

| 制限方法 | 使いどころ |
| --- | --- |
| 角度（Angle） | 一括でざっくり。まずはこれ |
| ウェイト（Weight） | 辺ごとにベベルウェイトを指定。狙った辺だけ落とせる |
| 頂点グループ | 領域単位で制御したいとき |

辺ごとに指定する場合は、編集モードで辺を選んで Ctrl+E → **ベベルウェイト**（またはNパネルの辺データ）で値を1にする。

## すでに破壊的ベベルをかけてしまった場合の戻し方

- 直後なら Ctrl+Z
- 進んでしまった場合：ベベルで増えた辺ループを **Alt+クリックで全部選択 → M → 距離でマージ**（Merge by Distance）で1本に潰せる
- または選択して **X → 辺を溶解（Dissolve Edges）**。ただし面の構成が崩れることがあるので、マージのほうが安全

戻したら、その辺にベベルウェイトを付けてベベルモディファイアに任せる。

## それでも破壊的ベベルを扱うときの選択テクニック

- ベベルの帯をまとめて選ぶ：ループを1本 Alt+クリック → **Ctrl+テンキー＋** で選択範囲を拡大
- 類似選択（Shift+G）で同じ方向・長さの辺をまとめて拾う
- 移動は **辺スライド（GG）** やプロポーショナル編集を使うと帯のまま素直に動く

## 破壊的ベベルを「あえて」使う場面

- スカルプトやゲーム書き出しなど、最終的にメッシュを確定させる必要があるとき
- → **作業の最後にモディファイアを適用**する。もしくは適用前のオブジェクトを複製してバックアップに残す

## まとめ

| 状態 | 方針 |
| --- | --- |
| 形を触っている最中 | ベベルモディファイアで非破壊。メッシュはローポリのまま |
| 角の出方を調整したい | 制限方法をウェイトにして辺ごとに指定 |
| 書き出し・スカルプト直前 | そこで初めて適用（バックアップを残す） |
