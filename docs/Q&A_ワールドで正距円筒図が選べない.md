# Q. Blenderでワールドの投影方式に「正距円筒図」が出てこない

HDRIをワールドに貼ろうとしたが、投影（Projection）のドロップダウンに「正距円筒図（Equirectangular）」が見つからない。

## A. 「環境テクスチャ」ではなく「画像テクスチャ」ノードを使っているのが原因

Blenderは**使っているテクスチャノードによって選べる投影方式が違う**。

| ノード | 選べる投影方式 |
| --- | --- |
| 環境テクスチャ（Environment Texture） | 正距円筒図 / ミラーボール |
| 画像テクスチャ（Image Texture） | フラット / ボックス / 球 / チューブ |

HDRIを貼るときに画像テクスチャノードを追加してしまうと、投影の欄に「正距円筒図」は出てこない。

## 直し方

1. シェーダーエディタを開く
2. 左上のモードを **「オブジェクト」→「ワールド」** に切り替える
3. 追加 → テクスチャ → **環境テクスチャ**
4. 環境テクスチャの **カラー出力** を **背景（Background）のカラー入力** につなぐ
5. これで投影の欄に「正距円筒図」が表示される

## 他に考えられる原因

- プロパティパネルのワールドタブから設定していて、そこでは投影の項目が省略されて見えていない（シェーダーエディタで開けば出る）
- シェーダーエディタのモードがワールドになっておらず、ワールドのノード自体が表示されていない

## 補足

環境テクスチャで正しく組んでいるのに項目がグレーアウトしている場合は、画面のスクショを見れば原因を特定しやすい。
