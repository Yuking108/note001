# Q. ビューポートでマウスカーソルに白い丸い枠が付いてくる

3Dビューポートで、マウスに細い白の実線の円がずっと追従してくる状態になった。これは何？

## A. 「サークル選択（Select Circle）」ツールがアクティブになっている

ツールバーの選択ツールがサークル選択に切り替わっていると、マウスに白い円が常時表示される。3Dカーソルとは別物。

## 直し方

- ビューポート上で `W` を押す（選択ツールが順送りで切り替わる）→ 「ツイーク」または「ボックス選択」に戻す
- または `T` でツールバーを表示 → 一番上の選択ツール（矢印アイコン）を長押し → Tweak / Box Select を選ぶ
- `C` キーで一時的に入っただけなら、右クリックか `Esc` で抜けられる
- 円のサイズはこの状態でマウスホイールで変更できる

## 紛らわしい似たもの

| 見た目 | 正体 | メモ |
| --- | --- | --- |
| 赤白の破線の円＋十字線 | 3Dカーソル | マウスには追従しない。`Shift+右クリック`で配置。オブジェクト追加位置や回転・スケールの中心。オーバーレイ設定で非表示にできる |
| 白い実線の円（追従する） | サークル選択ツール | 本件のケース |
| 円（追従する、モードがスカルプト/ペイント） | ブラシの半径 | `F` + ドラッグでサイズ変更。オブジェクトモードに戻れば消える |
| 移動中に出る白い円 | プロポーショナル編集の影響範囲 | 編集モードで `O` で切り替え |

## 補足

判別のコツは画面左上のモード表示を見ること。オブジェクトモードなら選択ツール、スカルプト/ペイントモードならブラシの半径。
