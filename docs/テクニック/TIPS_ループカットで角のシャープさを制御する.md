# ループカットで角のシャープさを制御する（サポートループ）

## 目的

サブディビジョンサーフェスを掛けたときに、**角をシャープにしたり、意図した丸みを出したりする**。`Ctrl+R` のループカットで辺を追加することでコントロールする。

この追加する辺を **サポートループ（support loop / holding edge）** と呼ぶ。

## 原理: 位置がすべて

サブディビジョンは「**周囲の頂点の平均**」で滑らかな面を作る。だから:

```
角から遠い位置にループ  →  平均される範囲が広い  →  丸くなる
角に近い位置にループ    →  平均される範囲が狭い  →  シャープになる
```

**ループの本数ではなく、角からの距離で決まる。**

ここを押さえておくと、「とりあえず分割を増やす」のではなく、狙った丸みを作れるようになる。

| ループの位置 | 結果 |
| --- | --- |
| 角のすぐ脇 | ほぼ直角のエッジ |
| 角から少し離す | 小さな丸み |
| 角から遠い / ループなし | 大きく丸まる |
| 面の中央だけ | **角のシャープさはほとんど変わらない**（ポリゴンが増えるだけ） |

面の中央に1本入れただけでは角は立たない。**角を立てたいなら角の近くに置く**のが要点。

## 手順

1. 編集モードで **`Ctrl+R`**
2. マウスを動かして、入れたい方向の辺をハイライトさせる
3. **クリック**するとスライドモードに入る
4. そのままマウスを動かして位置を決める → **左クリックで確定**
5. **位置を中央のままにしたいなら、スライドせずに右クリック**（または `Esc`）

### 覚えておくと速い操作

| 操作 | 内容 |
| --- | --- |
| `Ctrl+R` → **マウスホイール** | ループの本数を増やす（ハイライト中） |
| スライド中に **`E`** | 均等（Even）モード。隣の辺の形に関係なく一定の距離で入る |
| スライド中に数値入力 | 位置を数値指定（-1〜1） |
| 確定後に `F9` | 係数（Factor）や本数をあとから微調整 |

## 実はベベルのほうが向いている場面が多い

角を立てる目的なら、**`Ctrl+B`（ベベル）でセグメント1〜2** のほうが効率がいい。

| 方法 | 性質 |
| --- | --- |
| **ループカット（`Ctrl+R`）** | **1本ずつ、片側に**入る。面を横切る方向を自分で選ぶ |
| **ベベル（`Ctrl+B`）** | 選んだ辺の**両側に均等に**入る。角の制御そのものが目的の機能 |

角を挟む2本のサポートループが欲しいなら、ループカット2回よりベベル1回のほうが速く、対称性も保証される。

**使い分け**

- **形そのものを分割したい / 特定の方向に辺を走らせたい** → ループカット
- **角のシャープさだけ調整したい** → ベベル
- **ジオメトリを増やしたくない** → クリース（次項）

## ジオメトリを増やさない方法: クリース

辺を選択して **`Shift+E`** → マウス移動（または数値入力）。

サブディビジョンに対して「この辺は尖らせる」という**重みを付ける**機能。0〜1で指定し、1で完全にシャープになる。

- **ポリゴンが一切増えない**ので軽い
- ただし**丸みの大きさを細かくコントロールしにくい**
- 他のソフトへ書き出すと情報が失われることがある

ハードサーフェスの仕上げではサポートループ、ラフな確認やポリゴンを節約したい場面ではクリース、という使い分けになる。

## 注意点

- サポートループを入れすぎるとトポロジーが重くなり、後の編集が大変になる（ベベル後の編集と同じ問題）
- **先に形を作り、サポートループは最後に入れる。** 早い段階で入れると形の修正が面倒になる
- ブーリアンを使う場合は、ブーリアンの後にサポートループを入れる
