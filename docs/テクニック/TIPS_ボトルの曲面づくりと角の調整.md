# ボトルの曲面づくりと角の調整

ボトルのような回転体で、**くびれ・ふくらみ（曲面）**を作り、**全体の角**を整えるまでの流れ。

---

## 1. 曲面を作る — ループカット + スケール

### 手順

1. **`Ctrl + R`** → 辺にカーソルを乗せると**マゼンタの線**でカット位置がプレビューされる
2. クリックで確定 → そのままスライドできるので、位置を決めて再クリック
   （右クリック / `Esc` でスライドせず中央に固定）
3. 辺ループを **`Alt + クリック`** で選択
4. **`S`** でスケール → くびれ・ふくらみができる

### コツ

| 操作 | 効果 |
| --- | --- |
| **`S` → `Shift + Z`** | Z以外（XY）だけスケール。**円形断面を保ったまま太さだけ変える**。回転体ではこれが基本 |
| **プロポーショナル編集（`O`）** | 隣のループも滑らかに追従する。境目がカクッと折れるのを防ぐ。ホイールで影響範囲を調整 |
| **`G` → `G`（辺スライド）** | ループの位置だけを面に沿って動かす |
| **`G` → `Z`** | 高さ方向の位置調整 |
| `Ctrl + R` のプレビュー中にホイール／数字入力 | カットの本数を増やす（均等に配置される） |

### 注意点

- **ループカットは極（三角形やNゴン）で止まる。** 円柱の天面・底面がNゴンのままだと、そこでループが途切れる。思ったように形が取れないときは、まず**トポロジー**を疑う
- ループを増やしすぎると後の調整が大変になる。**少ない本数で形を決めてから足す**

> 💡 **ボトルを一から作るなら、円柱をいじるより「断面のプロファイル＋スクリューモディファイア」のほうが圧倒的に編集しやすい**（輪郭の頂点を動かすだけでシルエットが変わる）。
> → [[Q&A_ボトルと中身（液体）のベベル運用]]
>
> ループカット＋スケールは、**すでにある円柱形を手早く整える**ときの手段、という位置づけ。

---

## 2. 全体の角を整える — ベベル → サブディビジョンサーフェス

### 順番がすべて

```
ベベル                         ← 上（先に処理される）
  ↓
サブディビジョンサーフェス        ← 下
  ↓
スムーズ by アングル（オートスムーズ） ← 一番最後
```

- **ベベルは必ずサブディビジョンサーフェスより上**に置く。「サブサーフはほぼ常にスタックの最後」が原則
- **オートスムーズはさらにその後ろ**（→ [[Q&A_スムーズシェードをかけるタイミング]]）

> ⚠️ ここでの「適用」は、モディファイアを**追加する**という意味で捉えること。`Ctrl+A` の**適用（確定）は最後まで我慢する**。形を触っている間は非破壊で持つのが鉄則。
> → [[Q&A_ベベル後の編集が大変な問題]]

### なぜベベルが先なのか

サブディビジョンサーフェスは、**辺の近くに別の辺があるほど、その角を鋭く保つ**という性質がある。ベベルが作る細い帯が、そのまま**サポートエッジ（角を支える辺）**として働く。

> **ベベルの幅が、角の丸みそのものを決める。**
>
> - 幅が**狭い** = サポートが近い = **角が鋭く残る**
> - 幅が**広い** = サポートが遠い = **角が丸くなる**

つまりベベルとサブサーフは別々の処理ではなく、**ベベルでサブサーフに「ここは角」と教えている**という関係。

### サブサーフと併用するときのベベル設定

| 設定 | 推奨 | 理由 |
| --- | --- | --- |
| セグメント数 | **偶数** | サブサーフとの相性が良い |
| プロファイル | **1.0** | 同上 |
| 制限方法 | **ウェイト** | 狙った辺だけに効かせられる |
| ノーマルを固める（Harden Normals） | **使わない** | サブサーフ併用時は不要。相性が悪い |

### うまくいかないときのチェック

| 症状 | 対処 |
| --- | --- |
| 角が歪む | **ベベル幅を小さくする** |
| 極（5本以上の辺が集まる頂点）の周りが崩れる | その付近に**サポートループを足す** |
| UVが伸びる／テクスチャが歪む | ベベル＋サブサーフの**既知の弱点**。面の大きさを揃える（正方形に近づける）ほどマシになる |
| 角が立ちすぎ／丸すぎ | ベベル幅で調整。オートスムーズの角度しきい値も見る |

### そもそもサブサーフは必要か

**単純な形なら、ベベルのセグメント数を増やすだけでサブサーフなしでも十分滑らかになる。** 極の変形問題もUVの歪みも起きないので、結果がきれいなことも多い。

**サブサーフは「必要なら使う」くらいの距離感でよい**、というのが実際のところ。ボトルのような回転体は面が素直なので相性は悪くないが、まずはベベルだけで足りないか確かめる。

---

## 3. 一部の角だけ調整する

ベベルモディファイアの**制限方法を「ウェイト」**にして、辺ごとにベベルウェイトを付ける。

1. 編集モードで辺を選択
2. `Ctrl + E` → **ベベルウェイト** でドラッグして1に
3. モディファイアの制限方法を「ウェイト」に

**ウェイト値は幅の倍率にもなる**ので、1つのモディファイアで「太い面取り」と「細い面取り」を作り分けられる。

→ 詳しくは [[Q&A_Ctrl+Bとベベルモディファイアの使い分け]]

## まとめ

| やりたいこと | 方法 |
| --- | --- |
| くびれ・ふくらみ | ループカット → 辺ループを `S` → `Shift+Z`。プロポーショナル編集で馴染ませる |
| ボトルを一から | プロファイル + スクリューモディファイア |
| 全体の角 | ベベル（上）→ サブサーフ（下）→ オートスムーズ（最後） |
| 角の鋭さ | **ベベルの幅**で決まる。狭い＝鋭い、広い＝丸い |
| 一部の角だけ | ベベルウェイト + 制限方法「ウェイト」 |
| 確定（適用） | 書き出し直前まで我慢。複製をバックアップに残す |
