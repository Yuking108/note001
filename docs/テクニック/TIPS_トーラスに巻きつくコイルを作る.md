# トーラスに巻きつくコイル（トロイダルコイル）を作る

ドーナツ（トーラス）の輪に沿って、チューブの周りをぐるぐる巻いたコイルを作る方法。
実物でいう**トロイダルコイル**（環状インダクタ）の形。

**やり方は3通り。目的に応じて選ぶ。**

| 方法 | 向いているケース | 難易度 |
|---|---|---|
| **A. スクリュー + カーブ変形** | アドオンなしでやりたい／後から巻き数を調整したい | ★★☆ |
| **B. アドオン「Extra Curve Objects」** | とにかく早く作りたい | ★☆☆ |
| **C. Python スクリプト** | 数値で正確に作りたい／何度も作る | ★☆☆ |

---

## 大前提：トーラスそのものには巻きつけられない

**トーラスのメッシュを加工してコイルにするのではない。**
トーラスは「巻きつける相手」として置いておくだけで、**一切いじらない**。

やることは、**トーラスの芯を通る円（＝中心円）をレールとして取り出し、別に作ったバネをそのレールに沿わせる**こと。

```
    [トーラス]            ← 相手。加工しない（最後は隠してもいい）
        │
        │ 寸法から R（主半径）と r（副半径）を読む
        ▼
  [円カーブ（半径 R）]     ← コイルが走る「レール」＝ドーナツの芯を通る輪
        ▲
        │ カーブモディファイアで沿わせる
        │
  [断面の円 ＋ スクリュー]  ← まっすぐなバネ
        │
        ▼
  [トーラスに巻きついたコイル]  ✓
```

### トーラスの断面で見るとこうなっている

```
        横から見た断面

     ┌──── 副半径 r ────┐
  ───●━━━━━━━━━━━━━━●───   ← チューブ（トーラスの肉）
        ╲          ╱
         ╲    ×   ╱      ← この「×」が中心円の通る位置
          ╲______╱           ＝ コイルのレールが通るところ

  ├────────── 主半径 R ──────────┤
    （ワールド原点 → チューブの芯まで）
```

- **レールの半径 ＝ 主半径 R**（チューブの外側ではなく**芯**）
- **コイルの巻き半径 ＝ 副半径 r ＋ ワイヤーの半径**（トーラスの表面にちょうど乗る）

---

## ステップ0：今あるトーラスの R と r を調べる

### いちばん確実：作り直す

`Shift+A > メッシュ > トーラス` → **F9（redoパネル）** で
**主半径 = 1 / 副半径 = 0.25** のように自分で数値を入れる。
→ 以降の計算で迷わない。**おすすめはこれ。**

### 既にあるトーラスから逆算する

トーラスを選択して **`N`（サイドバー）> 寸法（Dimensions）** を見る。

```
X = Y = 2 × (R + r)
Z     = 2 × r
```

なので、

```
r（副半径） = Z ÷ 2
R（主半径） = X ÷ 2 − r
```

**デフォルトのトーラスなら X = Y = 2.5 / Z = 0.5** なので

```
r = 0.5 ÷ 2      = 0.25
R = 2.5 ÷ 2 − 0.25 = 1.0
```

> ※ オブジェクトモードでスケールをかけている場合は、先に `Ctrl+A > スケール` で適用してから読むこと。

---

## 方法A：スクリューモディファイア + カーブモディファイア

**考え方：まっすぐなバネを作り、それを円に沿わせて曲げる。**

### 手順1：ワイヤーの断面を作る

```
Shift+A > メッシュ > 円
F9（redoパネル）で   頂点 = 12 / 半径 = 0.02   ← ワイヤーの太さ
```

編集モードに入り（Tab）、`A` で全選択してから：

```
R X 90 Enter      ← 円を立てる（XZ平面に向ける）
G X 0.27 Enter    ← 巻き半径ぶん横にずらす（副半径0.25 + ワイヤー半径0.02）
```

Tab でオブジェクトモードに戻る。

### 手順2：スクリューモディファイアでバネにする

モディファイアプロパティ > 追加 > 生成 > **スクリュー**

| 項目 | 設定値 | 公式の説明 |
|---|---|---|
| **軸** | **Z** | らせんを作る方向 |
| **角度** | 360° | 1回転の角度 |
| **スクリュー** | **0.1047** | **らせん1回分の高さ**（＝ピッチ。6.283 ÷ 60巻き） |
| **反復（Iterations）** | **60** | **らせんの回転数**（＝巻き数） |
| **ステップ** | 16〜24 | 1回転の分割数（ビューポート） |
| **レンダーステップ** | 24〜32 | レンダー時の分割数 |

> **スクリュー × 反復 ＝ コイルの全長**になる。
> ここでは `0.1047 × 60 ≒ 6.283` で、中心円の円周とぴったり一致させている。**これが肝。**

### 手順3：沿わせる円カーブを作る

```
Shift+A > カーブ > 円
F9 で   半径 = 1     ← トーラスの主半径と同じ
```

位置はトーラスと同じ（両方ワールド原点）にしておく。

### 手順4：カーブモディファイアで曲げる

コイルのメッシュを選択 → モディファイア > 追加 > 変形 > **カーブ**

| 項目 | 設定値 |
|---|---|
| **カーブオブジェクト** | 手順3で作った円 |
| **変形軸** | **Z**（コイルがZ方向に伸びているため） |

### 位置合わせの注意（公式マニュアルより）

> カーブモディファイアは**グローバル空間で動作する**ので、ジオメトリとカーブの位置関係が結果を決める。
> **オブジェクトの原点をジオメトリの中心に**置き（「原点をジオメトリへ」）、
> **オブジェクトの原点をカーブオブジェクトの原点と同じ位置から始める**とよい。

> **カーブの端を超えた部分は、その端の方向のまま変形が続く。**
> → だから手順2で**全長を円周に合わせる**必要がある。
> ずれていたら「スクリュー」の値か「反復」を微調整して、巻きの端どうしがきれいに繋がるようにする。

## 方法B：アドオン「Extra Curve Objects」を使う（最速）

このアドオンのスパイラルには **Archimedean / Logarithmic / Spherical / Torus** の4種類があり、
**「Torus」がそのままトーラス状のらせん**を生成してくれる。

### インストール（4.2以降は拡張機能プラットフォームに移動している）

- **Blender 4.1 まで**：プリファレンス > アドオン で `Add Curve: Extra Objects` を有効化するだけ
- **Blender 4.2 LTS 以降（5.2 も含む）**：バンドルされていないので
  **プリファレンス > 拡張機能（Get Extensions）** で **「Extra Curve Objects」** を検索してインストール
  （または zip をダウンロードして「ディスクからインストール」／Blenderにドラッグ＆ドロップ）

### 使い方

```
Shift+A > カーブ > Extra Objects > Spirals > Torus
F9（redoパネル）で 巻き数・半径・分割数を調整
```

### 太さを付ける

カーブのままでは線なので、**カーブデータプロパティ > ジオメトリ > ベベル**：

```
形状 = 丸
深度 = 0.02        ← ワイヤーの太さ
解像度 = 4
```

## 方法C：Python スクリプトで数式から直接作る（最も正確）

トーラス上のらせんは数式で厳密に書ける。**スクリプトタブに貼って実行するだけ。**

### パラメトリック方程式

```
x = (R + r·cos(Nθ)) · cos θ
y = (R + r·cos(Nθ)) · sin θ
z =  r·sin(Nθ)

θ : 0 → 2π
R : トーラスの主半径
r : 巻きの半径
N : 巻き数（整数にすると端がぴったり閉じる）
```

この式の点は**必ずトーラス中心円から距離 r の位置**に来る（＝トーラス表面にぴったり乗る）ので、浮いたり埋まったりしない。

### スクリプト

```python
import bpy, math

# ===== パラメータ =====
R         = 1.0    # トーラスの主半径
r         = 0.27   # 巻きの半径（副半径0.25 + ワイヤー半径0.02）
N         = 60     # 巻き数（整数にすること）
steps     = 24     # 1巻きあたりの分割数
thickness = 0.02   # ワイヤーの太さ
name      = "ToroidalCoil"
# =====================

total = N * steps
pts = []
for i in range(total):
    t = 2 * math.pi * i / total
    a = N * t
    x = (R + r * math.cos(a)) * math.cos(t)
    y = (R + r * math.cos(a)) * math.sin(t)
    z = r * math.sin(a)
    pts.append((x, y, z))

cu = bpy.data.curves.new(name, 'CURVE')
cu.dimensions = '3D'
cu.bevel_depth = thickness
cu.bevel_resolution = 4
cu.use_fill_caps = True

sp = cu.splines.new('POLY')
sp.points.add(len(pts) - 1)
for i, (x, y, z) in enumerate(pts):
    sp.points[i].co = (x, y, z, 1.0)
sp.use_cyclic_u = True

ob = bpy.data.objects.new(name, cu)
bpy.context.collection.objects.link(ob)
bpy.context.view_layer.objects.active = ob
ob.select_set(True)
print("done:", total, "points")
```

### 使い方

```
1. 上部の「Scripting」タブを開く
2. 「新規」でテキストを作成し、上記を貼り付け
3. パラメータ（R / r / N / thickness）を自分のトーラスに合わせる
4. ▶ 実行（Alt+P）
```

メッシュにしたい場合は、生成後に **オブジェクト > 変換 > メッシュ**。

---

## 調整のコツ

| やりたいこと | 操作 |
|---|---|
| 巻きを細かくする | `N`（巻き数）を増やす。方法Aなら「反復」を増やし、「スクリュー」を `6.283 ÷ 反復` に合わせる |
| ワイヤーを太くする | 断面円の半径／ベベル深度／`thickness` を上げる |
| トーラスに密着させる | `r` ＝ **副半径 + ワイヤー半径** にする（0.25 + 0.02 = 0.27） |
| 巻きを浮かせる | `r` をもう少し大きく |
| コイルだけ見せる | トーラス本体を**目アイコン**で隠す（カメラアイコンで隠してもレンダーに影響しない点は別ノート参照） |

### 内側が詰まって見えるのは正常

輪の**内周は外周より短い**ので、均一に巻くと内側ほど巻きが密集する。
**実物のトロイダルコイルもまったく同じ見た目**になるので、これは不具合ではない。
