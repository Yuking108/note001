# サブディビジョンのショートカットとレベル設定（Ctrl+1〜5）

## ショートカット

オブジェクトモードで **`Ctrl+1` 〜 `Ctrl+5`**。

- サブディビジョンサーフェスモディファイアが**なければ追加**され、そのレベルが設定される
- **すでにある場合はレベルだけ変更**される（重複して追加されない）
- **`Ctrl+0`** でレベル0 = 実質オフ。モディファイア自体は残るので、あとで戻せる

モディファイアパネルを開かずに丸みを試せるので、形を詰めている最中に重宝する。

## 重要: 変わるのは「ビューポート」のレベルだけ

ここが誤解しやすいところ。

サブディビジョンモディファイアには**2つのレベル設定**がある。

| 設定 | 何に効くか |
| --- | --- |
| **ビューポート（Levels Viewport）** | 画面上の表示。`Ctrl+1〜5` が変えるのは**こちら** |
| **レンダー（Render）** | 実際のレンダリング結果 |

**`Ctrl+1〜5` ではレンダー側は変わらない。**

- ビューポートを1に落としても、**レンダー結果は設定されているレベル（新規追加時は2）のまま**
- 逆に、ビューポートで3にしてもレンダーが2なら、最終出力は2

最終的な品質を変えたいなら、**モディファイアパネルの「レンダー」欄を直接いじる**必要がある。

この分離は不便ではなく、**作業中は軽く、出力はきれいに**という使い分けのためにある。

### 定番の設定

| 用途 | ビューポート | レンダー |
| --- | --- | --- |
| 通常の作業 | 1 | 2 |
| 重いシーン | 0 | 2 |
| 最終確認 | 2 | 2〜3 |

## レベルを上げすぎない理由

**1レベルごとに面数が約4倍になる。**

| レベル | 元の面数に対する倍率 |
| --- | --- |
| 1 | 約4倍 |
| 2 | 約16倍 |
| 3 | 約64倍 |
| 4 | 約256倍 |

レベル3以上は、よほど大きく映るか曲率が極端でない限り**見た目の差が出ない**。にもかかわらずメモリとレンダリング時間だけが跳ね上がる。

**なめらかさが変わらないなら小さい数字を使う**という判断は正しい。多くの場合レンダー2で十分。

### 判断の目安

**シルエット（輪郭）で判断する。**

面の内側は陰影でごまかせるが、輪郭の角張りは隠せない。オブジェクトを画面に映る最大サイズで表示して、**外周のラインが角張って見えなければそのレベルで足りている**。

小さく映る物、遠景の物、ぼかしが掛かる物はさらに落としてよい。

## 併せてやること

### スムーズシェード

サブディビジョンだけでは面の境界が見えることがある。**オブジェクトモードで右クリック > スムーズシェード**を併用する。

### 最適表示（Optimal Display）

モディファイアのオプション。オンにすると、**ワイヤーフレーム表示で細分化された線を隠し、元のメッシュの線だけを表示**する。編集中に画面が線だらけにならないので、基本オンでよい。

### 細分化の種類

| 種類 | 内容 |
| --- | --- |
| **カトマル・クラーク（Catmull-Clark）** | 滑らかにする。通常はこちら |
| **シンプル（Simple）** | 形は変えずにポリゴンだけ増やす。ディスプレイスメントの下準備などに使う |

## 注意点

- **適用（Apply）は最後の最後。** 適用すると編集が非常に重くなり、元のきれいなトポロジーも失われる。基本はモディファイアのまま運用する
- サブディビジョンは**四角面を前提**に設計されている。三角形やN-gonが混ざると歪む。ブーリアンの直後などは要注意
- 角をシャープにしたいなら、レベルを上げるのではなく**サポートループかクリース**で対応する
