# オブジェクトを選択できないようにロックする

## 結論

**できる。アウトライナーの「選択を無効化」（矢印アイコン）がPhotoshopのロックに相当する。**

表示もレンダリングもされたまま、**ビューポートでクリックしても選択されなくなる。**

## 手順

矢印アイコンは**デフォルトでは表示されていない**ので、まず出す。

1. アウトライナー（右上のリスト）の**右上にあるフィルターアイコン（じょうご）**をクリック
2. **「制限の切り替え」**の並びにある**矢印（カーソル）アイコン**をオンにする
3. 各オブジェクトの行に矢印アイコンが追加される
4. ロックしたいオブジェクトの矢印をクリックしてオフにする

解除は同じ矢印をもう一度クリックするだけ。**この設定は .blend ファイルに保存される。**

## 他の「触らせない」方法との違い

Blenderには似たような機能が複数ある。**表示 / 選択 / レンダリング**の3つの軸で整理すると混乱しない。

| 操作 | ビューポート表示 | 選択 | レンダリング |
| --- | --- | --- | --- |
| **選択を無効化（矢印）** | される | **できない** | される |
| **非表示（目アイコン / `H`）** | されない | できない | **される** |
| **レンダー無効（カメラアイコン）** | される | できる | **されない** |
| **コレクションの除外（チェックボックス）** | されない | できない | されない |

**Photoshopのロックに一番近いのは「選択を無効化」。** 「見えているけど触れない」のはこれだけ。

### 使い分け

| やりたいこと | 使うもの |
| --- | --- |
| **見たままにして、誤クリックだけ防ぎたい** | **選択を無効化（矢印）** |
| 邪魔なので一時的に消したい | `H`（`Alt+H` で全部戻る） |
| ビューポートには出すが、レンダリングには出したくない | カメラアイコン |
| シーンから完全に外して軽くしたい | コレクションの除外 |

## 実務的なおすすめ: コレクション単位でロックする

オブジェクトを1つずつロックするより、**コレクションごとロックする**ほうが管理が楽。

```
背景セット      ← 選択を無効化
ライト          ← 選択を無効化
カメラ          ← 選択を無効化
作業中のモデル  ← ロックしない
```

**コレクションの行の矢印アイコンをオフにすると、中身すべてがまとめてロックされる。**

モデリングの途中で「床をうっかり動かしてしまった」「ライトを掴んでしまった」が激減する。シーンが複雑になるほど効く。

## 注意点

- **編集モードの中（頂点・辺・面）にはこの機能はない。** 編集モードで触りたくない部分は `H` で非表示にする（`Alt+H` で戻る）
- ロックしたオブジェクトも**モディファイアやコンストレイントの影響は受ける**。あくまで「手で選べない」だけ
- フィルターで矢印アイコンを非表示に戻すと、**ロック状態は残ったままアイコンだけ見えなくなる。** 「なぜか選択できないオブジェクトがある」ときは、まずフィルターで矢印を表示して確認する
