# UVに合わせた画像をマテリアルとして反映させる

## 大前提：UV Editorで画像を開いても、マテリアルにはならない

**UV Editor に表示している画像は「UV展開の参照用」**にすぎない。
実際にレンダリングされるのは**マテリアルのノード**で、**この2つは別物。自動では繋がらない。**

```
[UV Editor の画像]   ←→   [マテリアルの画像テクスチャ]
   UV合わせの見本            実際に描画されるもの
         ✗ 自動では連動しない ✗
```

→ **同じ画像を、マテリアル側でもう一度読み込む**必要がある。

---

## 手順

```
1. オブジェクトを選択
2. マテリアルプロパティ（赤い球アイコン）> 新規

3. 上部タブの「Shading」ワークスペースへ

4. Shift+A > テクスチャ > 画像テクスチャ

5. ノードの「開く」ボタンで、UV Editor で使ったのと同じ画像を読み込む

6. 画像テクスチャの「カラー」→ プリンシプルBSDF の「ベースカラー」へ接続

7. Z > マテリアルプレビュー で確認
```

---

## なぜUVが自動で効くのか

公式マニュアル（画像テクスチャノードの**ベクトル**入力）：

> 「**何も接続されていない場合、座標はオブジェクトのアクティブなUVマップから取られる（Z = 0）**」

→ **ベクトル入力には何も繋がなくていい。**
UV Editor で調整したUVが、そのまま使われる。

### 複数のUVマップがある場合だけ指定が必要

| 方法 | 手順 |
|---|---|
| アクティブを切り替える | オブジェクトデータプロパティ（緑の三角）> **UVマップ** で使いたいものを選択 |
| ノードで明示する | `Shift+A > 入力 > UVマップ` を追加 → **ベクトル**に接続 |

---

## 反映されないときのチェック

| 症状 | 原因・対処 |
|---|---|
| **何も変わらない** | ビューポートがソリッド表示。**`Z` > マテリアルプレビュー**（またはレンダー）へ |
| ソリッドのまま見たい | ビューポートシェーディング（右上の▼）> **カラー > テクスチャ** |
| **真っ黒／真っ白** | 「カラー」→「ベースカラー」に**繋がっていない**。ノードの線を確認 |
| **ずれる・伸びる** | UVが合っていない。UV Editorで展開を確認 |
| **一部の面だけ出ない** | **マテリアルスロットの割り当て漏れ**。編集モードで面を選択 > マテリアルプロパティ > **割り当て** |
| **色がおかしい** | **カラースペース**。色なら `sRGB`、ラフネス／法線／ディスプレイスメントは **`Non-Color`** |
| **画像が繰り返される** | **拡張（Extension）** の設定 |

### 拡張（Extension）の選択肢

> 「ベクトルが画像の範囲外に出たときの挙動を制御する。
> **リピート**（タイリング）／**延長**（端のピクセルを繰り返す）／**クリップ**（画像の外は透明）／**ミラー**（交互に反転）」

UVがはみ出していて繰り返したくないなら **クリップ** か **延長**。

---

## その他の設定（知っておくと便利）

### 投影（Projection）

> 「**フラット**：画像を単位正方形に置き、垂直に投影する。**通常はUVマップと併用**」
> 「**ボックス**：立方体の各面に投影（ブレンド設定あり）」
> 「**スフィア**：球に巻き付ける」
> 「**チューブ**：円筒に巻き付ける。**ボトルのラベルなどに向く**」

→ **UV展開したなら「フラット」のままでよい。**

### 補間（Interpolation）

> 「**リニア**（通常品質）／**キュービック**（より滑らか。**バンプマップに推奨**）／**クローゼスト**（最近傍。**ピクセルアートに向く**）／**スマート**（Cyclesのみ、OSL用）」

→ **ドット絵・ピクセルアートなら必ず「クローゼスト」**。そうしないとボケる。

### アルファ（透過画像の場合）

- 画像テクスチャの **「アルファ」出力 → プリンシプルBSDF の「アルファ」** に接続
- マテリアルプロパティ > **設定 > ブレンドモード** を調整（EEVEEの場合）

## 時短テクニック

| 方法 | 内容 |
|---|---|
| **ドラッグ＆ドロップ** | Shading ワークスペースで、画像ファイルをノードエディタに放り込むと画像テクスチャノードが作られる（※バージョンによって挙動が不安定なことがある） |
| **Node Wrangler** | アドオンを有効化 → プリンシプルBSDFを選択して **`Ctrl+Shift+T`** → カラー／ラフネス／法線などの**PBRテクスチャ一式を自動で読み込んで接続** |

---

## 覚え方

> **UV Editor ＝ 「どこに貼るか」を決める場所**
> **Shading（マテリアル）＝ 「何を貼るか」を決める場所**
>
> 両方そろって初めて画像が表示される。
