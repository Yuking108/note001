# 複数オブジェクトに同じマテリアルを一括で割り当てる（Ctrl+L）

## 手順

1. オブジェクトモードで、**割り当てたい側（マテリアルがまだ無いもの）を `Shift` を押しながら複数選択**
2. **最後に、コピー元になるオブジェクト（すでにマテリアルが付いているもの）を `Shift+クリック`**
3. **`Ctrl+L`** でリンク/転送データメニューを開く
4. **マテリアルをリンク** を選ぶ

これで選択したすべてのオブジェクトに、同じマテリアルが割り当たる。

## 最重要: 「最後に選んだもの」がコピー元

Blenderのこの手の操作はすべて**アクティブオブジェクト**が基準になる。

- **アクティブ** = 最後にクリックしたもの。**明るいオレンジの輪郭**で表示される
- それ以外の選択物は**暗いオレンジ（赤茶色）の輪郭**

コピー元とコピー先が逆だと、マテリアルが消えてしまう（無しの状態が転送される）ので注意。

### アクティブを選び直したいとき

選択をやり直す必要はない。**すでに選択されているオブジェクトを `Shift+クリック` すると、選択を保ったままそれがアクティブになる。**

（ただし、アクティブなオブジェクト自身を `Shift+クリック` すると選択が外れる）

アウトライナーでも、どれがアクティブかを確認できる。

## 「リンク」の意味 — 利点でもあり落とし穴でもある

`Ctrl+L` の「リンク」は**コピーではなく共有**。すべてのオブジェクトが**同じ1つのマテリアルデータを参照する**状態になる。

### 利点

- あとから色を変えると、**リンクしているオブジェクト全部に一度で反映される**
- 「金属パーツ全部の質感を一括で調整したい」といった場面で非常に強い
- ファイルも軽くなる

### 落とし穴

- **1つだけ色を変えたい、ができなくなる。** 1つ変えると全部変わる

### 1つだけ独立させたい場合

マテリアルプロパティのマテリアル名の横に、**使用者数（`2` や `3` などの数字ボタン）**が表示されている。これをクリックすると**単一化（Make Single User）**されて、そのオブジェクト専用のコピーになる。以降は独立して編集できる。

この数字は「今このマテリアルを何個のオブジェクトが使っているか」を示しているので、共有状態の確認にも使える。

## Ctrl+L で転送できる他のもの

マテリアル以外にもいろいろある。覚えておくと作業が速くなる。

| 項目 | 内容 |
| --- | --- |
| **オブジェクトデータをリンク** | メッシュそのものを共有。片方を編集すると両方変わる（リンク複製と同じ状態） |
| **マテリアルをリンク** | 本項目 |
| **モディファイアをコピー** | アクティブのモディファイア構成を他へコピー |
| **アニメーションデータをリンク** | キーフレームを共有 |
| **コレクションにリンク** | アクティブと同じコレクションに入れる |

右クリックメニューの **オブジェクト > リンク/転送データ** にも同じものがある。

## 他のやり方との比較

| 方法 | 向いている場面 |
| --- | --- |
| **`Ctrl+L` > マテリアルをリンク** | **複数オブジェクトに一括で。最速** |
| マテリアルプロパティのスロット横のドロップダウン（ブラウズ）から既存マテリアルを選ぶ | 1つだけ割り当てたいとき |
| 編集モードで面を選択して「割り当て」 | **1つのオブジェクトの中で**部分的に別マテリアルにしたいとき |

## 注意点

- 複数マテリアルスロットを持つオブジェクトに対しては、**スロット構成ごと置き換わる**。元の割り当てが消えるので、作り込んだオブジェクトに対しては慎重に
- 逆に、**コピー元が複数スロットを持っていればそれも含めて転送される**ので、スロット構成の複製にも使える
