# 押し出しの3種類を使い分ける

## 結論から

**`E` は「選択範囲をひとかたまりとして、平均法線方向へ」押し出す。** 円柱の側面のように向きがバラバラな面を**それぞれの方向へ**押し出したいときは、別の押し出しを使う必要がある。

## 3種類の押し出し

| 操作 | 挙動 | 円柱の側面を全選択した場合 |
| --- | --- | --- |
| **領域（`E`）** | 選択面を**1枚の板のように**まとめて、平均の法線方向へ移動 | 全方向の平均＝ほぼゼロなので、**何も起きないか潰れる** |
| **法線に沿って押し出し** | ひとかたまりのまま、各部分が**自分の法線方向**へ膨らむ。面は繋がったまま | **円柱が太くなる**（ソリッド化に近い） |
| **個別の面を押し出し** | 各面が**バラバラに**自分の法線方向へ。面と面の間に側面が新しく作られる | **各面が independently に飛び出す**（歯車・王冠のような形） |

「円柱の各面をそれぞれの方向に押し出す」なら **個別の面を押し出し**。

## 呼び出し方

### `Alt+E` が一番速い

右クリックメニューからでも出せるが、**`Alt+E` で押し出しメニューが直接開く**。ここから選ぶのが最短。

```
Alt+E →
  ├ 領域を押し出し
  ├ 法線に沿って押し出し
  ├ 個別の面を押し出し   ← これ
  ├ 多様体を押し出し
  └ カーソル方向に押し出し
```

### 他の呼び出し方

- **メッシュ > 押し出し** メニュー
- **右クリック（面コンテキストメニュー）**
- **ツールバー（`T`）の押し出しアイコンを長押し** → 「個別の面を押し出し」ツールに切り替え。ギズモをドラッグして操作できる

## 操作のコツ

### 距離を数値で指定する

押し出しを実行したあと、**左下のオペレーターパネル（`F9`）の「オフセット」**に数値を入力すると正確に決められる。マウスで決めるより再現性がある。

実行中にそのまま数値をタイプしてもよい。

### 間違えたときの判別

- **押しても何も起きない** → `E`（領域）を使っている。平均法線が打ち消し合っている
- **形が全体に膨らむだけ** → 「法線に沿って押し出し」になっている
- **面が離れてバラバラになる** → 「個別の面」で正解。これが狙いの挙動

## 似た関係にあるインセット

**インセット（`I`）**にも同じ区別がある。

- **`I`** … 選択範囲をひとまとまりとして内側に面を作る
- **`I` を2回** … **各面それぞれに**インセットが入る

押し出しと同じ考え方なので、セットで覚えると混乱しない。

## 注意点

- 「個別の面を押し出し」は**面と面の間に新しい側面を作る**ので、ポリゴン数が一気に増える
- 隣り合う面が離れるため、**サブディビジョンを掛けると形が崩れやすい**。使うならサポートループかクリースで押さえる
- 円柱の側面など曲率がある場所で大きく押し出すと、側面同士が交差することがある。オフセットは控えめに
