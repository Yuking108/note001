# エンプティでカメラを回す（親子付け + Track To）

## 目的

被写体の周りをカメラがぐるっと回る動きを、**キーフレーム2個だけ**で作る。あとから高さや距離を変えても、回転アニメーションが壊れないようにする。

## なぜ必要か

カメラを直接選んで `R` で回転させても、**カメラはその場で首を振るだけ**で、被写体の周りを回ってはくれない。

「公転」させるには、円を描く軌道のキーフレームを何十個も手で打つ必要がある。これは面倒なうえ、あとから半径を変えたくなったときに全部打ち直しになる。

そこで**回転の中心になる「軸」を別のオブジェクトとして用意する**。それがエンプティ。

### エンプティ（Empty）とは

位置と回転の情報だけを持つ、**レンダリングに一切映らない目印のオブジェクト**。実体がないので、中心軸や基準点として自由に使える。

### 仕組み

```
エンプティ（被写体の中心に配置）
  └─ カメラ（子）

エンプティをZ軸で360°回す
  → 子であるカメラが、エンプティを中心に円を描いて公転する
```

地球が太陽の周りを回るのと同じ。エンプティが太陽、カメラが地球。

## 手順

### 1. エンプティを被写体の中心に置く

1. 被写体を選択して `Shift+S` > **カーソル → 選択物**（3Dカーソルが被写体の中心に移動する）
2. `Shift+A` > **エンプティ** > **十字（プレーン軸）**

これで被写体の中心にエンプティができる。

### 2. カメラをエンプティの子にする

1. **カメラを先に選択**
2. `Shift` を押しながら**エンプティを選択**（あとから選んだほうが「親」になる）
3. `Ctrl+P` > **オブジェクト（トランスフォーム維持）**

アウトライナーでエンプティの下にカメラが入っていればOK。

### 3. カメラを被写体に向け続ける（Track To）

このままだとカメラは公転してもずっと同じ方向を向いたままで、被写体がフレームから外れる。

1. カメラを選択
2. プロパティパネルの**コンストレイント（鎖のアイコン）**タブ
3. **オブジェクトコンストレイントを追加** > **トラック** > **Track To**
4. **ターゲット**にエンプティ（または被写体そのもの）を指定

これでカメラが常にターゲットを向く。

> ターゲットを**被写体そのもの**にすると、被写体が動いたときもカメラが追いかける。中心を固定したいならエンプティを指定する。

### 4. 回転にキーを打つ

1. **エンプティを選択**（カメラではない）
2. フレーム1で `I` > **回転**
3. 最終フレーム（例: 120）へ移動
4. Nパネルの回転Zに **360** を入力して `I` > **回転**

### 5. 等速にする

そのままだと始めと終わりがゆっくりになる（イーズ）。一周ループさせたいなら等速に直す。

1. グラフエディター（またはドープシート）でキーを全選択
2. `T` > **リニア**

## ポイント

- **カメラの位置調整は、カメラを選んで動かすだけでよい**。エンプティからの距離＝軌道の半径、高さ＝見下ろす角度になる。回転アニメーションはエンプティ側に入っているので壊れない
- あとから「もう少し寄りたい」「もっと上から」と思ったら、カメラをずらすだけで済む。これが「軌道だけ差し替えられる」という意味
- エンプティのサイズは見た目だけの話で、結果に影響しない（`S` で見やすく調整してよい）

## 注意点

- 親子付けは**選択順が重要**。子 → 親 の順に選ぶ
- 「トランスフォーム維持」を選ばないと、カメラが原点に飛ぶことがある
- Track To を入れるとカメラの回転を手動で変えられなくなる。構図の微調整はエンプティの位置やカメラの距離で行う
- 傾き（ロール）がおかしいときは、Track To の **上方向（Up）** を `Y`、**追従軸** を `-Z` にする（デフォルト値）

## 応用

- エンプティをさらに別のエンプティの子にすると、公転＋上下動などを独立して管理できる
- カーブに沿わせたいなら Track To の代わりに **Follow Path コンストレイント**
- 被写体を回したい場合も同じ手順（被写体をエンプティの子にする）
