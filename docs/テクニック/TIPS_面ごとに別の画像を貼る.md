# 面ごとに別の画像を貼る

カードの表と裏で違う画像を貼りたい、のような「**1つのオブジェクトの面ごとに絵を変える**」作業の手順。

---

## 大前提：画像を「貼る」のはシェーダーエディター

⚠️ **ここが一番の勘違いポイント。**

> **UVエディターで画像を開いても、それだけではレンダリングに反映されない。**

公式マニュアルにも「UVに画像を当ててレンダリングしても、デフォルトではテクスチャは出てこない」と明記されている。役割は完全に別。

| どこ | 役割 |
| --- | --- |
| **シェーダーエディターの「画像テクスチャ」ノード** | **実際にレンダリングで使われる画像。これが本体** |
| **UVエディターの画像** | UVを合わせるための**表示用の下敷き**（ガイド） |

### 本体側のノード構成

```
テクスチャ座標（UV） → マッピング → 画像テクスチャ → プリンシプルBSDF（ベースカラー）
```

- **テクスチャ座標の「UV」出力**を使うことで、**UV展開の結果が反映される**
- マッピングは位置・回転・スケールの微調整用。無くても動くが、挟んでおくと後で貼り位置を直せる

---

## やり方は2通り

### A. マテリアルを分けて面に割り当てる（表裏なら、こっちが素直）

画像を2枚のまま扱えるので管理が楽。

1. マテリアルプロパティで**スロットを2つ**作る
2. それぞれに画像テクスチャノードで**別の画像**を設定
3. **編集モードに入る**
4. 面選択モード（`3`）で**表の面だけを選択**
5. マテリアルプロパティで表用スロットを選び、**「割り当て」**
6. 裏の面も同様に

→ UV展開は、各面のUVが画像の範囲（0〜1）に収まっていればよい。

### B. 1枚の画像に表裏を並べて、UVで貼り分ける（テクスチャアトラス）

マテリアル1つ・テクスチャ1枚で済むので軽い。枚数が増えるときはこちら。

1. 表と裏を**1枚の画像に並べて**作っておく
2. 編集モードで面を選択 → `U` → 展開 / **ビューから投影**
3. UVエディターで、その面のUVを画像の該当箇所に合わせる（`G` 移動 / `R` 回転 / `S` 拡縮）

→ このとき**UVエディターに表示する画像が「下敷き」として効いてくる**。位置合わせのために表示する、という位置づけ。

---

## UV展開の操作（共通）

編集モードで面を選択 → `U` でUVメニュー。

| モード | 使いどころ |
| --- | --- |
| **ビューから投影（Project from View）** | **平らなカードならこれが素直。** 正面から見た状態がそのまま投影される |
| 展開（Unwrap） | シームに沿って開く。基本 |
| スマートUV投影 | 自動でバラす。形が複雑なとき |
| キューブ／円筒／球状投影 | 形が単純な立体のとき |

### 守ること

- **必ず編集モードで、対象の面だけを選択してから**行う。オブジェクトモードのままでは面単位の操作にならない
- ワークスペースを **UV Editing** や **Shading** に切り替えると、UVエディターとシェーダーエディターが同時に見えて作業が速い

---

## つまずきやすいところ

| 症状 | 原因 |
| --- | --- |
| UVエディターで画像を開いたのにレンダリングに出ない | シェーダーエディターで画像テクスチャノードを繋いでいない（上記の大前提） |
| UV展開しても貼り位置が変わらない | 画像テクスチャの**ベクトル入力にUVが繋がっていない**。テクスチャ座標の「UV」から繋ぐ |
| 裏面の画像が鏡像になる | UVが反転している。UVエディターで `S` → `X` → `-1` |
| 面を選んで割り当てたのに変わらない | 編集モードではなくオブジェクトモードで操作していた／「割り当て」を押していない |
