# 曲がった角・板・反り屋根を作る

## 基本の手順（この流れで正しい）

```
1. Ctrl+A > スケール        ← 必ず最初に
2. ループカット（Ctrl+R）を複数入れる
3. シンプル変形モディファイア > ベンド
4. 必要ならエンプティを「原点」に指定
5. 軸と角度を調整
6. 足りない分は編集モードでプロポーショナル編集（O）で追い込む
```

以下、**各ステップがなぜ必要か**と、**ここから先に知っておくべきこと**。

---

## なぜスケール適用が必須なのか

公式マニュアルより：

> シンプル変形の**変形はローカル空間で計算される**。
> ローカル軸はグローバル軸と異なり得るため、**シーン内で回転したオブジェクトは自分自身の向きを基準に変形する**。

つまり：

- **ローカル座標で曲げた結果が、あとからオブジェクトのスケールで引き伸ばされる**
  → スケールが `1,1,1` でないと、曲がりが楕円に歪む
- **回転も同じ理屈**。意図しない軸で曲がるときは、回転が適用されていないことが多い

```
Ctrl+A > スケール        ← 最低限これ
Ctrl+A > 回転とスケール   ← 軸がおかしいならこちら
```

> ※ 「全トランスフォーム」は**位置も適用されて原点がワールド原点に飛ぶ**ので、ベンドの中心が変わってしまう。基本は使わない。

---

## なぜループカットが必要なのか

**曲げは頂点を動かすことでしか表現できない。辺が無いところは曲がらない。**

- 分割数 ＝ **曲がりの滑らかさ**
- 目安：**90°曲げるなら最低8〜12分割**、180°なら16〜24分割
- 分割が足りないと、曲がらずに「カクッ」と折れるか、**まったく変化しない**

---

## ベンドの「軸」でハマる理由（重要）

マニュアルの記述：

> ベンドの結果は**変形軸と曲げ軸の組み合わせ**に依存する。
> X または Y 変形は Z に沿って曲がり、Z 変形は X に沿って曲がる。
> **平らな平面を X または Y で変形しても変化が現れない**。すべての頂点の Z 座標が同じだからである。

### つまり

| 症状 | 原因 |
|---|---|
| 軸を変えても**何も起きない** | 曲げる方向に**厚み（座標の差）が無い** |
| 板をベンドしたいのに無反応 | 平面のまま。**ソリッド化で厚みを付ける**か、軸の組み合わせを変える |

→ 「軸を総当たりで試す」のではなく、**どの方向に座標の差があるか**を考えると一発で決まる。

---

## エンプティを「原点」にする意味

マニュアル：

> **Origin**：変形の原点と軸を設定する外部オブジェクト（通常はエンプティ）。
> **位置が原点を決め、回転が変形軸を決め、スケールが変形の係数を変える。**

**エンプティのスケールまで効く**のは見落としやすい。

| エンプティの操作 | 効果 |
|---|---|
| 移動 | 曲げの中心が動く（どこを支点に曲げるか） |
| 回転 | 曲げの軸が変わる（モディファイアの軸ボタンより自由） |
| **スケール** | **曲がりの強さが変わる** |

→ 支点を「屋根の軒先」や「柱の付け根」に置けるので、現実の曲がり方を再現しやすい。

---

## ★ 反り屋根の決め手：「制限（Limits）」

マニュアル：

> **Limits**：**変形軸に沿った範囲にモディファイアの影響を制限する**。
> 距離は**オブジェクトの原点から測られ**、上限は下限より低くできない。

**日本建築の反り屋根は「全体が曲がる」のではなく「先端だけ反る」。**
これを再現するのが Limits。

```
下限 = 0.6 / 上限 = 1.0   → 先端40%だけ反る
下限 = 0.0 / 上限 = 1.0   → 全体が均一に曲がる（既定）
```

角度を上げて全体を曲げるより、**角度は控えめ＋Limits で範囲を絞る**ほうが自然になる。

---

## ★ もう一段上の制御：頂点グループ

マニュアル：

> **Vertex Group**：**頂点の重みを使って、各頂点がどれだけ強く影響を受けるかを制御する**。

- Limits は「ここからここまで」という**ハッキリした境界**
- 頂点グループは**ウェイトペイントで連続的に**効きをコントロールできる

→ 「根元はまったく曲げず、中間からじわっと、先端で最大」といった**滑らかな反り**はこちら。

---

## シンプル変形の4モード

| モード | マニュアルの定義 | 用途 |
|---|---|---|
| **ベンド** | 選択した軸に沿ってメッシュを曲げる | 曲がった角、反り屋根、アーチ |
| **ねじれ（Twist）** | オブジェクト原点まわりに頂点を回転。**原点より下は負、上は正**に回転し、**原点の平面上の頂点は動かない** | ねじれた柱、ドリル、螺旋 |
| **テーパー** | 軸に沿って**原点からの距離に比例して**線形に拡大縮小。原点の平面では変化なし | 先細りの角、円錐状 |
| **ストレッチ** | 軸に沿って伸ばす。**正の値で伸びて原点が細くなり、負の値で潰れて原点が太くなる** | 弾性変形、スクワッシュ＆ストレッチ |

### ロック X/Y/Z の注意

> **ねじれ・テーパー・ストレッチでのみ利用可能。**

→ **ベンドでは使えない**。「ロックが出てこない」と悩む必要はない。

---

## モディファイアの順序で結果が変わる

| 順序 | 結果 |
|---|---|
| サブディビジョン → シンプル変形 | 先に滑らかにしてから曲げる。**きれいだが重い** |
| シンプル変形 → サブディビジョン | 曲げてから滑らかに。**軽いが角が丸まりやすい** |
| **ミラー → シンプル変形** | 左右**対称に**曲がる ← **屋根はこれ** |
| シンプル変形 → ミラー | 曲げた形を鏡像化。**左右で曲がりが逆向き**になる |

→ 「左右で反り方が違う」はこの順序ミスが原因。

---

## シンプル変形で無理なときの選択肢

| やりたいこと | 使うもの |
|---|---|
| **S字など自由な曲線**に沿わせたい | **カーブモディファイア** |
| **感覚的に滑らかなラインを作りたい** | **ラティス** ← 反り屋根の本命 |
| 既存の面（地形など）に貼り付けたい | **シュリンクラップ** |
| 球状・円筒状に寄せたい | **キャスト** |

### ラティスが反り屋根に向く理由（マニュアルより）

> - **頂点の多い密なメッシュの変形に向く**（直接編集するより速い）
> - **手でスカルプトするのが難しい滑らかな変形**を作れる
> - **1つのラティスを共有して複数オブジェクトをまとめて制御**できる
> - 元のジオメトリは無傷なので**非破壊**
> - **テクスチャ座標に影響しない**

屋根・瓦・棟・軒先を**まとめて同じラティスで反らせられる**のが決定的に強い。

### ラティスの使い方

```
Shift+A > ラティス
オブジェクトデータプロパティ > 解像度 U / V / W を 3〜5 に上げる
（屋根なら U=5, V=3, W=2 くらい）

対象メッシュを選択 > モディファイア > 変形 > ラティス
  オブジェクト = そのラティス

または：メッシュ → ラティスの順に選択 > Ctrl+P > ラティス変形
```

あとは**ラティスを編集モードで動かすだけ**でメッシュが追従する。
**ストレンジス（Strength）**で効き具合をブレンドできる。

## プロポーショナル編集を正しく使う

| 操作 | 内容 |
|---|---|
| **`O`** | 有効化／無効化。**オブジェクトモードでも使える**（オブジェクト単位で効く） |
| **`Alt+O`** | **接続のみ（Connected Only）** |
| **`Shift+O`** | フォールオフのパイメニュー |
| **変形中にマウスホイール / PageUp・PageDown** | **影響半径を変える** ← これを知らないと使えない |

### 接続のみ（Alt+O）

> 影響が**メッシュの辺のつながりに沿って**広がる。
> 手のモデルの**別の指のように、トポロジー的に繋がっていない近接ジオメトリは影響を受けない**。
> ※ **編集モードのみ**で利用可能

→ 重なっている別パーツを巻き込まずに済む。基本オンでよい。

### ビューから投影（Projected from View）

> 有効にすると、半径を適用する際に**視線方向の奥行きが無視される**。

→ 正面から見た形だけを整えたいときに使う。

### フォールオフの種類と使い分け

**一定 / ランダム / リニア / シャープ / ルート / 球状 / スムーズ / 逆二乗**

| 反りの表情 | フォールオフ |
|---|---|
| 自然でなだらかな反り | **スムーズ / 球状** |
| 先端だけキュッと鋭く | **シャープ** |
| 根元から急に立ち上がる | **ルート** |
| 直線的に持ち上げる | **リニア** |
| 岩肌・自然物のランダム感 | **ランダム** |

## よくある失敗と対処

| 症状 | 原因 | 対処 |
|---|---|---|
| 曲げても**何も起きない** | 分割が足りない／平らな面を X・Y でベンドしている | ループカットを増やす／軸の組み合わせを見直す |
| 曲がりが**楕円に歪む** | スケールが `1,1,1` でない | `Ctrl+A > スケール` |
| **変な位置を中心に**曲がる | 原点がずれている | 原点を移動、またはエンプティを Origin に指定 |
| 曲げすぎて**潰れる・自己交差する** | 角度が大きすぎる | 角度を下げて **Limits** で範囲を絞る |
| **左右で反りが違う** | ミラーとシンプル変形の**順序** | ミラーを先にする |
| 一部だけ曲げたいのに全体が曲がる | Limits 未設定 | **Limits** か**頂点グループ** |
| プロポーショナル編集で**関係ない所まで動く** | 接続のみがオフ | **`Alt+O`** |
