# 水のマテリアル（グラスBSDF）

## 設定値

マテリアルプロパティ > サーフェス を **グラスBSDF（Glass BSDF）** に変更し、以下を設定する。

| 項目 | 値 |
| --- | --- |
| **サーフェス** | グラスBSDF |
| **分布** | 複合散乱GGX（Multiscatter GGX） |
| **粗さ** | **0.2** |
| **IOR** | **1.33** |

## なぜその値なのか

### IOR 1.33 = 水の屈折率

**1.33 は水の実際の屈折率。** 物理的に決まっている定数なので、覚えてしまってよい。

**この値はソフトを問わず共通。** Blender でも Maya でも Cinema 4D でも Unreal でも、水を作るなら 1.33。IOR は現実の物性値なので、ソフトごとに違うということがない。

主要な素材の IOR:

| 素材 | IOR |
| --- | --- |
| 空気 | 1.0 |
| 氷 | 1.31 |
| **水** | **1.33** |
| プラスチック | 1.45〜1.55 |
| ガラス | 1.5 |
| ダイヤモンド | 2.42 |

### 粗さ 0.2 = さざ波の表現

- **0** … 完全な鏡面。風のない池、CG的に硬い印象になる
- **0.2** … **わずかに表面が乱れた水面。** 反射がほどよくぼやけて自然
- **0.4以上** … 荒れた水面、磨りガラスのような見え方

波の大きな形は**ジオメトリ（ディスプレイスメントやノイズ）**で作り、粗さは**それより細かい、モデリングでは表現できないミクロな凹凸**を担当する、という役割分担。

### 複合散乱GGX（Multiscatter GGX）

微細な凹凸の中で**光が複数回跳ね返ることを計算に入れる**方式。

通常の GGX は1回しか跳ね返りを考えないため、**粗さが高いときにエネルギーが失われて暗くなる**。複合散乱GGX はこれを補正するので、ざらついた水面でも暗くならず自然に見える。

粗さを上げる素材では基本的にこちらを選んでよい。その代わり計算は少し重い。

## 注意点

### Cycles 前提

**グラスBSDF が正しく屈折するのは Cycles。** EEVEE では光の経路を追わないため、そのままでは背景が透けて見えるだけで、屈折表現にならない。

EEVEE で使うなら、マテリアル設定で**レイトレース／スクリーンスペース屈折**を有効にする必要がある（それでも Cycles ほど正確にはならない）。

### 水に色を付けたいとき

**グラスBSDF の「カラー」で色を付けるのは避ける。**

カラーで青くすると、**薄いところも深いところも同じ濃さ**になってしまい、水らしくない。

正しくは **ボリューム > ボリュームの吸収（Volume Absorption）** を使う。これなら**厚い（深い）ところほど濃く色づく**ので、浅瀬は透明、深いところは濃い青、という現実の見え方になる。

### 厚みのあるメッシュにする

屈折は「物体に入って、出る」計算なので、**面1枚だと正しく屈折しない。** 水槽の水やコップの水は、厚みのある閉じた立体にする。

（海面や湖面のように「無限に広い水面」を表現する場合は平面1枚でも成立する。この手順の ICO球 のようなケースでは、球そのものが厚みを持っている）

### プリンシプルBSDFでも同じことができる

グラスBSDF の代わりに、**プリンシプルBSDF の「伝播（Transmission）」を 1.0、IOR を 1.33、粗さを 0.2** にしても同等の結果になる。

| 使い分け | |
| --- | --- |
| **グラスBSDF** | 透過だけを扱う。設定がシンプルで分かりやすい |
| **プリンシプルBSDF** | 他の要素（泡、汚れ、金属部分など）と混ぜたいとき |
