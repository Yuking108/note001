# バンプノードの効果

## ひとことで

**高さ情報（グレースケール）から、ライティング用の法線を偽造するノード。**

実際の凹凸を作るのではなく、**「光の当たり方だけ」を凹凸があるかのように変える**。

## 何をしているか

- 高さテクスチャを読み、シェーディング点とその近傍の高さを見て、**摂動を加えた法線**を生成する
- その法線をプリンシプルBSDFの「ノーマル」入力に渡すと、陰影が変わって凹凸に見える
- **実際のジオメトリは一切変わらない。** 面は平らなまま、ライティングの計算だけが変わる

```
高さ（グレースケール） → バンプ → 法線 → プリンシプルBSDFのノーマル入力
                                    ↑ 面は平らなまま、陰影だけ変わる
```

## 入力の意味

| 入力 | 役割 |
| --- | --- |
| **高さ（Height）** | グレースケール値。**明るい＝高い、暗い＝低い** |
| **強さ（Strength）** | 効果の強度。0で無効、1でフル適用 |
| **距離（Distance）** | 高さ値の**倍率**。凹凸の深さ全体をスケールする |
| **法線（Normal）** | 計算の元になる法線。他のバンプやノーマルマップと重ねるときに使う |
| **反転（Invert）** | 凹凸を逆にする。出っぱりが凹む |

### 強さと距離の使い分け

どちらも「強く見せる」効果だが、**距離が高さの実寸スケール、強さが最終的な混ぜ具合**。まず距離で凹凸の深さを決め、強さで馴染ませる、という順が分かりやすい。

## 限界（ここが本質）

ジオメトリが変わらないので、

- **シルエット（輪郭）には出ない。** 真横から見ると平らなのがバレる
- 深い凹凸や、影の落ち方まで変えたい場合には向かない

→ **浅い凹凸向き**。紙の繊維、皮のシボ、金属のヘアライン、印刷インクの微かな盛り、など。

本当に形を変えたいなら**ディスプレイスメント**（実際にメッシュを変形させる）を使う。

## バンプとノーマルマップの違い

| | バンプ | ノーマルマップ |
| --- | --- | --- |
| 入力 | **高さ**（グレースケール1枚） | **法線そのもの**（RGBの青紫の画像） |
| 計算 | 高さから法線を**計算する** | 記録された法線を**そのまま使う** |
| 作りやすさ | 手持ちの画像を流用しやすい | 専用に焼く必要がある |

どちらも「ジオメトリは変わらない」点は同じ。

## 実例メモ（カードのマテリアル）

カードのカラー画像をそのまま「高さ」に入れて、**距離 0.001 / 強さ 1.0**。印刷のインクの微かな盛りを表現する使い方で、**絵柄の明暗がそのまま微細な凹凸になる**。距離が小さいのは、紙の印刷程度の浅さを狙っているため。

> ⚠️ 厳密には、高さに使う画像の色空間は **非カラー（Non-Color）** が正しい。カラー用のsRGB画像を流用するのは手軽さ優先のショートカットで、意図した明暗と実際の高さがずれる。見た目が合っていれば実用上は問題ないが、狙いどおりにならないときはここを疑う。
