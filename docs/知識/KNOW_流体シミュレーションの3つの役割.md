# 流体シミュレーションの3つの役割

Blenderの流体シミュレーション（Mantaflow）は、**オブジェクトに「役割」を割り当てて組み立てる**。物理演算プロパティ > 流体 > タイプ から、`なし / ドメイン / フロー / エフェクター` を選ぶ。

つまり「流体シミュレーションという機能」があるのではなく、**役割を与えられたオブジェクト同士の関係**でシミュレーションが成立する。

## いちばん短いたとえ

| 役割 | たとえ | ひとことで |
| --- | --- | --- |
| **ドメイン** | 水槽 | 計算する**範囲** |
| **フロー** | 蛇口 | 流体を**出すもの** |
| **エフェクター** | 障害物 | 流体が**ぶつかるもの** |

```
 ┌──────── ドメイン（この箱の中だけが計算される）────────┐
 │                                                      │
 │      ● フロー（ここから水が湧く）                     │
 │           ↓                                          │
 │      ▭▭▭ エフェクター（ここでぶつかる・溜まる）        │
 │                                                      │
 └──────────────────────────────────────────────────────┘
      ※ フローもエフェクターも、ドメインの中に入っていないと無視される
```

---

## 1. ドメイン（Domain）＝ 水槽

**シミュレーションが計算される範囲そのもの。** この箱の内側でしか流体は計算されず、外に出た流体は消える。

- **ドメインタイプ** … `ガス`（煙・炎）/ `液体`（水）。**初期値はガス**なので、水をやるなら必ず変更する
- **解像度（Resolution Divisions）** … 箱を何分割して計算するか。上げるほどディテールが出るが、急激に重くなる
- 計算結果は**キャッシュ**に保存される（＝ベイク）

### 実用上のポイント

ドメインは**流体が通る範囲ギリギリまで小さく**する。無駄に大きいと、同じ解像度でも1マスあたりが大きくなるため、**ディテールが落ちたうえに重い**という一番損な状態になる。

---

## 2. フロー（Flow）＝ 蛇口

**流体を発生させるもの。**

- **フロータイプ** … `煙 / 炎 / 煙+炎 / 液体`。**初期値は煙**。ここも水なら変更が必要
- **フローの挙動（Flow Behavior）** … 3種類あり、性格がまったく違う

| 挙動 | 動作 |
| --- | --- |
| **流入口（Inflow）** | 蛇口。止めるまで流体を出し続ける |
| **流出口（Outflow）** | 排水口。入ってきた流体を消す |
| **ジオメトリ（Geometry）** | **オブジェクトの形がそのまま最初から液体になる**。一塊の水を落としたいとき |

### 「オブジェクトの形は関係ない」の正確なところ

⚠️ **挙動によって答えが変わる**ので、ここは分けて覚える。

- **流入口なら、ほぼ正しい** … 球でも立方体でも「そこから水が湧く」だけ。**凝った蛇口をモデリングする必要はない**。フロー用オブジェクト自体は絵に出さない（レンダリングでは非表示にする）のが普通なので、見た目も問われない
- **ジオメトリなら、大いに関係する** … オブジェクトの形がそのまま液体の初期形状になる
- 厳密には流入口でも、**流体はメッシュの表面から発生する**ので、**大きさと位置は結果に効く**。また法線の向きが初速の方向に影響する（初速を一方向に揃えたいなら法線を揃える必要がある）
- 「表面からの発生距離（Surface Emission）」は、メッシュ表面から何ボクセル分の範囲で流体を発生させるかの設定。**0だと発生範囲が実質ゼロ**になる

---

## 3. エフェクター（Effector）＝ 障害物

**流体とぶつかるもの。**

> **設定しないと、流体はそのオブジェクトを素通りする。** シミュレーターから見て、エフェクターでないオブジェクトは**存在しないのと同じ**扱いになる。

コップ・ボトル・床・壁など、流体を受け止めたいものには必ず設定する。「コップに水が注がれず、床を突き抜けていく」の原因はたいていこれ。

- **エフェクタータイプ**

| タイプ | 動作 |
| --- | --- |
| **コリジョン（Collision）** | ぶつかって流れを堰き止める。通常はこれ |
| **ガイド（Guide）** | オブジェクトの**速度**で流体の流れを誘導する。**動いていないと効かない** |

- **表面の厚さ（Surface Thickness）** … 衝突判定を外側に膨らませる。薄いメッシュで流体が漏れるときに上げる
- **平面（Is Planar）** … 平面や閉じていないメッシュに使うフラグ。閉じたメッシュでも、内部の体積から流体が湧くのを防ぐために使える

---

## 忘れやすい前提

1. **フローもエフェクターも、ドメインの内側に入っていないと無視される**
2. **初期値はガス／煙**。液体をやるならドメインタイプとフロータイプの両方を変更する
3. **設定しただけでは動かない。ベイクが必要**（→ [[Q&A_流体シミュレーションで液体が出ない]]）
