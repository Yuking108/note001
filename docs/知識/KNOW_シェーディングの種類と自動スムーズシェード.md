# シェーディングの種類と自動スムーズシェード

## 大前提: スムーズシェードは「元に戻せる」

**スムーズシェードは完全に可逆。** 形状は一切変わらない。

スムーズシェードがやっているのは、**面の陰影をどう計算するかの切り替えだけ**。頂点も面も1つも動かない。見た目が丸く見えるのは、法線（光の当たり方の基準）を隣の面と繋がっているように補間しているから。**実際の形はカクカクのまま。**

戻し方:

> オブジェクトモードで**右クリック > フラットシェード（Shade Flat）**

これで一発で戻る。ベベルやブーリアンのような「適用したら戻せない」操作とはまったく別物。

### よくある誤解の元

「適用」という言葉の印象で破壊的な操作に思えるが、スムーズシェードに「適用」は存在しない。単なる**状態の切り替え**。

## 3つのシェーディング

オブジェクトモードで右クリックすると出てくる。

| 種類 | 内容 | 向いているもの |
| --- | --- | --- |
| **フラットシェード** | すべての面をカクカクに。**デフォルト** | 低ポリ、メカ、本当に平面で構成された物 |
| **スムーズシェード** | **すべての面**を滑らかに | 球、円柱の側面など、全面が曲面のもの |
| **自動スムーズシェード** | **角度で自動的に使い分ける** | **実物のほとんど。箱・製品・ベベル済みの形** |

### 自動スムーズシェードの中身

**しきい値の角度（デフォルト30°）より緩やかな角は滑らかに、鋭い角はシャープのまま**にする。

円柱なら、側面はなめらかに繋がり、天面との境目はエッジが立つ。これが自然な見え方になる。

**「とりあえず全部スムーズにしたら角まで溶けて変になった」の解決策がこれ。**

## 自動スムーズシェードがモディファイアとして出る理由

**Blender 4.1 で仕様が変わった。**

- **4.0 まで**: メッシュのプロパティに「自動スムーズ」というチェックボックスと角度設定があった
- **4.1 以降**: そのチェックボックスは廃止され、**「スムーズ・バイ・アングル（Smooth by Angle）」というジオメトリノードのモディファイア**として実装された

だからモディファイアスタックに現れる。

### 利点

- **角度をいつでも変えられる**（モディファイアの値を触るだけ）
- **削除すれば効果が消える**（非破壊）
- 他のモディファイアとの**順番を変えられる**

## 重要な注意点: モディファイアを削除しても「フラット」には戻らない

**「自動スムーズシェード」は2つのことを同時にやっている。**

```
自動スムーズシェード =
  ① メッシュ全体をスムーズシェードにする
  ＋
  ② 「スムーズ・バイ・アングル」モディファイアを追加する
```

そのため、**モディファイアだけを削除すると「全部スムーズ」の状態が残る。**

完全にフラットへ戻すには、モディファイアを消したうえで**右クリック > フラットシェード**も実行する。

## 使い分けの基準は「可逆かどうか」ではない

質問の核心: **3つとも可逆なので、戻せるかどうかは判断基準にならない。**

本当の基準は「**どの角を滑らかにしたいか**」。

| 作りたいもの | 選ぶもの |
| --- | --- |
| 球、玉、完全な曲面 | スムーズシェード |
| 角のある製品・箱・ベベルを入れた形 | **自動スムーズシェード** |
| 低ポリ、意図的にカクカクさせたい | フラットシェード |

迷ったら**自動スムーズシェード**でよい。角度しきい値で結果を調整できるので、融通が効く。

## もうひとつの方法: シャープをマーク

**角を手動で指定したい**場合に使う。

1. スムーズシェードを適用
2. 編集モードで、立たせたい辺を選択
3. **辺 > シャープをマーク**

角度では拾いきれない「ここだけは角を立てたい」という場所を、1本ずつ指定できる。自動スムーズシェードと併用もできる。
