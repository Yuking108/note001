# オブジェクトの原点（オレンジの点）

## 結論: 重心ではない。「原点（Object Origin）」

公式マニュアルの定義:

> **「各オブジェクトには原点がある。この点の位置が、オブジェクトが3D空間のどこにあるかを決める」**
> （Each object has an origin point. The location of this point determines where the object is located in 3D space.）

オブジェクトを選択したときに表示される小さなオレンジの円が、これ。

**重心（Center of Mass）とは別物。**

### 重心ではない証拠

Blenderには **オブジェクト > 原点を設定 > 「原点を重心に移動」** という**専用のメニューが別に用意されている。**

わざわざ「重心へ移動させる」操作が存在するということは、**普段の原点は重心ではない**ということ。初期状態の原点は、単に「オブジェクトを作ったときに3Dカーソルがあった場所」でしかない。

## 原点が決めているもの

原点はただの飾りではなく、**5つのことの基準**になっている。

| 役割 | 内容 |
| --- | --- |
| **オブジェクトの位置** | `N` パネルの「位置 XYZ」は、**原点の座標**を表示している |
| **回転の中心** | `R` で回したときに中心になる点 |
| **スケールの中心** | `S` で拡大縮小したときの基準点 |
| **親子付けの基準** | 子オブジェクトは親の原点を基準に動く |
| **モディファイアの基準** | ミラーの対称面、アレイのオフセットは原点が基準 |

だから原点の位置は「どこでもいい」わけではなく、**そのオブジェクトをどう動かしたいかで決まる。**

- ドアを開閉させたい → 原点は**蝶番の位置**
- 床に置く家具 → 原点は**底面の中心**
- その場で回転させたい → 原点は**ジオメトリの中心**

## 原点を動かす2つの考え方

ここが混乱しやすいポイント。「原点とメッシュの相対位置を変える」には**2通りのやり方**があり、**結果が違う。**

### A. 原点だけを動かす（メッシュはその場）

**オブジェクトモード**で **オブジェクト > 原点を設定 > ...**

メッシュはワールド座標上で1ミリも動かない。原点だけが移動する。

### B. メッシュだけを動かす（原点はその場）

**編集モード**に入って `A` で全選択 → `G` で移動。

原点は置き去りで、メッシュだけが動く。

> **質問にあった手順はこちら（Bの編集モード）。**
> **オブジェクトモードで `A` → `G` をすると、原点も一緒に動く**（オブジェクト全体が移動するだけで、相対位置は変わらない）。原点が動かずメッシュだけ動いたなら、それは編集モードに入っていたということ。

### 違いの整理

| | 動くもの | ワールド座標でのメッシュの位置 |
| --- | --- | --- |
| **A. 原点を設定（オブジェクトモード）** | 原点 | **変わらない** |
| **B. `A` → `G`（編集モード）** | メッシュ | **変わる** |
| 参考: `A` → `G`（オブジェクトモード） | 原点とメッシュの両方 | 変わる（相対位置は不変） |

**形を今の場所に置いたまま原点だけ直したいなら A。** B は形ごと移動してしまうので、位置が決まっているシーンでは使えない。

## 「原点を設定」メニューの全項目

オブジェクトモードで **オブジェクト > 原点を設定**。

| 項目 | 動くもの | 内容 |
| --- | --- | --- |
| **ジオメトリを原点へ移動** | メッシュ | 原点の位置へメッシュが飛んでくる |
| **原点をジオメトリへ移動** | 原点 | 原点がメッシュの中心へ寄る |
| **原点を3Dカーソルへ移動** | 原点 | 原点が3Dカーソルの位置へ |
| **原点を重心に移動（サーフェス）** | 原点 | 表面積の分布から求めた重心へ |
| **原点を重心に移動（ボリューム）** | 原点 | 密度が均一と仮定した体積の重心へ |

名前が似ている上2つは**動くものが逆**なので、ここが最大の注意点。

### 「中心」オプション（原点をジオメトリへ移動 の下位設定）

実行後の左下パネル（`F9`）で切り替えられる。

| 中心の種類 | 計算方法 |
| --- | --- |
| **中点（Median Point）** | 全頂点の平均位置。**頂点が密集している側に引っ張られる** |
| **バウンディングボックス** | 外接する箱の中心。頂点の密度に影響されない |

## 「中心」「重心」「原点」は全部別物

混同しやすい3つを整理する。

| 用語 | 意味 | 求め方 |
| --- | --- | --- |
| **原点（Origin）** | Blenderがオブジェクトの位置として扱う基準点。**任意に置ける** | 手動 / メニュー |
| **ジオメトリの中心** | 頂点の平均、または外接箱の中心 | 原点をジオメトリへ移動 |
| **重心（Center of Mass）** | 質量の中心。物理的な量 | 原点を重心に移動 |

**細長い三角形**を想像すると分かりやすい。バウンディングボックスの中心、頂点の平均、重心は、どれも違う場所になる。

## 原点が見えないとき

ビューポート右上の**オーバーレイ**（2つの円が重なったアイコン）の `v` を開き、

- **原点** … 選択中のオブジェクトの原点を表示
- **原点（すべて）** … すべてのオブジェクトの原点を表示

## 確認方法

`N` パネルの**「位置」**が原点のワールド座標。原点を動かすとこの数値が変わり、メッシュだけを動かしてもこの数値は変わらない。
