# ブーリアンモディファイア

## ひとことで

**2つの立体の「重なり」を計算して、1つの形を作るモディファイア。**

切る・くっつける・重なりだけ残す、の3種類の演算がある。粘土を削る道具ではなく、**集合演算**（数学の「引き算・足し算・共通部分」）をメッシュでやるもの。

## 一番大事な考え方: 「面」ではなく「体積」を計算している

ここを理解すると、失敗の理由がほぼ全部わかる。

ブーリアンは**閉じた立体同士の体積演算**。「この面とこの面を削る」ではなく「この立体の内側にある部分を取り除く」という処理。だから:

- **平面（Plane）では切れない。** 厚みのない面には「内側」が存在しないため
- **穴の開いたメッシュは失敗する。** どこが内側か判定できない
- **面の向き（法線）が裏返っていると失敗する。** 内側と外側が逆に解釈される

「閉じていて、向きが揃っている立体」が大前提。

## 3つの演算

| 演算 | 内容 | 用途 |
| --- | --- | --- |
| **差分（Difference）** | 自分から相手の体積を**引く** | 穴をあける、削る。**圧倒的に使用頻度が高い** |
| **和集合（Union）** | 合体して1つの外殻にする | 複数パーツを1つの立体に |
| **交差（Intersect）** | **重なっている部分だけ**残す | 型抜き、交差断面の取り出し |

## 基本の手順

1. **切られる側（本体）を選択**する
   - ここが肝心。モディファイアは**本体側に付ける**
2. モディファイアプロパティ（レンチアイコン）> **追加 > 生成 > ブーリアン**
3. 演算を **差分** にする
4. **オブジェクト** 欄に「切り抜く側」のオブジェクトを指定（スポイトか一覧から）
5. 切り抜く側を**非表示**にする
   - アウトライナーの**目のアイコン**をオフ（ビューポートから消える）
   - レンダリングにも出したくないなら**カメラのアイコン**もオフ
6. 結果が確定したら、モディファイアのドロップダウン > **適用**

### 切り抜く側をワイヤーフレーム表示にしておくと便利

完全に非表示にすると位置調整ができないので、消す代わりに:

オブジェクトプロパティ > **ビューポート表示** > 表示方法を **ワイヤーフレーム** にする。

輪郭だけが見えるので、穴の位置を見ながら動かせる。

## モディファイアであることの価値

**適用するまで元の形は壊れていない。** これが編集モードで直接穴をあけるのとの決定的な違い。

- 切り抜く側のオブジェクトを**動かせば穴の位置も動く**
- 大きさを変えれば穴のサイズも変わる
- モディファイアを削除すれば元通り
- 納得いくまで何度でもやり直せる

逆に言うと、**適用するまでは切り抜く側のオブジェクトを消してはいけない**。消すとブーリアンが成立しなくなる。

## ソルバー（計算方式）

モディファイア内の「ソルバー」で切り替えられる。

| ソルバー | 性質 |
| --- | --- |
| **完全（Exact）** | 正確。重なった面や自己交差にも比較的強い。デフォルト。重い |
| **高速（Fast）** | 速いが結果が不安定。プレビューや大量処理向け |
| **マニフォールド（Manifold）** | 比較的新しいバージョンで追加。高速かつ堅牢だが、**入力が完全に閉じた多様体メッシュであること**が前提 |

迷ったら**完全（Exact）**でよい。うまくいかないときに他を試す。

## よくある失敗と対処

### 1. 何も起きない / 結果がぐちゃぐちゃ

**メッシュが閉じていないか、法線が乱れている。**

編集モードで:
- `A` で全選択 → `M` > **距離でマージ**（重複頂点を削除）
- `A` で全選択 → **メッシュ > ノーマル > 再計算（`Shift+N`）**
- オーバーレイの「**面の向き**」をオンにして、赤い面（裏返り）がないか確認

### 2. 面がぴったり重なっていると不安定

切り抜く側の面と本体の面が**同一平面上（面一）**にあると、どちらが内側か判定できず破綻しやすい。

→ **切り抜く側を少しはみ出させる。** 貫通穴なら、相手より確実に長くしておく。

### 3. スケールが適用されていない

`Ctrl+A` > **全トランスフォーム**。ベベルと同じく、スケールが1でないと計算がおかしくなる。

### 4. トポロジーが三角形だらけになる

**これは仕様。** ブーリアンはきれいな四角面を保証しない。

- サブディビジョンサーフェスとは相性が悪い（歪む）
- 後処理が必要な場合は、編集モードで **X > 限定的溶解（Limited Dissolve）** で不要な辺を整理する
- 陰影だけ整えたいなら **ウェイト法線（Weighted Normal）モディファイア**を後ろに追加

### 5. 切り口がシャープすぎる

ブーリアンの**後ろ**にベベルモディファイアを追加し、**制限方法を「角度」**にする。切り口だけに丸みが付く。

**モディファイアの順番が結果を変える**ので、ブーリアンが先、ベベルが後。

## コレクション指定

「オブジェクト」の代わりに**コレクション**を指定できる。

切り抜き用のオブジェクトを1つのコレクションにまとめておけば、**ブーリアンモディファイア1つで全部まとめて処理**できる。穴がたくさんある形では圧倒的に管理が楽。

## 適用前のバックアップ

適用すると元に戻せない。心配なら:

- `Shift+D` > `Esc` でオブジェクトを複製し、複製側を非表示にしておく
- あるいは適用せず、モディファイアのまま運用する（レンダリングは問題なくできる）
