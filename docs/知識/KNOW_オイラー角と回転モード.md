# オイラー角と回転モード（XYZ / クォータニオン）

## ひとことで

**オイラー角 = 3つの軸まわりの回転を「決まった順番で」適用して向きを表す方式。**

「XYZオイラー」「ZYXオイラー」などのモード名は、**どの順番で適用するかの宣言**。順番が違えば結果も違う。これが「設定によって回転方向が変わる」正体。

## なぜ順番で結果が変わるのか

**回転は掛け算の順序を入れ替えられない（非可換）**から。

手元の本やスマホで試すと一発で分かる:

- パターンA: X軸に90°倒す → その後 Z軸に90°回す
- パターンB: Z軸に90°回す → その後 X軸に90°倒す

**同じ角度なのに、まったく別の向きになる。** 移動（平行移動）は順番を変えても同じ場所に着くが、回転は着かない。だから3Dソフトは「順番」を明示する必要がある。

## Blenderでの実際の挙動

Blenderの「XYZオイラー」は **X → Y → Z の順に適用**される。ここから実用的なルールが出てくる。

| 位置 | XYZの場合 | 性質 |
| --- | --- | --- |
| 最後の軸 | Z | **常に親（ワールド）の軸のまま効く。** 他の回転に影響されない |
| 中間の軸 | Y | ジンバルロックの原因になる軸 |
| 最初の軸 | X | **他の回転に引きずられる。** 見た目の軸がどんどんズレる |

「Zを動かすと素直なのに、Xを動かすと変な方向に回る」と感じるのはこれが理由。

### 覚え方

**一番大きく／頻繁に回したい軸を、リストの最後に置く。**

例えばカメラ。Blenderのカメラは初期状態で真下を向いているので `X = 90°` で水平になる。この状態で XYZオイラーなら:

- `Z` = 左右のパン（ワールドの垂直軸まわり。地面に対して水平に振れる）
- `X` = 上下のチルト

これがカメラにとって自然な操作になるので、XYZのままでよい。

## ジンバルロック

**中間の軸（XYZなら Y）が ±90° になると、1番目と3番目の回転軸が重なって自由度が1つ失われる現象。**

こうなると:

- 2つのスライダーが同じ動きをしてしまい、特定の方向に回せなくなる
- アニメーションの補間が暴れる（急にぐるっと回る）

静止した向きを決めるだけなら実害は少ないが、**アニメーションさせると致命的**になる。

## 4つの回転モード

Nパネル（または オブジェクトプロパティ > 回転）の「回転モード」で切り替えられる。**切り替えても見た目の向きは変わらない**（内部で変換される）。

| モード | 中身 | 向いている用途 |
| --- | --- | --- |
| **XYZオイラー**（と並び替え6種） | 3軸の角度 + 適用順 | 数値が読める。単軸の回転。ほとんどの場面 |
| **クォータニオン（WXYZ）** | 4つの数値 | **ジンバルロックが起きない。** 補間が最短経路で滑らか。多軸の複雑な回転、ボーン |
| **軸角度（Axis Angle）** | 回転軸ベクトル + 角度 | 「この軸で何度」と決まっている場合 |

### クォータニオンの弱点

数値を見ても人間には意味が分からない。「45°回したい」を手入力できない。なので**アニメーション向き、手動調整には不向き**。

## 実務的な結論

1. **単軸で回すだけ**（ターンテーブル、ドアの開閉など）→ **オイラーのままで何も問題ない。** Zだけ動かす
2. **多軸を同時にアニメーション**させる → **クォータニオンに切り替える**
3. **モードは後から変更できる**。キーフレームを打つ前に決めておくのが安全

## 一番おすすめの回避策: エンプティで分解する

そもそも**1つのオブジェクトに複数軸の回転を持たせない**のが最強。

```
エンプティA（Z回転だけ担当）
  └─ エンプティB（X回転だけ担当）
        └─ オブジェクト
```

こうすると、各エンプティは1軸しか回らないので**順序問題もジンバルロックも原理的に起きない**。しかもあとから「Z回転だけ速くする」といった調整が独立してできる。

カメラワークで Empty を使うテクニックと同じ考え方。

## 操作面のコツ（Rキー）

| 操作 | 意味 |
| --- | --- |
| `R` → `Z` → `45` | **ワールド**のZ軸まわりに45° |
| `R` → `Z` `Z` （2回） | **ローカル**のZ軸まわり |
| `R` → `X` `X` | ローカルX軸まわり |

「思った方向に回らない」ときは、ワールド軸とローカル軸を取り違えていることも多い。軸キーを2回押すとローカルに切り替わる。

ヘッダーの**トランスフォーム座標系**を「ローカル」にしておくと、ギズモもローカル軸で表示されるので分かりやすくなる。
