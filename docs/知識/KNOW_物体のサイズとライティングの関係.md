# 物体のサイズとライティングの関係

> **きっかけ**：何も見ずに制作したとき、「物体が小さいのにライトを近くに置くと白飛びする」ことに気づいた。
> 物体サイズ・ライトのパワー・距離の関係を整理する。

---

## 結論：覚えるのは「3つの比」だけ

ライティングは**絶対値ではなく比率で決まる**。この3つを押さえれば、どんなサイズの物体でも同じ手順で寄せられる。

| # | 比 | 決まるもの | 式 |
|---|---|---|---|
| 1 | **パワー ÷ 距離²** | 明るさ（量） | `明るさ ∝ パワー ÷ 距離²` |
| 2 | **ライトのサイズ ÷ 距離** | 影のやわらかさ（質） | 比が大きいほどソフト |
| 3 | **距離 ÷ 物体サイズ** | 物体内の明暗差 | 比が小さいほど片側だけ白飛び |

**物体サイズそのものは明るさに直接関係しない。**
効いているのは「物体サイズに対して**どれだけ近い**か」＝ 比 3 → それが比 1 の距離を小さくする → 二乗で明るくなる → 白飛び。

---

## 関係図

```
                    ┌─────────────────────────┐
                    │   物体サイズ  L         │
                    └───────────┬─────────────┘
                                │ L が小さいと
                                │ 自然と距離 d も小さくなる
                                ▼
   ライトのサイズ S ──┐   ┌──────────────┐   ┌── パワー P
                      │   │   距離  d    │   │
                      ▼   └──────┬───────┘   ▼
                  ┌────────┐     │     ┌──────────────┐
                  │  S / d │     │     │  P / d²      │
                  │ 影の   │     │     │  明るさ      │
                  │ やわら │     │     │              │
                  │ かさ   │     │     │ ← 二乗で効く │
                  └────────┘     │     └──────────────┘
                                 ▼
                          ┌─────────────┐
                          │   d / L     │
                          │ 物体内の    │
                          │ 明暗差      │
                          └─────────────┘
```

---

## 1. 明るさの式（逆二乗則）

```
明るさ（照度） ∝ パワー ÷ 距離²
```

- 距離が **1/2** → 明るさ **4倍**
- 距離が **1/10** → 明るさ **100倍**
- 距離が **2倍** → 明るさ **1/4**

マニュアルの定義（Blender 公式）：

> **Power**（ポイント／スポット／エリア）: *"Power of the light in Watts. Higher values increase the intensity of the light."*
> **Sun の Strength**: *"Strength of the lights in Watts per square meter."*

→ ポイント／スポット／エリアは **W（総放射パワー）**なので距離で薄まる。
→ Sun は **W/m²（その場所に届く量そのもの）**なので**距離は一切関係しない**。

---

## 2. スケール不変の法則（いちばん重要）

**シーン全体を k 倍すると、同じ見た目にするにはパワーを k² 倍にする必要がある。**

距離が `d → k·d` になるので

```
P / (k·d)²  =  (P / k²) / d²     ← k² 分だけ暗くなる
∴ 必要なパワー = 元のパワー × k²
```

| シーンの大きさ | 必要なパワー | 同じパワーのままだと |
|---|---|---|
| 1/10 倍 | ×0.01 | **100倍明るい（＝白飛び）** |
| 1/5 倍 | ×0.04 | 25倍明るい |
| 1/2 倍 | ×0.25 | 4倍明るい |
| 等倍 | ×1 | — |
| 2倍 | ×4 | 1/4 の明るさ |
| 5倍 | ×25 | 1/25 の明るさ |
| 10倍 | ×100 | 1/100 の明るさ（真っ暗） |

### チュートリアルの「2000W」が合わない理由

チュートリアルは**人間スケール（物体 1〜2 m、ライト 5〜10 m）**で作られている。
自分のシーンが 1/10 のサイズ（物体 20 cm、ライト 1 m）だと、同じ 2000 W は **約100倍明るい** → 当然白飛びする。

→ 関連：[[Q&A_ライトのパワーが昔の数値と合わない]]

---

## 3. 距離 ÷ 物体サイズ → 物体内の明暗差

ライトが物体に近いと、**手前の面と奥の面で距離が大きく違う**ので、1つの物体の中で明るさが激変する。

```
明暗差 = ((d + L) / d)²
   d = ライトから手前の面までの距離
   L = 物体の奥行き
```

| d / L | 手前と奥の明るさ比 | 見た目 |
|---|---|---|
| 0.5 | **9倍** | 手前だけ白飛び、奥は真っ暗 |
| 1 | **4倍** | かなり強いグラデーション |
| 2 | 2.25倍 | 立体感が出て良い範囲 |
| 3 | 1.78倍 | 自然 |
| 5 | 1.44倍 | ほぼ均一 |
| 10 | 1.21倍 | 均一（平板に見えがち） |

**実用の目安：ライトは物体サイズの 2〜5 倍の距離に置く。**
近すぎると白飛び＋のっぺり、遠すぎると立体感が消える。

---

## 4. ライトのサイズ ÷ 距離 → 影のやわらかさ

影のやわらかさは、**物体から見たライトの「見かけの大きさ（角度）」**で決まる。
→ 1 m のエリアライトを 1 m に置く ＝ 10 m のライトを 10 m に置く（同じやわらかさ）。

| サイズ ÷ 距離 | 影 | 例え |
|---|---|---|
| 〜0.05 | カチッと硬い影 | 晴天の太陽、裸電球 |
| 0.1〜0.3 | 自然なやわらかさ | 窓明かり、ソフトボックス |
| 0.5〜1.0 | かなりソフト | 大型ディフューザー |
| 2.0〜 | 影がほぼ消える | 曇天、ライトボックスの中 |

### 注意：エリアライトのサイズを変えても「総パワー」は変わらない

Power は**ランプ全体が出す総ワット数**なので、サイズを大きくしても総量は同じ。
変わるのは **①影のやわらかさ ②ハイライトの大きさ ③単位面積あたりの明るさ（＝ライト自体の見た目の明るさ）**。

ただし**ライトが物体に極端に近い場合**は、サイズを大きくすると「壁のような面光源」になり、物体に届く量が実質増えて明るく見えることがある。
→ サイズをいじったら明るさは必ず再確認する。

---

## 5. 距離が関係しないライト

| 種類 | 単位 | 距離の影響 | サイズの影響 |
|---|---|---|---|
| ポイント／スポット／エリア | W | **逆二乗で効く** | 影のやわらかさ |
| **Sun（サン）** | W/m² | **なし** | Angle が影のやわらかさ（既定 0.526° ＝実際の太陽） |
| **World / HDRI** | 係数 | **なし** | — |

→ **スケールに悩まされたくないなら Sun と World を主役にする**のが一番安全。
小物の撮影でも、Sun ＋ World だけならシーンを縮小しても露出が崩れない。

---

## 6. 実用：パワーの開始値（経験式）

```
開始パワー（W） ≈ 20 × 距離（m）²
```

Blender のデフォルトシーン（原点から約 7 m のポイントライト ＝ 1000 W）と概ね一致する目安。

| ライトまでの距離 | 開始パワー |
|---|---|
| 0.1 m | **0.2 W** |
| 0.2 m | 0.8 W |
| 0.5 m | 5 W |
| 1 m | **20 W** |
| 2 m | 80 W |
| 3 m | 180 W |
| 5 m | 500 W |
| 7 m | **1000 W** |
| 10 m | 2000 W |
| 20 m | 8000 W |

※ エリアライトは面積が大きいと体感がやや暗くなるので 1.5〜2 倍から試す。
※ あとは **露出（Exposure）** で微調整（`+1 = 2倍`、`-1 = 1/2`）。

## 7. 実寸の基準表（これを守ればライティングで迷わない）

| 対象 | 実寸 |
|---|---|
| Blender のデフォルト立方体 | 2 m |
| 人（身長） | 1.7 m |
| ドア | 0.9 × 2.0 m |
| 机 | 1.2 × 0.7 × 0.72 m |
| A4 用紙 | 0.21 × 0.297 m |
| スマホ | 0.07 × 0.15 m |
| マグカップ | 0.09 m |
| 1 円玉 | 0.02 m |

**最初に実寸でモデリングしておけば、ライトのパワーはチュートリアルの値がそのまま使える。**
これが白飛び対策としては最も効く。

---

## 8. 白飛びしたときのチェック順

1. **物体の実寸を確認**（N キー → 寸法）。小さすぎないか？
2. **ライトまでの距離を確認**。物体サイズの 2〜5 倍になっているか？
3. **`20 × 距離²` と比べる**。桁がずれていないか？
4. **ビュー変換を確認**。4.0 以降は **AgX** が既定（Filmic より白飛びしにくい）。
5. **露出（Exposure）で詰める**。
6. それでも破綻するなら **シーン全体をスケールアップ**して実寸に合わせる。
