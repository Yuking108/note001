# スペキュラーとIOR（プリンシプルBSDF）

## ひとことで

**スペキュラーは「正面から見たときに、その表面がどれだけ光を跳ね返すか」の値。**

金属以外の素材（プラスチック、木、布、肌、ガラスなど＝**誘電体**）の反射の強さを決める。

## 計算の中身

```
正面から見たときの反射率 = スペキュラー値 × 0.08
```

| スペキュラー | 正面の反射率 | 相当するIOR | 実際の素材 |
| --- | --- | --- | --- |
| 0 | 0% | — | 反射しない（非現実的） |
| **0.5（デフォルト）** | **4%** | **約1.5** | **ガラス、プラスチック、ほとんどの素材** |
| 1.0 | 8% | 約1.8 | 現実にはあまりない高さ |

**現実の誘電体はほぼすべて「正面で約4%反射」する。** ガラスも木も肌も、真正面から見たときの反射率は意外と似ている。だから**デフォルトの 0.5 が現実の大半をカバーしていて、基本はいじらなくてよい。**

「鏡のような反射」に見えるのは、正面ではなく**浅い角度から見たとき**。どんな素材でも視線が浅くなるほど反射が強くなる（フレネル効果）。この挙動は自動で計算されるので、スペキュラーで操作するものではない。

## Blender 4.0 以降の名前と構成

4.0 でプリンシプルBSDFが整理され、名前と役割が変わった。

| 項目 | 内容 |
| --- | --- |
| **IOR（屈折率）** | **こちらが主役。** デフォルト 1.5。反射の強さと、透過時の屈折の両方を決める |
| **スペキュラー IOR レベル** | 旧「スペキュラー」。デフォルト 0.5 = **IOR の計算どおり**。ここを動かすと IOR と矛盾した非物理的な値になる |
| **スペキュラーチント** | 正面の反射に色を付ける |

**4.x では、素材の反射を変えたいならまず IOR を触るのが正しい。** スペキュラーIORレベルは「物理を無視してでも反射を弱めたい/強めたい」ときの逃げ道。

### 素材別の IOR の目安

| 素材 | IOR |
| --- | --- |
| 空気 | 1.0 |
| 氷 | 1.31 |
| 水 | 1.33 |
| プラスチック全般 | 1.45〜1.55 |
| ガラス | 1.5 |
| サファイア | 1.77 |
| ダイヤモンド | 2.42 |

## 金属では無視される

**メタリックを 1.0 にすると、スペキュラーの値は（ほぼ）効かなくなる。**

金属の反射は**ベースカラー**が決める。金色の金属を作るならベースカラーを金色にする。金属にスペキュラーをいじっても意味がない。

| メタリック | 反射の色を決めるもの |
| --- | --- |
| 0（非金属） | 白（無彩色）の反射。強さはIOR / スペキュラー |
| 1（金属） | **ベースカラー**の色で反射する |

## よくある混同: 「粗さ」とは別物

ハイライトまわりで混同されやすい2つ。

| 項目 | 何を変えるか |
| --- | --- |
| **スペキュラー / IOR** | 反射の**強さ**（どれだけ跳ね返すか） |
| **粗さ（Roughness）** | 反射の**ぼやけ具合**（鏡かマットか） |

- ハイライトが**白く小さく鋭い** → 粗さが低い
- ハイライトが**広くぼんやり** → 粗さが高い

**「テカりすぎるから抑えたい」のほとんどは、スペキュラーではなく粗さを上げるのが正解。** スペキュラーを下げると、素材そのものが非現実的になる（光を跳ね返さない物体になる）。

## 実用的な使いどころ

スペキュラー（IORレベル）をデフォルトから動かす場面は少ないが、以下は実用的。

| 場面 | 操作 |
| --- | --- |
| 布・起毛素材・つや消しの紙 | わずかに下げる（0.3〜0.4） |
| 濡れた表面・ニス塗り | IOR を上げる、または少し上げる |
| 完全にマットな板（撮影用の黒ケント紙など） | 下げる＋粗さを上げる |
| アニメ調で反射を消したい | 0 にする（非物理的だが意図的） |

**迷ったらデフォルトの 0.5（IOR 1.5）のままにして、粗さとベースカラーで調整する。** これが最も現実に近く、破綻しない。
