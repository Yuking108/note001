# Q. 辺（面）を削除したあとに残る緑の線って何ですか？

## A. 辺に付いた「マーク（エッジデータ）」の表示色

Blenderの辺には、**形とは別に属性（マーク）を持たせる**ことができ、
編集モードではそれぞれ**違う色**で表示される。

### 既定テーマでの色の一覧

| マーク | 色 | 用途 |
|---|---|---|
| **シーム（Seam）** | **赤** | 「選択した辺を**UVシーム**として設定／解除する」 |
| **シャープ（Sharp）** | **シアン（水色〜青緑）** | 「選択した辺を**シャープ**として設定／解除する」 |
| **クリース（Crease）** | **紫（マゼンタ）** | サブディビジョンサーフェスでの折り目の強さ |
| **ベベルウェイト** | **黄** | ベベルモディファイアの重み |
| **フリースタイルの辺マーク** | **緑** | 「選択した辺を**Freestyleのラインが必要**なものとしてマーク／解除する」 |

> ※ 色はテーマで決まる（プリファレンス > テーマ > 3Dビューポート）。マニュアルには色の記載はない。

→ **はっきり緑なら「フリースタイルの辺マーク」**
→ **青みがかった緑（水色）なら「シャープ」**

---

## なぜ削除したら出てきたのか

**マークは「辺」が持っている属性**であって、面の属性ではない。

```
面があったとき  →  辺がメッシュの内側にあり、周囲の辺に埋もれて目立たない
面を削除        →  その辺が「境界」になり、シルエット上に出てきて見えるようになった
```

つまり**新しく発生したのではなく、元からあったものが見えるようになっただけ**。
特に「シャープ」は、**スムーズ・バイ・アングル**や**辺分離モディファイア**を使うと自動的に付くことがある。

---

## 確実な特定方法

ビューポート右上の **オーバーレイのポップオーバー（重なった2つの円の ▼）** を開き、
**メッシュ編集モード**の項目を**1つずつオフ**にする。

```
シーム / シャープ / クリース / ベベル / フリースタイルの辺マーク
```

> **Seams**：「UV展開のシームを表示する」
> **Sharp**：「**辺分離モディファイアで使われる**シャープな辺を表示する」
> **Creases**：「**サブディビジョンサーフェスモディファイア用**にクリースが設定された辺を表示する」
> **Bevel**：「**ベベルモディファイア用**に作られたウェイトを表示する」
> **Freestyle Edge Marks**：「Freestyleの辺マークを表示する」

**消えた項目が正体。**

---

## 消し方

編集モードで該当の辺を選択 → **辺（Edge）メニュー**から。

| 消したいもの | 操作 |
|---|---|
| **フリースタイル** | 辺 > **フリースタイルの辺をクリア** |
| **シャープ** | 辺 > **シャープをクリア** |
| **シーム** | 辺 > **シームをクリア** |
| **クリース** | **`Shift+E`** → `-1` と入力（またはサイドバーで0に） |
| **ベベルウェイト** | 辺 > **辺のベベルウェイト** → 0 |

> **Edge Crease**：「選択した辺のクリース量を**インタラクティブに変更する**」ショートカット **Shift-E**。
> 「**正または負の数値を入力して現在の値に加算**することもできる」／サイドバーでも編集可能。

全部まとめて消したいなら、`A` で全選択してから各クリアを実行する。

---

## 注意：オブジェクトモードでは表示されない

これらのマークは**編集モードのオーバーレイ**なので、**オブジェクトモードでは出ない**。

もしオブジェクトモードで緑の線が見えているなら、別の可能性：

| 候補 | 確認方法 |
|---|---|
| 別のオブジェクトが選択されている（アウトライン） | アウトライナーで何が選択されているか見る |
| **グリッドのY軸（緑）**がオブジェクトと重なっている | 視点を回すと線が動かない／オブジェクトから外れる |
| 面を消して残った**浮いた辺** | `選択 > すべてを選択（特徴）> 緩いジオメトリ` で検出 → `X > 辺` |

> **Loose Geometry**：「選択モードに応じて、**どの辺にも属さない頂点**／**どの面にも属さない辺**／**他の面と辺を共有しない面**を選択する」

## ★ 解決（2026-10-21 実際のケース）

> **頂点を削除したときに、辺か頂点が取り残されている場合に出ていた。**
> **その残った辺／頂点を削除すれば消える。**

**この認識で合っている。** しかも**なぜ残るのか**まで仕様で説明がつく。

### 原因：削除メニューの選択肢によって「残るもの」が違う

公式マニュアルの定義（メッシュ > 削除）：

| 選択肢 | 何が消えるか | 孤立要素は？ |
|---|---|---|
| **頂点** | 「選択した頂点と、**それが属する辺と面も**削除する」 | 残らない |
| **辺** | 「選択した辺と、**それが属する面も**削除する」 | 「**孤立した頂点も削除される**」 |
| **面** | 「選択した面を削除する」 | 「**孤立した頂点と辺も削除される**」 |
| **辺と面のみ** | 「選択した辺と面、および**選択した辺を含む未選択の面**も削除する」 | 「**孤立した頂点は残される**」 |
| **面のみ** | 「選択した面を削除する」 | 「**孤立した頂点と辺は残される**」 |

→ **「面のみ」「辺と面のみ」は、孤立要素を“わざと残す”仕様。**
骨組み（辺）だけ残して作り直したいときのための選択肢であって、
**普通に消したいなら `X > 頂点` か `X > 面` を使う。**

### 残ってしまった孤立要素をまとめて消す

```
メッシュ > クリーンアップ > 孤立要素を削除（Delete Loose）
```

> 「**何にも繋がっていない**、選択した頂点・辺（およびオプションで面）を削除する」

先に選択して確認したいなら：

```
選択 > すべてを選択（特徴）> 緩いジオメトリ
→ 光ったものが孤立要素
→ X > 頂点
```

> **Loose Geometry**：「選択モードに応じて、**どの辺にも属さない頂点**／**どの面にも属さない辺**／**他の面と辺を共有しない面**を選択する」

### 重なって二重になっている場合

位置が同じ頂点が2つある（重複）なら、孤立ではないので上の方法では取れない。

```
A（全選択）> M > 距離で結合
```

> **Merge by Distance**：「**一定距離より近い頂点のクラスタをそれぞれ結合する**」

左下の「Removed N vertices」で、いくつ消えたか確認できる。

### 切り分けの手順（これで確実）

```
1. メッシュ > クリーンアップ > 孤立要素を削除
     ├ 緑線が消えた  → 孤立ジオメトリだった ✅（今回のケース）
     └ 消えない      → ↓

2. A > M > 距離で結合
     ├ 消えた        → 重複頂点だった
     └ 消えない      → ↓

3. 残っているのは「マーク付きの辺」
     → 辺メニューから シャープ／フリースタイル／シームをクリア
       （このページ上部の表を参照）
```

### 補足（ここだけ注意）

「削除すれば消える」で**ほぼ常に合っている**が、**例外がひとつ**ある。

**孤立要素を消しても緑線が残る場合**、それは孤立ジオメトリではなく
**面に囲まれた“生きている辺”にマークが付いている**ケース。
この場合は削除してはいけない（形が壊れる）ので、**マークをクリアする**のが正解。

→ **まず「孤立要素を削除」を試し、消えなければマークを疑う**、という順番で見ること。
