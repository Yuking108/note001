# Q. モデリング中に出るこのガビガビは何？スケール適用しても直らない

## A. 結論：Zファイティング（深度バッファの競合）

**同じ場所に2つの面が重なっていて、どちらを手前に描くかGPUが決められない**状態。
その結果、市松模様・縞模様・チラつきとして見える。

**スケールの適用（Ctrl+A）では直らない。**メッシュの構造か、ビューの設定の問題だから。

### 見分け方

**視点を少し動かしてみる。**
→ 模様が**這うように変化する／チラつく**なら、ほぼ確実にZファイティング。

原因は大きく2系統：

| 系統 | 原因 | 直し方 |
|---|---|---|
| **A. メッシュ側** | 面が二重になっている／内部に余計な面がある | 重複を削除する ← **大半はこれ** |
| **B. ビュー側** | クリッピング範囲が広すぎて深度の精度が足りない | 範囲の開始／終了を調整 |

---

## 系統A：メッシュが二重になっている（最有力）

### よくある発生原因

| 操作 | 何が起きるか |
|---|---|
| **`E`（押し出し）してすぐ右クリック／Esc** | **移動はキャンセルされるが、面は複製されたまま**元の位置に残る ← **断トツで多い** |
| `Shift+D`（複製）して右クリック | 同じ位置にまるごと複製が残る |
| ミラーモディファイアで**クリッピングなし**、中央が重なっている | 中央で両側の面が重複 |
| **ソリッド化モディファイアの厚み = 0** | 表と裏が同じ位置に |
| **配列モディファイアのオフセット = 0** | コピーが全部同じ位置に積み重なる |
| ブーリアンの切断面が**元の面とぴったり同一平面** | 2枚が同じ平面に乗る |

### 診断1：重複頂点を結合してみる

編集モードで：

```
A        ← 全選択
M        ← マージメニュー
> 距離で結合
```

> 公式マニュアル：**Merge by Distance** = 「*一定距離より近い頂点のクラスタをそれぞれ結合する*」
> オプション **結合距離（Merge Distance）**＝「*この距離より近い頂点が結合される*」

実行後、**左下に「Removed N vertices」と出たらビンゴ**。それが原因だった。
`0` なら重複頂点は無い（＝面だけが重なっているか、系統Bの可能性）。

### 診断2：内部の面を探す

```
選択 > すべてを選択（特徴） > 内側の面
```

> 公式マニュアル：**Interior Faces** = 「*メッシュの表面ではなく、誤って内部に作られてしまった可能性のある面を選択する*」
> （1つの辺を複数の面が共有しているような、異常な隣接を持つ面を見つける）

何か選択されたら、`X > 面` で削除する。

### 診断3：面数を数える

```
オーバーレイ（右上のプルダウン）> 統計
```

ただの直方体なら **面は6枚**のはず。倍になっていたら二重。

---

## 系統B：クリッピング範囲が広すぎる

`N`（サイドバー）> **ビュー** タブ > **範囲の開始 / 終了（Clip Start / End）**

公式マニュアルの警告：

> 「*広いクリッピング範囲は近くと遠くの両方を見られるようにするが、**深度の精度が落ち、アーティファクトが発生する***」
> 「*非常に広い範囲では、深度バッファに依存する処理が不安定になることがある（グラフィックカードとドライバによる）*」

### 直し方（公式の推奨）

> - 大きなシーンでは**開始（近クリップ）の値を上げる**
> - **遠くから見ないオブジェクトでは終了（遠クリップ）を下げる**
> - 平行投影（透視投影オフ）では**終了の値だけが効く**ので、極端に大きい値はやはりアーティファクトを生む

今回のように**10cm程度の小さいオブジェクト**を扱っているなら：

```
範囲の開始 = 0.001 〜 0.01 m
範囲の終了 = 10 〜 100 m     ← 既定の 1000 m から下げるのが効く
```

> ※ これはBlender固有の問題ではなく、**OpenGL / DirectX のアプリ全般に共通する制限**。

---

## どうしても面を同一平面に置きたい場合

デカールやシールのように**わざと面を重ねる**必要があるときは、**ほんの少しだけ浮かせる**。

```
0.0005 〜 0.001 m ほど法線方向にオフセットする
```

完全に同じ平面にある限り、Zファイティングは原理的に避けられない。

## チェック順まとめ

```
1. 視点を動かして模様が這うか確認 → Zファイティング確定

2. 編集モード > A > M > 距離で結合
   └ 「Removed N vertices」が出たら解決                  → 系統A

3. 選択 > すべてを選択（特徴）> 内側の面 → X > 面        → 系統A

4. モディファイアを確認
   （ミラーのクリッピング／ソリッド化の厚み0／配列のオフセット0）→ 系統A

5. N > ビュー > 範囲の終了 を 1000 → 100 に下げる         → 系統B

6. わざと重ねている面なら 0.001m 浮かせる
```
