# Q. テンキー1を押した後に5を押さないと真横を向かない。そういうもの？

## A. いいえ。デフォルトなら `1` だけで平行投影の正面になる

「自動パース（Auto Perspective）」という設定がオフになっているのが原因。デフォルトはオンなので、本来は `テンキー1` を押すだけで**フロント・平行投影**になる。

### 2つのキーの役割

| キー | 役割 |
| --- | --- |
| テンキー 1 / 3 / 7 | 視点の**向き**を変える（正面 / 右 / トップ） |
| テンキー 5 | **透視投影 ⇄ 平行投影**の切り替え |

向きと投影方式は別物。`1` はあくまで向きを変えるだけなので、透視投影のままだと「真横から見ているのに奥行きがついて斜めに見える」状態になる。

### 直し方

1. 編集 > プリファレンス
2. **視点の操作（Navigation）**
3. 「視点の回転・パン」の中の **自動パース（Auto Perspective）** にチェックを入れる

これで `テンキー1 / 3 / 7` を押したときに自動で平行投影へ切り替わり、逆に視点をドラッグで回すと自動で透視投影に戻る。

### 今どちらか確認する方法

3Dビューポート**左上のテキスト**に出ている。

- `ユーザー・透視投影` … 自由視点 + 透視投影
- `フロント・平行投影` … 正面 + 平行投影 ← これが狙いの状態

### 補足

- 視点を少しでもドラッグで回すと透視投影に戻るのは、自動パースがオンでも正常な動作
- ノートPCでテンキーがない場合は、プリファレンス > 入力 の「**テンキーを模倣**」をオンにすると上段の数字キーで代用できる（ただし数字キーのコレクション表示切り替えが使えなくなる）
- モデリングで正確に作業したいときは平行投影、見た目を確認したいときは透視投影、と使い分ける
