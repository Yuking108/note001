# Q. スムーズシェードをかけるタイミングは？最後（完成後）でもいい？

解説動画では制作の途中でかけていることが多いが、決まったタイミングがあるのか、いつでもいいのかが分からない。

## A. いつでもいい。最後にかけてもまったく問題ない

スムーズシェード（Shade Smooth）は**形状を一切変えない「見た目の設定」**。面ごとに「滑らかに表示する」フラグを立てているだけなので、

- ジオメトリは変化しない
- 何度でも切り替えられる（Shade Flat で戻せる）
- 後からかけても結果は同じ

つまり「この工程の前にやらないと壊れる」という順序の縛りはない。完成後にまとめてかけるのが一番シンプル。

## なぜ動画では途中でかけているのか

**形のチェックのため**。フラットシェードだと面の境目が全部見えてしまい、面の流れの歪みや潰れが分かりにくい。スムーズにすると、

- 陰影のムラ
- ピンチ（つまみ）やヨレ
- シルエットの気持ち悪さ

が一気に見えるようになる。だから「モデリング中の検品ツール」として早めにかけている。順序のルールではなく、作業のしやすさの話。

## 実務的なおすすめ運用

1. モデリング中：早めにスムーズシェードをかけて、形の確認用にそのまま進める
2. 途中で押し出し・分割して面を足すと、周囲の設定を引き継ぐのでフラットとスムーズが混ざることがある
3. 完成後：オブジェクト全体を選択して **Shade Auto Smooth（自動スムーズ）** をかけ直し、角を立てたい辺だけ調整する

これなら「途中で確認」と「最後に整える」を両立できる。

## 1つだけ順序に注意する点（Blender 4.1以降）

4.1以降、以前の「自動スムーズ」はオブジェクトデータの項目ではなく **Smooth by Angle（角度によるスムーズ）というジオメトリノードのモディファイア**として追加される（右クリック → シェードのオートスムーズ）。

このモディファイアは**モディファイアスタックの最後に置く**のが基本。早い段階でオートスムーズをかけ、その後にベベルやサブディビジョンを追加すると、スムーズ処理がそれらより前に来てしまい、意図した角の立ち方にならないことがある。

→ **オートスムーズは「モディファイアを組み終わった後」にかける**、あるいは追加後にスタックの一番下へドラッグする。

## まとめ

| 目的 | タイミング |
| --- | --- |
| 形のチェック | 早め（いつでも、何度でも） |
| 最終的な見た目の確定 | 完成後にまとめて |
| オートスムーズ / Smooth by Angle | モディファイアを組み終わった最後 |
