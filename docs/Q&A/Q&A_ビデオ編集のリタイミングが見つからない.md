# Q. ビデオ編集で ver5.2 にリタイミングが見つからない。クリップを選択すれば出たはずだけど、今はどこから？

## A. 結論

**「ストリップ」メニュー > 「リタイミング」（Strip > Retiming）にすべて入っている。**

見つからなかった理由は単純で、**リタイミングキーは既定で非表示**だから。

> 公式マニュアルより：
> **キーは Show Retiming Keys プロパティを有効にするまで表示されない**
> （Keys stay hidden until the *Show Retiming Keys* property is enabled）

だから「クリップを選択しても何も出ない」。サイドバー（`N`）を探しても無い。

---

## 最短手順

```
1. ストリップ（クリップ）を選択
2. Ctrl + R        ← リタイミングキーの表示をオン
3. キーが出てくるので、ドラッグ or G で移動して伸縮
```

**もっと手早く速度だけ変えたい場合：**

```
ストリップを選択 → R → 速度の数値を入力
```

> 公式マニュアル：「素早い速度変更には **R** を押して速度を入力する」

---

## メニュー一覧（ストリップ > リタイミング）

| 操作 | メニュー項目 | ショートカット | 内容 |
|---|---|---|---|
| **表示の切り替え** | Toggle Retiming Keys<br>（リタイミングキーを切り替え） | **Ctrl + R** | `Show Retiming Keys` をオンにしてキーを表示・操作可能にする |
| **キーを追加** | Add Retiming Key<br>（リタイミングキーを追加） | **I** | 現在フレームにキーを追加。**ストリップの始点・終点のキーは常に必須**なので自動で作られる |
| **速度を数値指定** | Set Speed<br>（速度を設定） | — | 区間の速度を設定。**「現在のリタイミングを維持」**オプションで、他区間の速度を変えずにストリップの長さ側で調整する |
| **静止させる** | Add Freeze Frame and Slide<br>（フリーズフレームを追加してスライド） | — | 任意の長さで1フレームに静止。**フリーズフレームへの滑らかな出入りはできない** |
| **なめらかに速度変化** | Add Speed Transition and Slide<br>（速度トランジションを追加してスライド） | — | 2つの速度間を滑らかに繋ぐ。**連動する2つのキー**が逆方向に動く |
| **キーを削除** | Delete Retiming Keys<br>（リタイミングキーを削除） | **X / Delete** | 削除しても**ストリップの長さは変わらない**。速度が前後区間の平均になる |
| **元に戻す** | Reset Retiming<br>（リタイミングをリセット） | — | ストリップ本来のタイミングに戻す |

---

## キーの選択・移動のクセ（ここでつまずく）

公式マニュアルの記述そのまま：

- **ボックス選択は、すでにキーが1つ選択されているときだけキーを拾う。**
  そうでないと**ストリップを選択してしまう**
  → 「囲ってもキーが選べない」のはこれが原因。まず1つクリックで選ぶ
- **Ctrl + クリック** で、**そのキーより右側のすべてのキー**を選択できる
- キーの移動は**ドラッグ**または **G**
- **移動させたキー以外は動かない**
  → 複数区間をまとめて伸縮したいなら**複数選択が必要**
- ストリップの境界外にあるキーは、最初／最後のキーと一緒に動く（隠れたリタイミング情報を保つため）

---

## 制限事項（これも公式明記）

- **エフェクトストリップはリタイミングできない**
- リタイミングされるのは**ストリップの中身（コンテンツ）だけ**。
  **既存のアニメーション（キーフレーム）はリタイミングされない**
- **音声のリタイミングは Audaspace 経由**で、フレームごとの再生速度を渡す方式のため**正確ではなく、わずかにずれることがある**
- メタストリップは子ストリップごとリタイミングできる（メタ → 子の順に評価される）

---

## 仕組み（なぜキーで速度が変わるのか）

リタイミング区間は**2つのリタイミングキー**で挟まれる。各キーが持つのは：

| 値 | 意味 |
|---|---|
| `strip_frame_index` | ストリップ先頭から数えたキーの位置（**素材側の時間**） |
| `retiming_factor` | **0 = 素材の最初のフレーム / 1 = 最後のフレーム** |

- **最後のキーの位置がストリップの長さを決める**
- 再生時は `retiming_factor × 素材の長さ` で表示するフレームを求める
- キーの種類は3つ
  - **デフォルト**：2つのキー間を線形補間
  - **フリーズフレーム**：両端のキーが同じ `retiming_factor` を持つ
  - **速度トランジション**：隣接区間の傾きに接する**円弧**で繋ぐ（必ずキー2つセット）

→ つまり「キーを横にずらす＝素材のどのフレームをいつ表示するかを付け替える」ので、伸ばせばスロー、縮めれば早送りになる。

---

## 「昔は選択すれば出た」について

リタイミングキーは Blender 4.0 で導入された機能。
古い解説には **「追加 > エフェクトストリップ > 速度コントロール」** を使う手順も多いが、**現在の正式な方法はリタイミングキー**。

いずれにしても **5.2 では `Ctrl + R` でキー表示をオンにしないと何も見えない**ので、そこだけ押さえればよい。
