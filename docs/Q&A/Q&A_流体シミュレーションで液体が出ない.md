# Q. 流体シミュレーションが、再生しても出ない／ベイクしても出ない

環境: Blender 5.2 LTS。参考動画は 3.6.3。ドメインの箱の中に Sphere（流入口）とボトルを置いた構成。

## A. 結論：ベイクの工程を1つ飛ばしていた

**モジュラーでは「データをベイク」と「メッシュをベイク」が別のボタン。「データをベイク」だけ押して止まっていた。**

その状態だと、流体の計算自体は終わっているのに**水面のメッシュが生成されないので、画面には何も出ない**。エラーも警告も出ない。

決め手になった観察は **「モジュラーだと出ないが、リプレイだと出る」**。リプレイは全工程が自動で走るので出る。この差がすべてを説明した。

**シミュレーションも設定もファイルも、最初から壊れていなかった。**

## キャッシュタイプの違い（ここが本質）

| タイプ | 挙動 | 使いどころ |
| --- | --- | --- |
| **リプレイ** | 再生すると**全工程が自動で走る** | 作業中・確認用。最終レンダリングには非推奨 |
| **モジュラー** | 工程ごとに**手動でベイク**。ボタンが分かれている | 工程ごとに調整したいとき |
| **全て** | **1ボタンで全工程を一括ベイク** | 最終レンダリング前はこれが安全 |

### モジュラーで押す順番

1. **データをベイク** — 流体の基本計算
2. **メッシュをベイク** — 水面のポリゴン生成 ← **ここを忘れる**
3. 必要に応じて「ノイズをベイク」「パーティクルをベイク」

## 運用ルール（これだけ守れば再発しない）

- **作業中・確認 → リプレイ**
- **レンダリング前 → 「全て」でベイク**
- **迷ったらモジュラーを使わない**（押し忘れが起きる）

## 遠回りの記録（同じ沼に入らないために）

結論に至るまでに疑って**外れた**もの。

| 疑ったこと | 結果 |
| --- | --- |
| 表面からの発生距離が 0 だった → 1.5 に変更 | 液体は出たが、**値そのものが原因とは限らない**。設定変更でキャッシュが無効化され再計算が走ったのが効いた可能性が高い。0 は発生範囲が実質ゼロなので 1.5 に戻すこと自体は正しい |
| `Shift + ←` で1フレーム目に戻して再読み込み | **リプレイで古いキャッシュが残っているときには実際に有効**。公式バグ [#75850](https://developer.blender.org/T75850) の回避策としても挙げられている |
| キャッシュのフォルダパス／日本語パス／iCloud同期／ディスク容量 | 今回は無関係 |
| 公式バグ（[#72860](https://developer.blender.org/T72860) 開始フレーム3以上で生成されない、[#85403](https://developer.blender.org/T85403) 再読み込み時に表示されない、[#73770](https://developer.blender.org/T73770) 非ASCIIパス） | いずれも該当せず（#73770はWindows専用・修正済み） |
| ドメインタイプが「ガス」のまま／スケール未適用／解像度不足 | 該当せず |

## 出ないときのチェックリスト（改訂版）

1. **ベイクのボタンが他にもないか見る**（モジュラーなら「メッシュをベイク」）← 今回の原因
2. キャッシュタイプを **「全て」** にして一括ベイクしてみる（工程の押し忘れが消える）
3. `Shift + ←` で1フレーム目に戻して再読み込みさせる（リプレイのキャッシュが古いとき）
4. ドメインのドメインタイプが「液体」か（初期値は「ガス」）
5. フロータイプが「液体」／フローの挙動が「流入口」か（フロータイプの初期値も「煙」）
6. フローの「表面からの発生距離」が 0 になっていないか（通常 1.5）
7. ドメインのスケールを適用したか（`Ctrl+A > スケール`）
8. 解像度（Resolution Divisions）。初期値 32 では小さい流入口を拾えないことがある
9. 切り分け：**新規ファイルで「クイック液体」が動くか**。動けばBlenderは正常、ファイル側の問題

## 教訓

**「ベイクしたのに出ない」ときは、まずベイクのボタンが他にもないか見る。**

設定や環境（パス・同期・ディスク・バグ）を疑う前に、**工程の押し忘れ**を疑う。今回は環境側を延々と調べたが、答えは押していないボタンが1つあっただけだった。

そしてもう一つ。**「Aだと動くがBだと動かない」という差が見つかったら、それが最短の手がかり**。今回もリプレイとモジュラーの差に気づいた瞬間に解決した。
