# Q. ブーリアンモディファイアを使っているのに、オブジェクトがきちんと消えない

## A. 結論：ブーリアンは「体積」の演算なので、閉じた立体でないと正しく動かない

公式マニュアルの警告：

> **多様体（Manifold）メッシュだけが正しい結果を保証される。**
> 非多様体メッシュ、特に穴のあるものは「*たいていうまく動くが、奇妙なグリッチやアーティファクトが出ることがある*」。
> **Manifold ソルバーは非多様体メッシュではまったく動作しない。**

「面が足りない」「辺が3枚以上の面に共有されている」といった状態では、**どこが内側でどこが外側か決められない**ので、切れないか変な結果になる。

---

## まず試す3つ（大半はここで直る）

### 1. ソルバーを「Exact」に変える ← 最優先

| ソルバー | マニュアルの説明 |
|---|---|
| **Float**（旧「高速 / Fast」） | シンプルで**性能が良いが、重なったジオメトリに対応していない** |
| **Exact**（完全） | 複雑だが**最良の結果**。**重なったジオメトリに完全対応**。ただし**かなり遅い** |
| **Manifold** | **たいてい最速**だが、**多様体メッシュでしか動かない**（例外：平面との差分） |

→ **切れないならまず Exact。** これだけで直ることが非常に多い。

### 2. 法線を外向きに直す

裏返った面があると、Blenderは内外を判定できない。

```
編集モード > A（全選択） > Shift+N
```

> 「Mesh > Normals > **Recalculate Outside**」／ショートカット **Shift-N**
> 「選択した面を必要に応じて反転させ、**すべて外向き（または内向き）に揃える**」

**確認方法**：オーバーレイ > **面の向き（Face Orientation）**

> 「**面が間違った向きになっているものを素早く見つけるのに役立つ**」

青が表、赤が裏。**赤が見えたら Shift+N**。

### 3. 重複頂点を結合する

```
編集モード > A > M > 距離で結合
```

> **Merge by Distance** =「*一定距離より近い頂点のクラスタをそれぞれ結合する*」

左下に「Removed N vertices」と出たら、それが原因だった可能性が高い。

---

## それでも直らないとき

### 4. 非多様体を探す

```
選択 > すべてを選択（特徴）> 非多様体
```

> 「**メッシュの非多様体ジオメトリを選択する**」
> ※ **頂点選択モードと辺選択モードでのみ利用可能**

選ばれた場所が原因。典型例：

| 症状 | 対処 |
|---|---|
| 穴が開いている（面が足りない） | 穴の縁を選択して `F` で面を張る |
| 1つの辺を3枚以上の面が共有 | 余分な面を削除 |
| 浮いた頂点・辺がある | メッシュ > クリーンアップ > **孤立要素を削除** |
| 内部に面がある | `選択 > すべてを選択（特徴）> 内側の面` → `X > 面` |

### 5. Exact の「自己交差」「穴の許容」をオンにする

> **Self Intersection（自己交差）**：参加しているメッシュの**自己交差を正しく処理する**。ただし**性能コストがかかる**。
> **Hole Tolerant（穴の許容）**：**非多様体ジオメトリ向けに出力を最適化する**（計算時間は増える）。
> **Exact ソルバーが非多様体ジオメトリでエラーを出すときだけ有効にすること。**

→ メッシュを直せない事情があるときの「逃げ道」。常時オンにするものではない。

### 6. カッターが貫通しきっていない

差分（Difference）で「途中までしか切れない」なら、**カッターが対象を完全に突き抜けていない**。
カッターを少し大きくして、**両側にはみ出させる**。

### 7. 面がぴったり同一平面で接している

カッターの面と対象の面が**完全に同じ平面**にあると、内外が決まらず破綻する。

→ **カッターを 0.001 m ほどずらす。**
（[[Q&A_面にガビガビのノイズが出る（Zファイティング）]] と同じ根っこの問題）

### 8. スケールが適用されていない

```
Ctrl+A > スケール
```

### 9. モディファイアの順序

ブーリアンは**その時点での形**に対して働く。

| 順序 | 結果 |
|---|---|
| ミラー → ブーリアン | ミラー**後**の形を切る（両側が切れる） |
| ブーリアン → ミラー | 切った形を鏡像化（**切り口も鏡像になる**） |
| サブディビジョン → ブーリアン | 滑らかになった後の形を切る |
| ブーリアン → サブディビジョン | 切ってから滑らかに（**切り口が溶ける**） |

→「片側しか切れていない」はミラーとの順序が原因のことが多い。

### 10. オペランドタイプを確認

> **オブジェクト**：ソースは**単一のメッシュオブジェクト**
> **コレクション**：ソースは**任意の数のメッシュオブジェクト**。
> ※ **Float ソルバーでは Intersect（交差）が使えない**

複数のカッターで切るならコレクションにまとめる。

---

## 切れたけど見た目が汚い場合

### 切り口のトポロジーが汚い

**これは正常。**ブーリアンは切り口にNゴン（多角形面）を作る。
サブディビジョンをかけるなら、適用後に手でループを整えるか、ベベルでエッジを締める。

### マテリアルがおかしい

> **Index Based**：ソースのマテリアルスロットを**順番で**対応付ける。範囲外のインデックスの面は**修正対象メッシュの最初のマテリアル**を使う。
> **Transfer**：**ソースメッシュのマテリアルを使い**、必要に応じてスロットを追加する。空のスロットはソースのマテリアルインデックスにフォールバックする。

## チェック順

```
1. ソルバーを Exact に                                  ← まずこれ
2. A > Shift+N（法線を外向きに）
   └ オーバーレイ > 面の向き で赤が無いか確認
3. A > M > 距離で結合（重複頂点）
4. 選択 > すべてを選択（特徴）> 非多様体 で穴を探す
5. Exact の「自己交差」「穴の許容」をオン
6. カッターを完全に貫通させる／0.001m ずらす
7. Ctrl+A > スケール
8. モディファイアの順序（特にミラー）
```

## ★実例：円を押し出した円柱では切れず、円柱プリミティブでは切れた

**違いは「ふた（キャップ）があるかどうか」＝閉じた立体かどうか。**

### 円（Circle）の既定は「ふた＝なし」

マニュアルの「ふたのタイプ（Fill Type）」：

| 選択肢 | 定義 |
|---|---|
| **なし（Nothing）** | 「円を塗りつぶさず、**外周の頂点だけ**を作る」 ← **円の既定** |
| **Nゴン** | 「中心を**1枚のNゴン面**で埋める」 |
| **三角の扇（Triangle Fan）** | 「中心の頂点を共有する三角形の面で埋める」 |

→ 既定のままだと**面が存在しない**。だから押し出しているのは「面」ではなく**辺（エッジループ）**。
→ 結果は **両端とも開いた筒**。ふたが1枚も無い。

### 円柱（Cylinder）の既定は「Nゴン」

| 選択肢 | 定義 |
|---|---|
| **なし** | 「端のふたは追加されない。**側面だけが作られ、筒になる**」 |
| **Nゴン** | 「**両端がそれぞれ1枚のNゴン面で埋められる**」 ← **円柱の既定** |
| **三角の扇** | 「両端が中心頂点を共有する三角形で埋められる」 |

→ 最初から**完全に閉じた立体**。だからブーリアンが成立する。

### なぜ開いていると切れないのか

> **多様体メッシュだけが正しい結果を保証される。**

ブーリアンは**体積の演算**。開いた筒は「どこが内側か」が数学的に定義できないので、
**どこを削ればいいか決められない**。

```
【円柱プリミティブ】           【円を辺で押し出したもの】

   ╭─────╮  ← ふた              ╭ ─ ─ ─ ╮  ← 開口（面が無い）
   │     │                      │       │
   │     │  閉じた体積 ✅       │       │  体積が定義できない ❌
   │     │                      │       │
   ╰─────╯  ← ふた              ╰ ─ ─ ─ ╯  ← 開口
```

### 確認方法

```
編集モード > 選択 > すべてを選択（特徴）> 非多様体
```

**上下の縁が光ったら、そこが開口部＝原因。**

### 直し方

| 方法 | 手順 |
|---|---|
| **① ふたを張る（最速）** | 開いた縁を `Alt+クリック` でループ選択 → **`F`**（Nゴンが張られる）。**両端やる** |
| **② 作る段階で直す** | 円を追加した直後に **F9 > ふたのタイプ = Nゴン** → そのあと**面モードで押し出す** |
| **③ 厚みを付ける** | ソリッド化モディファイアを適用（形は変わる） |
| **④ 応急処置** | ブーリアンを Exact にして**穴の許容（Hole Tolerant）**をオン |

> **Hole Tolerant（穴の許容）**：「**非多様体ジオメトリ向けに出力を最適化する**」
> 「**Exact ソルバーが非多様体ジオメトリでエラーを出すときだけ有効にすること**」

### 補足：面を押し出せば、ちゃんと閉じる

マニュアルの押し出し（領域）の挙動：

> 「**境界ループが1つの面にしか属していない場合、選択した面はすべて複製され**、新しく作られた面とリンクされる」
> 「それ以外の場合、選択した面は新しい面にリンクされるが**複製はされない**」

つまり**単独の円の面**を押し出した場合は、**元の面も残る**ので閉じた円柱になる。
→ 失敗していたのは「**ふたの無い円を、辺で押し出していた**」から。

### 教訓

> **ブーリアンのカッターは「水も漏らさない閉じた立体」でなければならない。**
> 押し出しで作ったものは、**必ず両端が閉じているか確認する。**

## ★「Fでふたを閉じたのに、まだ切れない」とき

ふたを張っても切れないなら、**次に疑うのは法線**。

### 最有力：法線がバラバラ／内向きになっている

**辺（エッジループ）を押し出して作った筒は、側面の法線が内向きになりやすい。**
辺の巻き方向から面の向きが決まるため、プリミティブのように「必ず外向き」にはならない。
さらに `F` で張ったふたも、向きは自動では揃わない。

→ 形は閉じていても、**Blenderから見ると「どっちが外か分からない立体」**のまま。

```
編集モード > A（全選択） > Shift+N
```

**確認は必ず目で：オーバーレイ > 面の向き**
**青＝表（外向き）／赤＝裏**。赤が1枚でも見えたらアウト。

### 決定的な診断ツール：3Dプリントツールボックス

メッシュが「水密（watertight）」かどうかを一発で判定できる。

> **Solid（ソリッド）チェック**：「**非多様体の辺**と**不正な連続辺（Bad Contiguous edges）**を探す。これらは**メッシュが水密でない**ことを意味しうる」
>
> **非多様体の辺**：「**辺は正確に2枚の面に接続しているべき**。**1枚なら穴があり**、3枚以上も許されない」
>
> **Bad Contiguous edges**：「**ある面の法線が隣の面と違う方向を向いている**ため、その辺がフラグされる」← **法線の不整合がここに出る**
>
> **Degenerate（縮退）**：「**面積が0の面／長さが0の辺**」
>
> **Intersections（交差）**：「別々のパーツの面が重なっている」

**編集モードで結果をクリックすると、問題箇所が選択される。**

| バージョン | 入手方法 |
|---|---|
| 〜4.1 | プリファレンス > アドオン > Mesh > **3D Print Toolbox** を有効化 |
| **4.2 LTS 以降（5.x含む）** | **プリファレンス > 拡張機能**で「**3D Print Toolbox**」を検索してインストール |

パネルは **3Dビューポート > サイドバー（N）> 3D-Print タブ**。
**「Check All」** で全チェック、**「Make Manifold」** で自動修復もできる。

### 次に疑う：`F` の張り方

| ありがちなミス | 正しいやり方 |
|---|---|
| **全頂点を選択したまま `F`** を押した | **辺モード**にして `Alt+クリック` で**縁のループだけ**を選択 → `F` |
| 片方の端しか塞いでいない | **両端**やる |
| 縁が平面でない | `S > Z > 0`（軸は向きによる）で平らに揃えてから `F` |

**再チェック**：

```
選択 > すべてを選択（特徴）> 非多様体
```

まだ光るなら塞ぎ切れていない。ここが空なら形状はOK＝法線かソルバーの問題。

### それでも駄目なら

```
1. A > M > 距離で結合（重複頂点）
2. ソルバーを Exact に
3. Ctrl+A > スケール
4. カッターが対象を完全に貫通しているか
5. 3Dプリントツールボックス > Make Manifold で自動修復
```

### 現実的な最短ルート

**円柱プリミティブで作り直す。**
そちらは問題なく切れることが確認できているので、
「押し出しで作った筒を直す」より速いことが多い。

```
Shift+S > カーソル → 選択物   ← 位置を記憶
古い筒を削除（X）
Shift+A > メッシュ > 円柱 → F9 で頂点数・半径・深度を指定
```
