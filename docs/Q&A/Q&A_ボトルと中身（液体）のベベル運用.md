# Q. 複雑な形を作っていて、ボトルの中身（液体）も作った場合はどうする？

ベベルモディファイアはオブジェクト全体にかかるので、ボトルと中身が絡む複雑なモデルではどう運用するのか。

## A. 大前提：ボトルと中身は「別オブジェクト」にする

モディファイアは**オブジェクト単位**。別オブジェクトにすれば、

- ボトルのベベル設定と液体のベベル設定が干渉しない
- マテリアル（ガラス IOR 1.45 / 水 1.33）を別に持てる
- 片方だけ非表示にして中を確認できる

逆に同一オブジェクトにまとめると、1つのベベルモディファイアが両方にかかるので混乱する。まず分ける。これが一番効く。

## ボトル本体：回転体は「プロファイル + スクリュー」で非破壊に持つ

ボトルのような回転体は、円筒をいじるより**断面の輪郭線（プロファイル）を作ってスクリューモディファイアで回す**方が圧倒的に編集しやすい。

- 輪郭の頂点を動かすだけでシルエットが変わる（くびれ、肩、口の絞り）
- 頂点数が少ないので編集が軽い
- ベベルの帯を何本も動かす問題が最初から起きない

### モディファイアの順番

```
スクリュー（回転体化）
  ↓
ソリッド化（ガラスの厚み）
  ↓
ベベル（口・底・エッジの面取り）
  ↓
ウェイテッドノーマル（陰影整え / 任意）
  ↓
スムーズ by アングル（オートスムーズ・最後）
```

**注意点**：スクリューの継ぎ目（回転の始点と終点）で頂点が重複していると、そこだけベベルが破綻する。スクリューの「マージ」をオンにするか、頂点をマージしてからベベルをかける。

## 中身（液体）：ガラスの内壁を流用する

1. ガラスの内側の面を選択して **複製 → 分離（P → 選択物）** で別オブジェクトにする
2. 液面の高さで切って、液面のフタになる面を張る
3. 液体はガラスに**わずかに食い込ませる**（0.001〜0.01mm程度）

3が重要。ガラスと液体の間に空気の隙間があると、レンダリング時に「ガラス → 空気 → 液体」と余計な屈折の界面ができて、境目が暗く濁ったように出る。**隙間を作らず、あえてめり込ませる**のが定石。

### 液体のベベル

- 液面の縁（液体とガラスが接する円）だけ、**ごく小さいベベル**を入れる。実物のメニスカス（液面の張り付き）に近づいて一気にリアルになる
- 液体側は制限方法「ウェイト」にして、液面の縁の辺だけウェイト1を付ける

## Ctrl+B を使う箇所（このケース）

「ベベル面の上にさらに作業する」ところは破壊的ベベルの領分。

- 口のネジ山、注ぎ口の返し
- ラベルの段差、凹みのディテール
- 底の接地リング（へこみ）の作り込み

これらは面取りした面を土台にして押し出したり穴を開けたりするので、実体のあるジオメトリが必要。

## 同一オブジェクト内で部分的に設定を変えたいとき

分けられない事情があるなら、**頂点グループ**で制限したベベルモディファイアを複数重ねる。

| モディファイア | 制限 | 用途 |
| --- | --- | --- |
| ベベル1 | 頂点グループ「口」 | 口周りを太めに |
| ベベル2 | 頂点グループ「胴」 | 胴の角を細く |

## スムーズシェード

最後に **シェードのオートスムーズ**（Smooth by Angle）を全モディファイアの後ろに置く。回転体は角度30°の既定でだいたい素直に出る。液面の縁など「ここは角を立てたい」辺には**シャープをマーク**する。

## まとめ

| 対象 | 方針 |
| --- | --- |
| ボトルと中身 | 必ず別オブジェクト。モディファイアはオブジェクト単位 |
| ボトルの形 | プロファイル + スクリューで非破壊。輪郭だけ編集 |
| ボトルのベベル | モディファイア + 辺ごとのベベルウェイト |
| 液体 | 内壁を複製して分離、ガラスに微妙にめり込ませる |
| 液面の縁 | 極小ベベルでメニスカス表現 |
| ネジ山・ラベル段差 | Ctrl+B（上にさらに作業するため） |
| オートスムーズ | 必ずスタックの最後 |
