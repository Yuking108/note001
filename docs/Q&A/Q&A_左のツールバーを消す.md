# Q. 3Dビューポートの左にあるバーを消したい

編集モードで左端に縦に並んでいるアイコンの列（選択・移動・押し出し・ベベルなど）。画面が狭いので消したい。

## A. `T` でトグル

**3Dビューポート上にマウスを置いて `T`。** もう一度 `T` で戻る。

これは **ツールバー（Toolbar）** という名前で、**コンテキストに応じたツールアイコン**が並ぶ領域。メニューからなら **ビュー > サイドバー/ツールバー**。

ツールバーは3Dビューポート専用ではなく、シェーダーエディター、UVエディター、シーケンサー、ドープシート、ファイルブラウザなど多くのエディターに共通で存在し、**どこでも `T` で開閉できる**。

## ついでに覚えておく周辺のトグル

| キー / 場所 | 消えるもの |
| --- | --- |
| **`T`** | **左のツールバー** |
| **`N`** | 右のサイドバー（アイテム / ツール / ビュー のパネル） |
| ビュー > ギズモ のチェックを外す | 右上のナビゲーションギズモ、右端のズーム・手のひら・カメラ・鍵アイコン |
| ヘッダー右の「オーバーレイを表示」ボタン | グリッド、選択のハイライト、原点、法線表示など |
| `Ctrl + Space` | マウス位置のエディターを一時的に全画面化（レイアウトは保持） |

`N` のサイドバーも `T` と同じく、グラフエディターやUVエディターなど多くのエディターで共通。

## スクリーンショットを撮るとき

**`T` → `N` → ギズモOFF → オーバーレイOFF** の順で、ほぼ絵だけのクリーンな画面になる。

作業に戻るときはそれぞれ元に戻すだけ。**表示の設定なので、モデルやシーンには一切影響しない。**
