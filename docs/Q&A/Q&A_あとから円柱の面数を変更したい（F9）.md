# Q. メッシュを選択してF12を押しても、円柱の面数を変更できない。移動させた後とか

## A. まず2つ訂正

| キー | 実際の機能 |
|---|---|
| **F12** | **レンダリング（画像をレンダー）** ← 面数とは無関係 |
| **F9** | **最後の操作を調整（Adjust Last Operation）** ← こっち |

そして本題の答えは：

> **移動したあとでは、もう変更できない。**

---

## なぜできないのか

公式マニュアルより：

> 「**オペレーターを実行した後に、そのパラメーターを調整できる**」
> 「対応しているエディターでは、**左下にヘッドアップディスプレイのパネル**がある」
> 「F9（編集 > 最後の操作を調整）のポップアップも**同じことをする**」
> 「このパネルは**最後に実行された操作に基づく**」

ポイントは最後の一行。**「最後に実行された操作」に基づく**。

```
円柱を追加          → F9 で「頂点数」が出る ✅
   ↓ G で移動
移動（Move）が最後の操作 → F9 で「移動」のオプションが出る ❌
```

つまり移動した瞬間、**最後の操作が「追加」から「移動」に入れ替わる**ので、頂点数のパネルは消える。
選択やクリックでも同じように入れ替わる。

### もっと根本的な理由

**Blenderのプリミティブはパラメトリックではない。**
「頂点32個の円柱オブジェクト」ではなく、**作られた瞬間にただの頂点と面の集合**になる。
F9は「もう一度作り直す」機能であって、既存のメッシュの設定を書き換えているわけではない。
だから編集したあとに戻れるはずがない。

---

## 対処法

### 1. 追加した直後にF9（本来の使い方）

```
Shift+A > メッシュ > 円柱
→ 何もせずに F9（または左下のパネルを開く）
→ 頂点 / 半径 / 深度 / ふたの塗りつぶし を調整
```

**追加した直後に必ず数値を決める**のを習慣にするのが一番早い。

### 2. Ctrl+Z で追加直後まで戻ってから F9

移動しただけなら、`Ctrl+Z` を1回押して移動を取り消せば、最後の操作が「追加」に戻るので F9 が使える。

### 3. 消して作り直す（結局これが一番速いことが多い）

移動した位置を保ちたいなら：

```
1. 3Dカーソルをそのオブジェクトにスナップ
   Shift+S > カーソル → 選択物
2. 古い円柱を削除（X）
3. Shift+A > メッシュ > 円柱   ← 3Dカーソルの位置に作られる
4. F9 で頂点数を指定
```

### 4. ★ あとから何度でも変えたいなら：ジオメトリノード

**これが本当の解決策。**ジオメトリノードの**円柱ノード**はパラメトリックなので、**いつでも頂点数を変えられる**。

| 入力 | マニュアルの定義 |
|---|---|
| **頂点（Vertices）** | 「**上面と下面の円上の頂点数**」※3未満ではジオメトリが生成されない |
| **サイドセグメント** | 「側面に沿って**垂直に走る辺の数**」※1未満では生成されない |
| **フィルセグメント** | 「上面・下面の丸い面を埋めるのに使う**同心円状のリングの数**」 |
| **半径** | 「**Z軸からの頂点の距離**」※0だと出力は1本の線になる |
| **深度** | 「**円柱の高さ**」 |
| **フィルタイプ**（プロパティ） | 「半径が0より大きいとき、**上下の円をどう面で埋めるか**」→ なし / Nゴン / 三角形 |

```
1. オブジェクトを選択
2. ジオメトリノードプロパティ > 新規
3. Shift+A > メッシュ > プリミティブ > 円柱
4. グループ出力に繋ぐ
5. モディファイアパネルに「頂点」などが出てくるので、いつでも変更できる
```

→ **あとから何度も調整する可能性があるものは、最初からジオメトリノードで作る**のが正解。

### 5. Pythonコンソールから作る

```python
import bpy
bpy.ops.mesh.primitive_cylinder_add(vertices=64, radius=0.5, depth=2, location=(0,0,0))
```

数値を書き換えて実行し直せば何度でも作れる。

## 編集モードで円周の分割を増やしたい場合

既存の円柱の**円周方向の分割数**を直接変えることはできないが、近いことはできる。

| やりたいこと | 方法 |
|---|---|
| **高さ方向**の分割を増やす | `Ctrl+R`（ループカット）／側面を選択して細分化 |
| **円周方向**の分割を倍にする | 側面の垂直な辺をすべて選択 > 右クリック > **細分化** |

> ただし**細分化しただけでは新しい頂点は円弧上ではなく多角形の辺の上に乗る**ので、断面が真円から外れる。
> 円形に整えるには **LoopTools アドオンの「円」** を使うか、素直に作り直す。

**結論：円周の分割数を変えたいなら作り直したほうが速くてきれい。**

## まとめ

```
F12 = レンダリング（別機能）
F9  = 最後の操作を調整   ← 追加した「直後」だけ有効

移動・選択など別の操作をした時点で、もう変えられない
　→ Ctrl+Z で戻るか、作り直す
　→ あとから変えたいものは ジオメトリノードの円柱ノード で作る
```
