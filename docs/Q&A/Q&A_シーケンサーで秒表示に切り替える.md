# Q. ビデオ編集モードで「秒で表示」に切り替えるボタンはどこ？

Blender 5.2。シーケンサーのタイムラインがフレーム表示になっていて、秒で見たい。

## A. `Ctrl + T`

これが最速。メニューからなら **ビュー（View） > 秒を表示（Show Seconds）**。シーケンサーのヘッダーにある「ビュー」メニューの中。

表示は **SMPTEタイムコード形式**（`00:01:15:10` のような形）になる。もう一度 `Ctrl + T` でフレーム表示に戻る。

## 注意点：エディターごとの設定

**シーケンサーのタイムラインと、下にあるタイムラインエディターは別々**に切り替える必要がある。片方だけ秒表示になって混乱しやすい。

`Ctrl + T` は**マウスカーソルを置いているエディター**に対して効くので、切り替えたい方の上にカーソルを乗せてから押す。

この「カーソルがある場所に効く」はBlender全体の原則。ショートカットが効かないときは、まずカーソルの位置を疑う。
