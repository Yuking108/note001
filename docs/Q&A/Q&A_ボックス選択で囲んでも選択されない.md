# Q. ボックス選択で囲んでいるのに選択にならない

ボックス選択ツールでドラッグして範囲を囲んでいるのに、何も選択されない。透過モードにしても奥側が選択されない。

## A. 原因は複数ある。上から順にチェックする

### 1. ツール設定のモードが「減算」になっている

ボックス選択ツールを選ぶと画面上部のツール設定バーに小さなアイコンが4つ並ぶ（設定 / 拡張 / 減算 / 差分 / 交差）。ここが「減算（Subtract）」だと、囲っても選択が解除されるだけで何も選ばれない。**一番左の「設定（Set）」**に戻す。ツール切り替え直後に一番多い原因。

### 2. 透過（X-Ray）がオンになっていない

編集モードでは、デフォルトだと手前から見えている頂点しか選択されない。`Alt+Z` で透過をオン。

- `Shift+Z`（ワイヤーフレーム切り替え）と押し間違えやすい
- ビューポート右上の「重なった2つの四角」アイコンが青くハイライトされていれば有効
- シェーディングのプルダウンで X-Ray スライダーが 1.0 だと、見た目は不透明のまま

### 3. 面選択モードになっている

面は「中心の点」が範囲内に入らないと選択されない。`1` で頂点選択モードに切り替えて試すと分かりやすい。

### 4. 裏側が別オブジェクトになっている

編集モードは今編集中のオブジェクトにしか効かない。複数同時に編集するなら、オブジェクトモードで全部選択してから `Tab`。

### 5. 非表示の頂点がある

過去に `H` で隠した部分は選択対象外。`Alt+H` で全表示に戻る。

### 6. モディファイア由来の形状

ミラーやサブディビジョンで画面に見えているだけの形状は実体がないので選択できない。必要なら「適用」する。

### 7. アウトライナー側の設定

- 選択可能（矢印アイコン）がオフ → フィルター（じょうごアイコン）から有効化
- 目のアイコンがオフ / コレクションのチェックが外れている

## 切り分けの近道

`A`（全選択）を押す。裏側も含めて全部オレンジになるならジオメトリは存在しているので透過設定の問題。ならない部分があれば、別オブジェクトか非表示か、モディファイア由来の形状。
