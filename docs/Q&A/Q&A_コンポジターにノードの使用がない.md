# Q. 解説に「コンポジットで『ノードの使用』にチェックを入れる」と書いてあるが、そんなボタンがない

## A. Blender 5.0で「ノードを使用（Use Nodes）」は削除された。代わりにヘッダーの「新規」ボタンを押す

5.0でコンポジットのノードツリーが**独立したデータブロック**になり、マテリアルと同じ扱いに変わった。そのため有効化の操作もマテリアルと同じ形式になっている。

### 5.0以降の手順

1. コンポジットワークスペース（またはエディタタイプを「コンポジター」）を開く
2. **ヘッダーの「新規（New）」ボタン**を押す → ノードツリーが作られてシーンに割り当てられる
3. ノードを組む

これが旧バージョンの「ノードの使用にチェック」に相当する操作。

### 5.0でのその他の変更点

| 旧（4.x以前） | 新（5.0以降） |
| --- | --- |
| ヘッダーの「ノードを使用」チェック | ヘッダーの「新規」ボタン |
| **コンポジット**ノード（最終出力） | **グループ出力**ノード |
| シーンに1つのノードツリー | データブロックとして複数持てる・他のblendファイルでも再利用できる |
| `scene.node_tree`（Python） | `scene.compositing_node_group` |

「コンポジットノードが見つからない」という混乱も同じ原因。最終出力は**グループ出力**につなぐ。

## 4.x以前を使っているのに見つからない場合

チェックボックス自体は存在するので、以下を確認する。

- **エディタタイプが「コンポジター」になっていない**（シェーダーエディタを見ている）。左上のエディタタイプで切り替える
- **ヘッダーが狭くて項目が隠れている**。ヘッダー上で中ボタンドラッグ（またはホイール）すると横にスクロールして出てくる
- バージョン確認：ヘルプ → Blenderについて

## 補足：レンダリング結果をコンポジターに持っていく方法

- 通常は**レンダーレイヤー**ノードを使う。画像を読み込む必要はなく、レンダリング結果が自動で入ってくる
- 保存済みの画像ファイルを処理したいときは**画像**ノードで読み込む
- 途中の結果を見るには**ビューアー**ノードをつなぎ、ヘッダーの「背景（Backdrop）」を有効にすると背景に表示される

## 追問：「新規」を押すと自動的に反映されるのか？

**反映される。** 別途チェックを入れる操作は不要。

「新規」を押すと、コンポジットのノードツリーが作られて**そのシーンに割り当てられる**。以降、F12レンダリングと出力画像はこのノードツリーを通った結果になる。旧バージョンの「ノードを使用」にチェック＝有効化、という2段階が1つのボタンにまとまった形。

ただし実感として「何も変わらない」ように見える点に注意。

- 押した直後は **レンダーレイヤー → グループ出力** が素通しで繋がっているだけなので、見た目は一切変わらない
- 間にノード（グレアやカラーバランスなど）を挟んで初めて効果が出る

### 本当のオン/オフスイッチはここ

**レンダープロパティ → 後処理（Post Processing）→ コンポジティング** のチェック。
既定でオンなので普段は触らないが、「ノードを組んだのにレンダリングに反映されない」ときはここを確認する。逆に、ノードツリーを残したまま一時的に切りたいときもここをオフにする。

### ビューポートに反映させたいとき

F12のレンダリング結果には自動で乗るが、3Dビューポートのプレビューに出すかは別設定。

3Dビューポート右上の**シェーディングのポップオーバー**（下向き矢印）→ **コンポジター** を「常時」または「カメラ内」にする。既定は「無効」。

### 効果を切り分けたいとき

- 個別のノードを一時的に無効化：ノードを選んで **M**（ミュート）
- ノードツリーごと外す：ヘッダーのデータブロック名の横の **X** でリンクを解除
